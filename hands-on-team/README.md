# 만져보는 수학 전담팀

미적분Ⅱ부터 교육과정 위계를 따라 내려오며 `만져보는 수학` 활동을 하나씩 자동으로 만드는 AI 팀입니다.

- **언제**: 매일 20:00 · 24:00 · 04:00(서울), 한 번에 활동 하나
- **누가**: 설계(Opus) → 제작(Sonnet부터) → 자동 점검 → 오르빗 검수(Opus) → 정리(Sonnet)
- **수준**: 모든 역할이 가장 낮은 수준(low)에서 시작해, 오류·막힘·수정 지적이 나올 때마다 한 칸씩 올립니다. 사다리는 `RUNBOOK.md` 2절.
- **보고**: 매 실행 끝에 오르빗이 성취기준 부합·작동 점검·수학 정확성을 요약해 휴대폰 알림으로 보냅니다.
- **사이트 반영**: 자동으로 되지 않습니다. 확인 후 Supabase SQL Editor 에서 `supabase/hands-on.sql` 을 실행하면 올라갑니다.

| 파일 | 내용 |
|---|---|
| `RUNBOOK.md` | 예약 실행이 따르는 절차 |
| `queue.json` | 만들 순서(성취기준 61개: 미적분Ⅱ 23 · 미적분Ⅰ 20 · 대수 18)와 진행 상태 |
| `roles/*.md` | 역할별 지침(설계·제작·정리·오르빗) |
| `../.claude/agents/hands-on-*.md` | 모델 × 수준 8가지 팀원 |
| `tools/check_activity.py` | 실제 사이트와 같은 샌드박스에서 PC·모바일 작동 점검 |
| `log/<id>.md` | 활동별 수준 변화와 오르빗 보고 |
| `drafts/<id>/spec.md` | 설계서 |

순서·수준 규칙을 바꾸고 싶으면 `queue.json`·`RUNBOOK.md` 만 고치면 다음 실행부터 반영됩니다.
특정 항목을 건너뛰려면 그 항목의 `status` 를 `skipped` 로 바꾸세요.
