🏯 석가탑과 다보탑, 얼마나 떨어져 있을까?

불국사 대웅전 앞에는 석가탑과 다보탑이 마주 서 있습니다. 아래 배치도를 보고 두 탑 사이의 거리를 말해 보세요.

왜 선뜻 답하기 어려울까요?

그림에는 기준이 없기 때문입니다. 어디가 0 인지(원점), 1 이 얼마인지(단위)가 정해지지 않으면 “멀다/가깝다”만 말할 수 있을 뿐 수로 답할 수 없습니다.
수학이 도형을 다루는 첫걸음은 기준을 정하는 것 — 바로 좌표를 놓는 일입니다.

이 활동은 학습지 1-01 의 첫 질문과 이어집니다. 활동을 마친 뒤 학습지에 답을 적어 보세요.

앞 활동에서 배웠듯 좌표는 우리가 정하는 것이고, 어떻게 잡아도 거리는 변하지 않습니다. 그렇다면 계산이 가장 쉬워지는 자리에 놓으면 되겠죠. 세 가지 배치를 비교해 보세요.

③ 처럼 놓으면 B(−c, 0), C(c, 0), M(0, 0) 이 되어 부호가 딱 맞아떨어집니다. 학습지에서 “직선 BC 를 x축, 점 M 을 원점” 으로 잡으라고 한 이유예요.

세 줄이면 끝난다

B(−c, 0), C(c, 0), M(0, 0), A(a, b) 로 놓습니다. 한 단계씩 스스로 해 본 뒤 열어 보세요.

1단계 — 왼쪽 AB² + AC² 을 a, b, c 로 나타내기

AB² = (a − (−c))² + b² = (a + c)² + b²
AC² = (a − c)² + b²
더하면 (a² + 2ac + c²) + (a² − 2ac + c²) + 2b² = 2a² + 2b² + 2c²  — 2ac 가 서로 지워집니다!

2단계 — 오른쪽 2(AM² + BM²) 을 a, b, c 로 나타내기

AM² = (a − 0)² + (b − 0)² = a² + b²
BM² = (−c − 0)² + 0² = c²
2(AM² + BM²) = 2a² + 2b² + 2c²

3단계 — 두 결과를 비교하기
2a² + 2b² + 2c²  =  2a² + 2b² + 2c²   ∎

양쪽이 완전히 같은 식이 되었습니다. 증명 끝!

위 화면의 삼각형을 다시 움직여 보면, a·b·c 값이 바뀌어도 두 식은 늘 같은 모양임을 확인할 수 있어요.
