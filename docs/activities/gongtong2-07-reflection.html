대칭이동 — 점

파란 점 P 를 드래그 하면 네 가지 대칭점이 동시에 나타납니다. 부호와 자리가 어떻게 바뀌는지 관찰하세요.

x축 대칭   y축 대칭
원점 대칭   y=x 대칭
정리 · 점

점 (x, y) 의 대칭이동

기준이동한 점규칙
x축(x, −y)y좌표 부호 반대
y축(−x, y)x좌표 부호 반대
원점(−x, −y)둘 다 부호 반대
직선 y=x(y, x)x, y 자리 바꿈
헷갈릴 땐 앞 화면으로 돌아가 점을 (3, 1) 근처에 놓고 네 대칭점의 좌표를 직접 확인해 보세요.
도형의 대칭이동

도형을 대칭시키기

비대칭인 ‘ㄱ’ 모양 깃발(회색)을 기준별로 대칭시켜 봅니다(파랑). 버튼을 눌러 기준을 바꿔 보세요.

회색이 원래 도형, 파랑이 대칭이동한 도형입니다. 점선은 대칭축(또는 중심).
정리 · 도형

도형 f(x, y) = 0 의 대칭이동

기준이동한 도형
x축f(x, −y) = 0
y축f(−x, y) = 0
원점f(−x, −y) = 0
직선 y=xf(y, x) = 0
점의 이동과 완전히 같습니다! 도형은 “그 도형 위의 모든 점”을 옮긴 것이므로, 점에 적용한 규칙(부호 반대 / 자리 바꿈)을 방정식의 x, y 자리에 그대로 넣으면 됩니다. (평행이동과 달리 부호를 되돌리는 −a 가 아니라, x→−x 처럼 변수 자체를 바꿔치기합니다.)
정리

한눈에 정리

기준점 (x,y)도형 f(x,y)=0
x축(x, −y)f(x, −y)=0
y축(−x, y)f(−x, y)=0
원점(−x, −y)f(−x, −y)=0
y=x(y, x)f(y, x)=0

아래 ‘내 생각 적기’ 칸에, 네 가지 대칭이동 규칙을 정리하고, 도형의 대칭이동이 점의 대칭이동과 같은 규칙을 따르는 이유를 설명해 보세요.

확장 탐구

🔭 더 넓게, 더 깊게

배운 것을 옆으로(다른 분야와 잇기) 그리고 아래로(더 근본적인 이유로) 넓혀 봅시다. 정답을 맞히는 시간이 아니라 생각을 키우는 시간이에요.

↔ 수평 확장 · 어디에 쓰일까

이슬람 건축의 문양, 에셔의 판화, 나비의 날개, 사람 얼굴 — 아름답다고 느끼는 많은 것에 대칭이 있습니다. 거울·반사 조명, 이미지 편집의 ‘좌우 뒤집기’도 대칭이동이에요.

↕ 수직 확장 · 더 근본으로

대칭이동을 두 번 하면 제자리로 돌아옵니다(자기 자신이 역원). 또 서로 다른 두 대칭을 이어서 하면 회전이나 평행이동이 나와요. 이렇게 이동들을 ‘합성’해 분류하는 것이 변환군이고, 결정 구조·타일링 분류의 언어가 됩니다.
