평행이동 — 점

점 (x, y) 를 x축으로 a, y축으로 b 만큼 옮기면 좌표에 그대로 더합니다. 슬라이더를 움직여 파란 점이 어떻게 이동하는지 보세요.

(x, y) → (x + a, y + b)
도형의 평행이동

포물선을 옮기면?

포물선 y = x² 를 (a, b) 만큼 평행이동하면 y = (x − a)² + b 가 됩니다. 회색은 원래, 파랑은 옮긴 것. 부호에 주목하세요 — x 자리에 (x − a) 입니다!

도형의 평행이동

원과 직선도 마찬가지

원 x² + y² = 4 를 (a, b) 만큼 옮기면 (x − a)² + (y − b)² = 4. 모든 도형이 같은 규칙 — x → x−a, y → y−b 로 바꿉니다.

왜?

점은 +a, 도형은 −a — 왜 반대일까?

옮긴 도형 위의 새 점 (x, y) 를 생각해 봅시다. 이 점은 원래 도형 위의 어떤 점을 (a, b) 만큼 민 것입니다. 그렇다면 민 것을 되돌린 점 (x − a, y − b) 는 원래 도형 위에 있어야 합니다.

원래 도형: f(x, y) = 0  →  옮긴 도형: f(x − a, y − b) = 0

즉, 점은 좌표를 앞으로(+) 밀지만, 방정식에서는 되돌리는(−) 대입이 들어가므로 부호가 반대로 보입니다.

정리

대상(a, b) 만큼 평행이동
점 (x, y)(x + a, y + b)
방정식 f(x, y) = 0f(x − a, y − b) = 0
직선 y = mx + ny − b = m(x − a) + n
포물선 y = x²y = (x − a)² + b
원 x² + y² = r²(x − a)² + (y − b)² = r²

아래 ‘내 생각 적기’ 칸에, 점은 +a·+b, 도형은 −a·−b 로 부호가 반대인 이유를 자신의 말로 설명해 보세요.

더 나아가기 이슬람 미술의 테셀레이션은 한 무늬를 평행이동·회전·반사로 반복해 만듭니다. 평행이동은 그 첫걸음이에요. 관심 있으면 회전변환도 탐구해 보세요!

게임 캐릭터가 걷고, 지도가 스크롤되고, 슬라이드가 넘어가는 모든 움직임이 평행이동입니다. 이미지 편집의 ‘레이어 옮기기’, 프레젠테이션의 애니메이션도 좌표에 벡터를 더하는 일이에요.

↕ 수직 확장 · 더 근본으로

평행이동은 벡터 덧셈입니다. (a₁,b₁)만큼 옮기고 다시 (a₂,b₂)만큼 옮기면 (a₁+a₂, b₁+b₂)만큼 옮긴 것과 같고, 반대로 옮기면 원래대로 돌아오죠. 이렇게 ‘합성이 되고, 항등원과 역원이 있는’ 구조를 수학에서는 군(group)이라 부릅니다.
