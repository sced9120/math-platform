곡선 y = x − 2 와 직선 y = 2x + t 입니다. 어떤 학생이 “양변을 제곱해서 판별식으로” 교점의 개수를 구했습니다. 슬라이더로 t 를 움직여 판별식이 세는 개수와 실제 교점의 개수를 비교해 보세요.

판별식이 세는 해
–
실제 교점

회색 점선은 제곱하는 순간 함께 태어나는 유령 곡선 y = −x − 2 입니다. 제곱한 방정식 x − 2 = (2x + t)² 은 두 곡선을 구분하지 못합니다.

현장 검증

t = −5 — 학습지 풀이를 검산하자

학습지의 풀이는 판별식 D > 0 ⟺ t < −31/8 이라고 했습니다. 그렇다면 t = −5 에서는 교점이 2개여야 합니다. 정말일까요?

제곱한 방정식: 4x² − 21x + 27 = 0 → x = 3 또는 x = 2.25

두 해를 원래 식 x − 2 = 2x − 5 에 각각 대입해 봅시다. 버튼을 눌러 확인하세요.

범인의 정체

제곱은 부호를 지운다

a = b  ⟹  a² = b²   (참)
a² = b²  ⟹  a = b   (거짓! a = −b 일 수도)

x − 2 는 항상 0 이상입니다. 그런데 제곱한 방정식 x − 2 = (2x + t)² 은 2x + t 가 음수인 해까지 함께 데려옵니다. 그 해가 바로 유령 곡선 y = −x − 2 위의 교점, 즉 가짜 해입니다.

Ⅱ단원의 말로 정리하면 — 「a = b 이면 a² = b² 이다」는 참이지만 그 역은 거짓입니다. 제곱은 충분조건 방향으로만 안전한 조작이라서, 제곱해서 얻은 해는 반드시 원래 식으로 되돌아가 검산해야 합니다.

그래서 놓치면 안 되는 조건이 두 가지입니다.

조건이유
x ≥ 2근호 안이 0 이상이어야 함 (정의역)
2x + t ≥ 0좌변 x − 2 ≥ 0 이므로 우변도 0 이상이어야 함
사건 해결

올바른 답을 찾아라

첫 화면으로 돌아가 t 를 천천히 움직이며, 실제 교점이 2개가 되는 t 의 범위를 찾아보세요. 특히 t = −4 와 t = −31/8 = −3.875 근처에서 무슨 일이 일어나는지 관찰하세요.

곡선과 직선이 서로 다른 두 점에서 만나는 t 의 범위는?
t판별식의 해실제 교점무슨 일이
t > −31/80개0개아예 안 만남
t = −31/81개(중근)1개접함
−4 ≤ t < −31/82개2개둘 다 진짜 ✅
t < −42개1개하나는 가짜 👻
그래프로 보는 요령 — 직선이 곡선의 시작점 (2, 0) 을 지나는 순간(t = −4)과 곡선에 접하는 순간(t = −31/8) 사이가 답입니다. 무리함수 문제에서는 판별식보다 이 두 경계를 그래프에서 직접 찾는 것이 안전합니다.

아래 ‘내 생각 적기’ 칸에 정리해 보세요.
(1) t = −5 에서 x = 2.25 가 가짜 해인 이유를 대입 결과로 설명하세요.
(2) 제곱이라는 조작이 무엇을 잃어버리게 하는지, 충분조건이라는 말을 써서 설명하세요.
(3) 올바른 범위 −4 ≤ t < −31/8 이 나오는 과정을 ‘시작점을 지날 때’와 ‘접할 때’로 나누어 쓰세요.

방정식을 변형할 때 해가 보존되려면 그 조작이 필요충분(⟺)이어야 합니다. 양변에 같은 수를 더하기·0이 아닌 수 곱하기는 ⟺ 이지만, 제곱은 ⟹ 한쪽 방향뿐입니다. Ⅱ단원의 명제가 방정식 풀이의 문법이었던 셈이죠.
