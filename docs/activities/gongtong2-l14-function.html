이 대응들은 어떻게 다를까?

네 가지 대응입니다. 상자를 눌러 관계를 살펴보세요.

B 와 C 는 어떻게 다른가?

B (화가 → 작품) — 짝이 하나씩 딱 맞아떨어집니다. 겹치는 것도 남는 것도 없어요. 거꾸로 돌려도 함수 입니다.

C (도시 → 국가) — 서울과 거제가 둘 다 한국 으로 갑니다. 여럿이 하나로 몰려도 함수는 함수 입니다. 또 호주 는 짝이 되는 도시가 없어요.

그래서 C 를 거꾸로 돌린 D 는 함수가 되지 못합니다. B 는 되는데 C 는 안 되는 까닭이 바로 이 차이예요.

‘출발 쪽에서 하나씩 나가면’ 함수입니다. 도착 쪽이 겹치거나 남는 것은 상관없습니다. 이 차이가 뒤에 일대일대응 과 역함수 로 이어집니다.

치역을 구해 보자

정의역이 함께 주어져 있습니다. 하나씩 눌러 치역을 확인해 보세요.

같은 함수는 어느 것과 어느 것일까?
C = D  그리고  E = F

C f(x) = |x| − 1 와 D g(x) = x² − 1 은 정의역 { −1, 0, 1 } 에서 x = −1 → 0, x = 0 → −1, x = 1 → 0 으로 모든 값이 같습니다.

E f(x) = |x| 와 F g(x) = x² 도 정의역 { 0, 1 } 에서 값이 같습니다.

두 함수의 정의역과 공역이 각각 같고,
정의역의 모든 원소 x 에 대하여 f(x) = g(x) 일 때 f = g

식이 달라도 정의역에서 값이 같으면 같은 함수입니다. 거꾸로 식이 같아도 정의역이 다르면 다른 함수예요.

일대일함수 — 정의역의 두 원소 x₁, x₂ 에 대하여

그대로 내보내기, 한 곳으로 몰기

항등함수 f : X → X 에서 ① 정의역과 공역이 같고 ② X 의 각 원소 x 에 그 자신 x 가 대응할 때. 즉 f(x) = x
상수함수 f : X → Y 에서 정의역의 모든 원소가 공역의 단 하나의 원소 c 에만 대응할 때. 즉 f(x) = c
항등함수는 일대일대응이라고 할 수 있을까?

네, 언제나 일대일대응입니다.

  • x₁ ≠ x₂ 이면 f(x₁) = x₁ ≠ x₂ = f(x₂) 이므로 일대일함수 ✓
  • 치역 = { x | x ∈ X } = X = 공역 이므로 공역 = 치역 ✓

상수함수의 치역은 { c } — 원소가 1개인 집합입니다. 정의역의 원소가 2개 이상이면 일대일함수가 될 수 없습니다.

로봇으로 돌아가 보면 — turn_left() 를 4번 한 것이 바로 항등함수 였습니다. 아무것도 바꾸지 않고 그대로 두니까요.

문제 풀어보기

1. 정의역이 { 1, 3 } 인 두 함수 f(x) = x² + a, g(x) = bx − 8 에 대하여 f = g 일 때 상수 a, b 의 값을 구하시오. (교과서 111쪽)

같은 함수는 정의역의 모든 원소에서 함숫값이 같아야 합니다.

f(1) = g(1) → 1 + a = b − 8
f(3) = g(3) → 9 + a = 3b − 8

아래 식에서 위 식을 빼면 8 = 2b → b = 4, 넣으면 1 + a = −4 → a = −5

a = −5, b = 4

확인: f(x) = x² − 5, g(x) = 4x − 8. f(1) = g(1) = −4, f(3) = g(3) = 4 ✓

두 실수 a, b 와 두 함수 f(x) = −x² − 2x + 1, g(x) = x² − 2x − 1 에 대하여

h(x) = f(x)  (x < a)   /   g(x + b)  (x ≥ a)

라 하자. 함수 h(x) 가 실수 전체의 집합에서 실수 전체의 집합으로의 일대일대응이 되도록 하는 a, b 의 모든 순서쌍 (a, b) 만을 원소로 하는 집합을 A 라 할 때, <보기>에서 옳은 것만을 있는 대로 고른 것은?

  • ㄱ. (0, k) ∈ A 를 만족시키는 실수 k 는 존재하지 않는다.
  • ㄴ. (−1, 4) ∈ A
  • ㄷ. 집합 { m + b | (m, b) ∈ A 이고 m 은 정수 } 의 모든 원소의 합은 5 + √3 이다.
어디서부터 볼까?
  • 실수 전체 → 실수 전체의 일대일대응이려면, 그래프가 끊기지 않고 계속 증가만 하거나 감소만 해야 합니다.
