대응이 ‘함수’가 되려면?

프로그래밍 명령어처럼 ‘하나의 입력 → 정확히 하나의 결과’. 집합 X 의 모든 원소에 대해 Y 의 원소가 오직 하나씩 대응할 때, 이 대응을 함수라 합니다. 버튼으로 확인하세요.

용어

정의역 · 공역 · 치역

함수 f : X → Y 에서
이름뜻
정의역 (X)입력이 되는 집합 (X 전체)
공역 (Y)출력이 담길 수 있는 집합 (Y 전체)
치역실제 대응된 출력들의 모임 = { f(x) | x∈X }  (공역의 부분집합)
f(x)x 에 대응하는 값 (함숫값)
치역 ⊂ 공역 입니다. 치역이 공역과 같아질 때(꽉 채울 때) 특별한 이름 ‘일대일대응’이 붙어요(다음 화면).
특별한 함수

일대일함수 · 일대일대응

버튼을 눌러 세 함수를 비교하세요. 일대일함수: 서로 다른 입력 → 서로 다른 출력. 일대일대응: 일대일함수 이면서 치역 = 공역(빠짐 없이 꽉 참).

특별한 함수 2

항등함수 · 상수함수

항등함수 f(x)=x: 자기 자신으로 대응 → 일대일대응!   상수함수 f(x)=c: 모든 입력이 한 값 c 로 → 치역은 {c} 하나뿐(일대일 아님).
정리

한눈에 정리

종류조건
함수X의 각 원소에 Y의 원소가 오직 하나 대응
일대일함수x₁≠x₂ → f(x₁)≠f(x₂) (서로 다른 입력 → 서로 다른 출력)
일대일대응일대일함수 + 치역 = 공역
항등함수f(x) = x (모든 x)
상수함수f(x) = c (모든 x, 일정)

아래 ‘내 생각 적기’ 칸에, 대응이 ‘함수’가 되는 조건을 쓰고, 일대일함수와 일대일대응의 차이를 대응 그림으로 설명해 보세요.

확장 탐구

🔭 더 넓게, 더 깊게

배운 것을 옆으로(다른 분야와 잇기) 그리고 아래로(더 근본적인 이유로) 넓혀 봅시다. 정답을 맞히는 시간이 아니라 생각을 키우는 시간이에요.

↔ 수평 확장 · 어디에 쓰일까

프로그래밍의 함수, 자판기(버튼 → 음료), 바코드(상품 → 번호)가 모두 함수입니다. 특히 일대일대응이어야 되돌릴 수 있어서, 암호·압축·주민번호 체계 설계에서 결정적으로 중요해요.

↕ 수직 확장 · 더 근본으로

함수는 ‘두 집합 사이의 특별한 대응’이고, 더 근본적으로는 관계의 특수한 경우입니다. 칸토어는 함수(일대일대응)를 이용해 무한집합의 크기를 비교했어요 — 자연수와 짝수는 크기가 같고, 실수는 더 크다는 놀라운 결론이 여기서 나옵니다.

🧗 도전 질문
자연수 전체 {1,2,3,…} 와 짝수 전체 {2,4,6,…} 사이에 일대일대응 f(n) = 2n 을 만들 수 있습니다. ‘부분이 전체와 크기가 같다’는 이 결과를 어떻게 받아들여야 할까요?
