# 공비 지도 칠하기 — rⁿ은 어디로 갈까

- summary: 수직선 위의 공비 r을 손으로 끌어 막대가 r배씩 늘고 줄고 뒤집히는 모습을 보고, 시험한 r마다 수직선에 결과를 칠해 등비수열 rⁿ의 수렴·발산 지도를 직접 완성한다.
- 높이: 660

## 핵심 아이디어 (왜 이 조작이 이 성취기준인가)
등비수열 rⁿ의 판정은 "r이 수직선의 어느 구간에 있느냐"로 정해진다: r>1 → ∞, r=1 → 1, |r|<1 → 0, r≤−1 → 진동.
학생은 공비 r 하나를 수직선 위에서 끌고, rⁿ이 '직전 막대에 r을 곱한 막대'로 하나씩 자라나는 모습(커짐/줄어듦/부호 뒤집힘)을 본다. 곱셈의 반복이 눈에 보이는 것이 이 활동의 핵심이며, 앞선 띠(calc2-01-01: ε·N 판정)·조립기(calc2-01-02: 극한의 성질) 활동과 달리 '공비라는 한 손잡이 → 구간별 판정'에 집중한다.
[칠하기]를 누를 때마다 그 r 자리에 판정 색 점이 수직선에 남고, 여러 번 시험하면 색 구간 경계(−1, 1)가 학생 손으로 드러난다. 2단계에서 a·rⁿ⁻¹ 꼴의 첫째항 a 를 바꿔 극한값(0 또는 a)을 구하는 데까지 확장한다.

2. 공비 수직선(무대 위쪽, 가로 전체): 범위 −2.0 ~ 2.0, 눈금 0.5 단위, −1·0·1 은 굵은 눈금. r 손잡이(큰 동그라미, 터치 영역 44px). 시험 기록 점이 이 수직선 바로 아래 줄에 쌓인다.
3. 막대 무대(캔버스, 가운데): 가로축 n = 1~20, 각 n 에 세로 막대 rⁿ(양수 위로 파랑, 음수 아래로 주황). 세로 범위 [−3, 3] 고정, 넘는 막대는 가장자리에서 잘리고 끝에 화살표와 실제 값 숫자. y=0 기준선, 극한값이 있으면 y=극한값 점선(초록).

4. 판정 상자(무대 오른쪽 위): "r = 0.80 → |r| < 1 → 0 으로 수렴" 한 줄, 아래에 a₂₀ 값(유효숫자 4자리).

## 조작과 반응
- r 손잡이를 끌면 → 20개 막대가 즉시 rⁿ으로 다시 그려지고 판정 상자·식이 바뀐다. r은 0.01 단위, −1·0·1·±0.5·±2 근처(±0.03)에서 그 값에 붙는다(자석). 수직선 탭 = 그 자리로 이동. 좌우 미세 조정 버튼 [−0.01][+0.01] 도 둔다(정확히 r=±1 을 만들기 쉽게).
- [이 r 칠하기] → 수직선 아래에 색 점: 초록(0으로 수렴), 파랑(1로 수렴, r=1), 빨강(양의 무한대로 발산), 보라(진동). 같은 r(0.01 단위)은 한 번만 기록. 점이 8개 이상이고 다섯 종류 구간(r<−1, r=−1, −1<r<1, r=1, r>1) 중 4개 이상을 칠하면 힌트가 "경계는 어디인가요?"로 바뀐다.
- [지도 지우기] → 기록 점 삭제.
- r 이 0.95~0.99 또는 1.01~1.05 처럼 1에 가까우면 → n=20 까지 막대 변화가 작아 보인다는 힌트를 띄운다(유한 화면의 한계).
- ② 탭: a 손잡이(세로 작은 다이얼, −3~3, 0.5 단위) 추가. 수열은 aₙ = a·rⁿ⁻¹ (n=1 막대가 a). 극한값 점선과 판정 상자가 "a·rⁿ⁻¹ → 0" / "r=1 이므로 → a" / "a=0 이므로 모든 항 0 → 0" 으로 바뀐다. 수직선 칠하기는 ②에서도 동작하되 a≠0 기준 판정 색을 쓴다.
- [처음으로] → r=0.5, a=1, ① 탭, 지도 유지.

## 수학 계산 규칙
- ①: aₙ = rⁿ, n = 1~20, r ∈ [−2, 2] (0.01 단위로 반올림한 값으로 계산·판정; 부동소수 비교는 반올림된 정수 100r 로 한다).
  - r > 1: 양의 무한대로 발산 / r = 1: 1 로 수렴 / −1 < r < 1: 0 으로 수렴 (r=0 이면 모든 항 0) / r = −1: 진동(−1, 1 반복, 발산) / r < −1: 진동하며 절댓값이 한없이 커짐(발산, 극한 없음).
- ②: aₙ = a·rⁿ⁻¹. a = 0 → 0 으로 수렴(r 무관). a ≠ 0 이면 위 판정과 같고, 극한값은 |r|<1 → 0, r=1 → a. r ≤ −1 또는 r > 1 → 발산(r>1 이면 a>0 이면 양의 무한대, a<0 이면 음의 무한대).
- 0⁰ 문제 없음: ①은 n≥1, ②는 n=1 에서 r⁰=1 로 둔다(r=0 이어도 a₁=a).
- 표시: |값| > 3 막대는 잘림 + 숫자. 2²⁰ ≈ 1.05×10⁶ 까지이므로 숫자는 지수 표기 허용.
- 판정 문구에서 '수렴'은 극한값을 반드시 함께 적는다.

## 안내 문구와 탐구 질문
힌트:
- 시작: "공비 r을 끌어 보세요. 막대 하나하나가 앞 막대에 r을 곱한 것이에요."
- r 이 0과 1 사이: "곱할수록 막대가 줄어들어요. 어디까지 줄어들까요?"
- r 이 음수: "음수를 곱하면 막대가 위아래로 뒤집혀요. 뒤집히면서 줄어드나요, 커지나요?"
- 1 근처: "1에 아주 가까우면 20번 곱해도 변화가 작아 보여요. 화면이 짧을 뿐, n이 더 커지면 어떻게 될지 생각해 보세요."
- 칠하기 많이 했을 때: "지도의 색이 바뀌는 경계는 어디인가요? r = 1 과 r = −1 에서는 각각 어떤 색인가요?"
- ② 탭: "이번엔 첫째항 a를 바꿔 보세요. 극한값은 a와 r 중 무엇에 따라 달라지나요?"

탐구 질문:
1. r = 0.5, −0.5, 0.9, −0.9 를 칠해 보세요. 모두 같은 색인 까닭을 '곱할수록 크기가 어떻게 되는지'로 설명해 보세요.
2. r = 1 과 r = −1 은 둘 다 |r| = 1 인데 판정이 다릅니다. 막대 모양을 보고 이유를 말해 보세요.
3. 지도를 완성해 등비수열 rⁿ 이 수렴하는 r 의 범위를 부등식으로 써 보세요. (−1 < r ≤ 1)
4. ② 에서 aₙ = 3·(1/2)ⁿ⁻¹ 과 aₙ = 3·1ⁿ⁻¹ 의 극한값은 각각 얼마인가요? a·rⁿ⁻¹ 이 수렴하는 조건을 a 와 r 로 말해 보세요. (a = 0 또는 −1 < r ≤ 1)

## 제작 난이도 판단
쉬움~보통 — 계산은 rⁿ 20개뿐이고 손잡이는 r(②에서 a 추가) 하나라 단순하지만, 수직선 기록 점·자석·탭 2개 상태 관리와 좁은 화면 배치에 약간 손이 간다.

## 점검 포인트
1. 판정 구간: r>1 양의 무한대, r=1 → 1, −1<r<1 → 0, r=−1 진동, r<−1 진동(발산)이 경계값 ±1 에서 정확한지(0.01 반올림 후 정수 비교).
2. 수렴 범위가 −1 < r ≤ 1 이고 극한값이 0(|r|<1) 또는 1(r=1)인지.
3. ② a·rⁿ⁻¹: a=0 이면 r 과 무관하게 0, r=1 이면 a, |r|<1 이면 0. 수렴 조건 "a=0 또는 −1<r≤1".
4. r<−1 을 '음의 무한대로 발산'이라고 쓰지 않는지(진동 발산).
5. '화면은 n=20까지의 유한한 항' 문구가 실제로 있는지.
