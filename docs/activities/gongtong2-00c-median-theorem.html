📐 정말 항상 같을까?

삼각형 ABC 에서 변 BC 의 중점을 M 이라 할 때, 다음이 언제나 성립한다고 합니다.

AB² + AC² = 2(AM² + BM²)

세 꼭짓점을 마음대로 드래그해 보세요. 어떤 삼각형으로 만들어도 두 막대의 길이가 같은가요?

AB² + AC²
2(AM² + BM²)

아무리 찌그러뜨려도 두 값이 같습니다. 그런데 왜 그럴까요? 중학교식(논증 기하)으로 증명하려면 꽤 복잡합니다. 좌표를 쓰면 어떻게 될까요?

좌표를 어디에 놓느냐가 전부다

앞 활동에서 배웠듯 좌표는 우리가 정하는 것이고, 어떻게 잡아도 거리는 변하지 않습니다. 그렇다면 계산이 가장 쉬워지는 자리에 놓으면 되겠죠. 세 가지 배치를 비교해 보세요.

③ 처럼 놓으면 B(−c, 0), C(c, 0), M(0, 0) 이 되어 부호가 딱 맞아떨어집니다. 학습지에서 “직선 BC 를 x축, 점 M 을 원점” 으로 잡으라고 한 이유예요.
증명
학습지 1-01 · 교과서 14p 빈칸 채우기

세 줄이면 끝난다

B(−c, 0), C(c, 0), M(0, 0), A(a, b) 로 놓습니다. 한 단계씩 스스로 해 본 뒤 열어 보세요.

1단계 — 왼쪽 AB² + AC² 을 a, b, c 로 나타내기

AB² = (a − (−c))² + b² = (a + c)² + b²
AC² = (a − c)² + b²
더하면 (a² + 2ac + c²) + (a² − 2ac + c²) + 2b² = 2a² + 2b² + 2c²  — 2ac 가 서로 지워집니다!

2단계 — 오른쪽 2(AM² + BM²) 을 a, b, c 로 나타내기

AM² = (a − 0)² + (b − 0)² = a² + b²
BM² = (−c − 0)² + 0² = c²
2(AM² + BM²) = 2a² + 2b² + 2c²

3단계 — 두 결과를 비교하기
2a² + 2b² + 2c²  =  2a² + 2b² + 2c²   ∎

양쪽이 완전히 같은 식이 되었습니다. 증명 끝!

위 화면의 삼각형을 다시 움직여 보면, a·b·c 값이 바뀌어도 두 식은 늘 같은 모양임을 확인할 수 있어요.

왜 교과서에 실렸을까

이 문제의 진짜 주인공

중학교 방식(논증 기하)이라면?
보조선을 긋고, 합동·닮음을 찾고, 피타고라스를 여러 번 적용해야 합니다. 게다가 예각·둔각·직각 삼각형을 경우를 나눠 다뤄야 하죠.
좌표를 쓰면?
경우를 나눌 필요가 전혀 없습니다. a, b, c 가 양수든 음수든 식은 그대로 성립하니까요. 게다가 계산 세 줄이면 끝납니다.
이 단원 전체의 메시지 — 좌표의 도입은 “계산을 조금 편하게”가 아니라 기하 문제를 대수 문제로 완전히 바꿔 버리는 패러다임의 전환이었습니다. 원점을 잘 고르면 계산이 극적으로 단순해진다는 것도 함께 배웠고요.

아래 ‘내 생각 적기’ 칸에 정리해 보세요.
(1) B(−c, 0), C(c, 0) 으로 놓았을 때 계산이 쉬워진 결정적인 이유는 무엇인가요? (힌트: 어떤 항이 지워졌나요?)
(2) 만약 B(0, 0), C(2c, 0) 으로 놓았다면 어떻게 되는지 직접 계산해 비교해 보세요.
(3) 이 정리가 실제로 어디에 쓰일지 하나만 찾아 적어 보세요.

↔ 수평 확장 · 어디에 쓰일까

여러 번 측정한 위치의 평균과 흩어짐을 다룰 때 이 식이 그대로 나타납니다. 로봇이 같은 지점을 여러 번 짚어 오차를 줄일 때, 물리에서 물체의 관성모멘트를 무게중심 기준으로 바꿔 계산할 때(평행축 정리)도 똑같은 구조예요.

↕ 수직 확장 · 더 근본으로

이 정리는 사실 평행사변형 법칙과 같은 말입니다. BC 를 대각선으로 하는 평행사변형을 그리면 “두 대각선 제곱의 합 = 네 변 제곱의 합”이 되죠. 이 성질은 벡터의 길이를 다루는 모든 공간에서 성립합니다.
