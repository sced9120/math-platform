🙋 우리 반을 나눠 보자

아래 기준으로 우리 반 학생을 나누려고 합니다. 모임이 분명하게 정해지는 것과 사람마다 답이 갈리는 것을 구분해 보세요. 기준마다 버튼을 눌러 판단합니다.

　기준분명 / 애매
애매한 기준을 고쳐 봅시다

‘애매하다’고 답한 기준은 말을 바꾸면 분명해집니다. 어떻게 고칠 수 있을까요?

  • 키가 큰 학생 → 키가 170 cm 이상인 학생  기준값을 정해 준다
  • 노래를 잘하는 학생 → 교내 가창 평가 90점 이상인 학생  잴 수 있는 것으로 바꾼다

공통점은 “누가 판단해도 답이 같아지도록” 만들었다는 것입니다.

그렇다면 — 어떤 모임이 ‘집합’이 되기 위해 꼭 필요한 것은 무엇일까요? 아래 기록칸에 한 문장으로 적어 보세요.

집합이란 무엇인가

어떤 기준에 따라 대상을 분명하게 정할 수 있는 모임 → 집합

‘분명하게’ 가 핵심입니다. 누가 판단해도 답이 같아야 집합입니다.

용어뜻
집합대상을 분명하게 정할 수 있는 모임
원소집합을 이루는 하나하나의 대상
a ∈ Aa 는 집합 A 의 원소이다  a 는 A 에 속한다
b ∉ Bb 는 집합 B 의 원소가 아니다
유한집합원소가 유한개인 집합  예) {1, 2, 5, 10}
무한집합원소가 무수히 많은 집합  예) 자연수 전체의 집합
공집합 ∅원소가 하나도 없는 집합. n(∅) = 0
n(A)유한집합 A 의 원소의 개수
주의 — ∅ 와 {∅} 는 다릅니다. ∅ 는 빈 상자, {∅} 는 빈 상자가 하나 들어 있는 상자. 그래서 n(∅) = 0, n({∅}) = 1 입니다.

이 모임은 집합일까?

다음 중 집합인 것을 모두 찾고, 집합인 것은 원소를 모두 써 봅시다. 각 줄에서 집합 / 집합 아님을 눌러 판단하세요.

　모임집합인가?
원소까지 확인하기
모임집합?원소
(1) 20보다 작은 소수의 모임○2, 3, 5, 7, 11, 13, 17, 19
(2) 우리나라의 큰 강의 모임×‘큰’ 의 기준이 없다
(3) 12의 약수의 모임○1, 2, 3, 4, 6, 12
(4) √2 에 가까운 유리수의 모임×‘가깝다’ 의 기준이 없다

(2)·(4) 도 기준을 정해 주면 집합이 됩니다. 예) 길이가 400 km 이상인 강 / |x − √2| < 0.01 인 유리수 x.

원소의 개수
✍️ 학생이 직접 푸는 화면📄 학습지 4-01 Q2 원소의 개수 n(A)

n(A) 를 구해 보자

다음 집합의 원소의 개수 n(A) 를 구하시오. 먼저 스스로 세어 본 뒤 열어 확인하세요.

집합n(A)이유
A = { x | x 는 24의 약수 } 1, 2, 3, 4, 6, 8, 12, 24
A = { x | x2 + 1 = 0 인 실수 } 실수 범위에서 해가 없다 → A = ∅
A = { ∅ } 원소가 ∅ 하나 들어 있다
A = { x | x 는 100 이하의 5의 배수 } 5 × 1 부터 5 × 20 까지
두 번째와 세 번째를 나란히 보세요. ∅ 는 원소가 0개, { ∅ } 는 원소가 1개입니다. 이 차이가 시험에 자주 나옵니다.
탐구 · 부분집합
🖥 보여주며 조작📄 학습지 4-01 ■[탐구] 전체집합의 일부분, 부분집합

🔴 당신은 포켓몬 트레이너!

오박사 센터 U(전체집합) = { 피카츄, 파이리, 꼬부기, 이상해씨 }. 기호로는 피카츄 = a, 파이리 = b, 꼬부기 = c, 이상해씨 = d 입니다.

[부분집합] 함께할 포켓몬을 원하는 만큼 선택하세요. 선택하지 않아도 됩니다. 몇 가지 조합이 나올까요?
찾은 조합 0 / 16
[진부분집합] 이번에는 오박사 센터에 적어도 한 마리를 남기고 출발하는 멤버를 꾸려 봅시다.

넷을 모두 데려가는 조합만 빼면 됩니다. 그래서 16 − 1 = 15 가지. 이렇게 자기 자신을 뺀 부분집합을 진부분집합이라 합니다.

📖교과서 68쪽 — 부분집합 · 서로 같은 집합 · 진부분집합. ⊂ 와 ∈ 의 차이를 꼭 짚습니다.

부분집합 · 서로 같은 집합 · 진부분집합

용어뜻
부분집합
A ⊂ B		 A 의 모든 원소가 B 에 속한다. ∅ 과 자기 자신도 항상 부분집합이다.
서로 같은 집합
A = B		 A ⊂ B 이고 B ⊂ A. 원소가 완전히 같다.
진부분집합 A ⊂ B 이면서 A ≠ B. 자기 자신은 뺀다.
⊂ 와 ∈ 은 무엇이 다를까?

A = { 1, 2, 3 } 일 때

  • 1 ∈ A — 1 은 원소다. 원소와 집합 사이의 기호가 ∈.
  • { 1 } ⊂ A — { 1 } 은 집합이다. 집합과 집합 사이의 기호가 ⊂.
  • 1 ⊂ A (×), { 1 } ∈ A (×) — 둘 다 잘못된 표기.

왼쪽이 낱개면 ∈, 왼쪽이 묶음이면 ⊂ 이라고 기억하세요.

∅ ⊂ A 는 항상 참입니다. “∅ 의 모든 원소가 A 에 속한다” 인데, ∅ 에는 원소가 하나도 없으므로 어길 원소 자체가 없기 때문입니다.

원소마다 넣는다(○) / 안 넣는다(×) 두 갈래로 갈립니다. 표의 ○ × 를 눌러 바꿔 가며 8가지를 모두 만들어 보세요.

A = { 1, 2, 3, 4, 5 } 일 때

다음을 구하고, 구한 방법을 함께 적어 봅시다. 스스로 세어 본 뒤 열어 확인하세요.

구하는 것개수생각하는 방법
부분집합의 개수 원소 5개가 각각 ○ × 두 갈래 → 25
진부분집합의 개수 자기 자신 하나를 뺀다 → 25 − 1
3 을 반드시 포함하는 부분집합 3 은 넣기로 고정. 나머지 4개만 갈린다 → 24
1 을 포함하지 않는 부분집합 1 은 빼기로 고정. 나머지 4개만 갈린다 → 24
고정하면 갈림길이 줄어든다 — 이것이 개수 문제의 핵심입니다. “반드시 포함”이든 “포함하지 않음”이든, 그 원소는 갈리지 않으므로 지수에서 빠집니다.

🖥 보여주며 조작📄 학습지 4-01 Q6 원소가 n 개일 때

원소가 n 개라면?

원소마다 넣는다 / 안 넣는다 두 갈래. 원소가 n 개면 갈림길이 n 번이므로 2 를 n 번 곱한 만큼입니다.

부분집합의 개수 = 2n   /   진부분집합의 개수 = 2n − 1
왜 −1 일까?

진부분집합은 자기 자신을 뺀 부분집합이므로, 모든 원소를 다 넣은 경우 딱 하나만 제외합니다. 그래서 −1 입니다. ∅ 은 진부분집합에 그대로 포함됩니다 (A 가 공집합이 아닐 때).
