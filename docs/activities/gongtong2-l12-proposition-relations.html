🎟 약속을 어긴 것은 언제일까?

A가 B에게 이렇게 약속했습니다.

“내가 로또 1등에 당첨된다면, 너한테 2억원을 줄게.”

이 명제를 두 개의 조건으로 나누어 이름을 붙여 봅시다.

p : 로또 1등에 당첨된다   /   q : B에게 2억원을 준다

다음 세 상황 중 A가 약속을 어긴 경우를 찾아 보세요.

가정이 거짓이면?

p → q 는 언제 거짓일까?

앞의 세 상황을 표로 정리해 봅시다. 줄을 눌러 확인하세요.

pqp → q로또 약속에서는
명제 p → q 는 p 가 참인데 q 가 거짓일 때 오직 그때만 거짓이다.
가정이 거짓이면 왜 참일까?

당첨이 되지 않았다면 약속은 아직 시험대에 오르지 않은 것입니다. 어기지 않았으니 약속은 그대로 유효합니다. 수학에서도 마찬가지로, 가정이 거짓이면 그 명제는 참으로 봅니다.

거꾸로 말하면 — 가정이 거짓인 논증은 결론에 대해 아무것도 보장하지 못합니다.

📖교과서 84쪽 — ‘p이면 q이다’ 의 가정과 결론을 함께 짚습니다.

가정과 결론

두 조건 p, q 로 이루어진 명제 ‘p 이면 q 이다’ 를 기호로 p → q 라 쓰고, p 를 가정, q 를 결론이라고 합니다.

x = 2 이면 x² = 4 이다
↑ 가정 p         ↑ 결론 q

다음 네 문장에서 가정과 결론을 찾아봅시다. 문장을 눌러 확인하세요.

주의 — (4)처럼 ‘~하면 ~이다’ 가 아니라 ‘~할 때’, ‘~인 경우’ 로 쓰인 문장도 있습니다. 조건 두 개로 갈라 보는 것이 먼저입니다.

🖥 보여주며 조작📄 학습지 5 · 2-02 명제 ①② 의 논리적 흐름

‘모조리’ 들어가는가?

세 조건을 놓고 봅시다. p : x 는 4의 약수  /  q : x 는 8의 약수  /  r : x 는 6의 약수

논리적 흐름 — 이렇게 따집니다
  • (1) 가정 p 에서 x 가 될 수 있는 값은 1, 2, 4. 이 값들이 모조리 결론을 만족하는가?
  • (2) 진리집합을 써 본다. P = {1, 2, 4}, Q = {1, 2, 4, 8}, R = {1, 2, 3, 6}
  • (3) P ⊂ Q 이므로 p → q 는 참. P ⊄ R 이므로 p → r 은 거짓.
반례 — p → r 이 거짓임을 보이려면 가정은 만족하지만 결론은 만족하지 않는 예를 하나만 찾으면 됩니다. 여기서는 x = 4 — 4의 약수이지만 6의 약수는 아닙니다.

P ⊂ Q ⟺ p → q 는 참

진리집합명제 p → q
P ⊂ Q참 — p 가 참이 되는 모든 경우에 q 도 참
P ⊄ Q거짓 — p 는 참이지만 q 는 거짓인 원소가 있다 (반례)
예시 — 명제 ‘x = −1 이면 x² = 1 이다’ 에서 p : x = −1, q : x² = 1 이므로 P = {−1}, Q = {1, −1}. P ⊂ Q 이므로 이 명제는 참입니다.

연결 문제
✍️ 학생이 직접 푸는 화면📄 학습지 5 · 2-02 [연결 문제] 참이 되는 명제를 만들려면?

참이 되게 하려면 — 수직선으로

세 조건 p : −2 < x ≤ 1,  q : x > a,  r : | x − b | < 4 에 대하여 두 명제 p → ~q, p → r 가 모두 참이 되도록 하는 상수 a, b 의 값의 범위를 구하시오.
풀이

P = { x | −2 < x ≤ 1 }

p → ~q 가 참 ⟺ P ⊂ (~Q). ~q : x ≤ a 이므로 P 의 오른쪽 끝 1까지 덮으려면 a ≥ 1

p → r 이 참 ⟺ P ⊂ R. r : b − 4 < x < b + 4 이므로
  왼쪽 : b − 4 ≤ −2 → b ≤ 2
  오른쪽 : 1 < b + 4 → b > −3

a ≥ 1  ,  −3 < b ≤ 2

끝점에서 등호가 되는지 아닌지를 꼭 따져 보세요. P 의 왼쪽 끝 −2 는 P 에 포함되지 않으므로 b − 4 = −2 라도 괜찮습니다.

역 : q → p   (가정과 결론을 바꾼다)

원래   p → q
역      q → p
이      ~p → ~q
대우   ~q → ~p

대우는 ‘역’ 과 ‘이’ 를 둘 다 거친 것입니다.

🃏 어느 카드를 뒤집어야 할까?

한 면에는 숫자가, 다른 면에는 알파벳이 적힌 카드 네 장이 놓여 있습니다.

명제 : “카드의 한 면에 알파벳 자음이 적혀 있으면, 다른 쪽 면에는 짝수가 적혀 있다.”

이 명제가 참인지 확인하기 위해 반드시 뒤집어 보아야 하는 카드를 모두 고르세요.

대우로 보면 한눈에

p : 자음이다  /  q : 짝수이다  →  확인할 명제는 p → q

K (자음) — p 가 참. 뒷면이 홀수이면 명제가 무너집니다. 뒤집어야 함

7 (홀수) — ~q 가 참. 대우 ~q → ~p 를 확인하는 자리입니다. 뒷면이 자음이면 명제가 무너집니다. 뒤집어야 함

A (모음) — p 가 거짓. 가정이 거짓이면 명제는 참이므로 볼 필요가 없습니다.

4 (짝수) — q 가 참. 뒷면이 무엇이든 명제는 무너지지 않습니다. 이 카드를 뒤집는 것은 역 q → p 를 확인하는 일이지, 원래 명제가 아닙니다.

충분조건 · 필요조건 · 필요충분조건

명제 p → q 가 참일 때 이를 p ⇒ q 로 쓰고, 이때

p 는 q 이기 위한 충분조건
q 는 p 이기 위한 필요조건
진리집합p 는 q 이기 위한
P ⊂ Q충분조건  p ⇒ q
Q ⊂ P필요조건  q ⇒ p
P = Q필요충분조건  p ⇔ q
왜 ‘필요’ 라고 부를까?

P ⊂ Q 일 때, Q 안에 들어가는 것은 P 에 들어가기 위해 반드시 먼저 통과해야 하는 관문입니다. 하지만 그것만으로는 모자라죠 — 그래서 필요하지만 충분하지는 않습니다.

앞 화면으로 돌아가 보세요. A 합격은 B 합격이기 위한 충분조건, B 합격은 A 합격이기 위한 필요조건이었습니다.

🔗 삼단논법 — 조건을 사슬로 잇기

(전제 1) 고래는 포유류이다.    (전제 2) 포유류는 동물이다.
(결론) 따라서 고래는 동물이다.

두 전제가 참이면 삼단논법의 결론은 항상 참입니다.

세 조건 p, q, r 에 대하여 p 는 r 이기 위한 충분조건, q 는 r 이기 위한 필요조건 일 때, 다음 중 참인 것을 모두 찾아보세요.

주어진 것
p ⇒ r  →  P ⊂ R
r ⇒ q  →  R ⊂ Q
집합으로 바꾸어 보기 (교과서 91쪽 2번)

두 집합 A, B 에 대하여 조건 p : A ∩ B = A, q : A ∪ B = B 일 때 p 는 q 이기 위한 무슨 조건일까요?

A ∩ B = A ⟺ A ⊂ B 이고, A ∪ B = B ⟺ A ⊂ B 입니다. 두 조건이 같은 말이므로 필요충분조건입니다.

집합 단원에서 배운 것이 그대로 쓰입니다. 벤 다이어그램을 그려 A 가 B 안에 쏙 들어간 모습을 떠올려 보세요.
