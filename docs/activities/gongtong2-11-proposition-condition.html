명제란?

명제 = 참인지 거짓인지 명확하게 판별할 수 있는 문장이나 식. 의견·주관·모호한 문장은 명제가 아닙니다.

“지평선이 직선이니 지구는 평평하다” 같은 궤변에 속지 않으려면, 문장이 참·거짓을 가릴 수 있는지(=명제인지) 따지는 힘이 필요합니다. 아래에서 연습해 보세요.
조건과 진리집합

조건 → 진리집합

문자를 포함해 참·거짓이 정해지지 않은 문장을 조건이라 합니다. 전체집합 U 에서 그 조건을 참이 되게 하는 원소들의 집합을 진리집합 P 라 해요. 버튼을 눌러 진리집합을 확인하세요.

U = {1, 2, …, 10}

그리고 · 또는

‘그리고’ = ∩, ‘또는’ = ∪

조건 p: x 는 짝수, 조건 q: x ≤ 5. 두 조건을 ‘그리고/또는’으로 이으면 진리집합은 교집합·합집합이 됩니다.

‘그리고’는 두 조건을 모두 만족 → 교집합. ‘또는’은 적어도 하나 만족 → 합집합. 조건의 부정 ~p 의 진리집합은 여집합 Pᶜ. (명제·조건이 집합과 똑같이 움직입니다!)
모든 · 어떤

‘모든’과 ‘어떤’

명제뜻참/거짓
모든 실수 x, x² ≥ 0전부 만족참
모든 실수 x, x² = 4전부 만족?거짓 (x=3은 아님)
어떤 실수 x, x² = 4하나라도 만족참 (x=2)
어떤 실수 x, x²+3 ≤ 0하나라도 만족?거짓 (항상 >0)
‘모든(전칭)’은 진리집합이 전체집합 U 와 같아야 참. ‘어떤(존재)’은 진리집합이 공집합이 아니면 참. (반례가 하나라도 있으면 ‘모든’ 명제는 거짓!)
부정

‘모든’을 부정하면?

‘모든 x 에 대하여 p(x)’ 의 부정  →  ‘어떤 x 에 대하여 ~p(x)’
‘어떤 x 에 대하여 p(x)’ 의 부정  →  ‘모든 x 에 대하여 ~p(x)’

예) ‘우리 반의 모든 학생은 걸어서 등교한다’ 의 부정은?
→ ‘우리 반의 어떤 학생은 걸어서 등교하지 않는다’ (즉, 걸어서 안 오는 학생이 한 명이라도 있다).

‘모든 학생이 안 걸어온다’ 가 아닙니다! ‘모든’의 부정은 ‘전부 아니다’가 아니라 ‘하나라도 아니다(반례가 있다)’ 입니다. and ↔ or 처럼 뒤집힌다고 기억하세요(드모르간과 닮은꼴).
정리

정리

  • 명제 = 참·거짓 판별 가능한 문장/식
  • 조건 → 진리집합 P,   ~p ↔ Pᶜ,   ‘그리고’ ↔ ∩,   ‘또는’ ↔ ∪
  • ‘모든’ 참 ⟺ P=U,   ‘어떤’ 참 ⟺ P≠∅
  • 부정: 모든 ↔ 어떤,   p ↔ ~p

아래 ‘내 생각 적기’ 칸에, (1) 무엇이 명제인지, (2) 조건 p, q 의 진리집합 P, Q 로 ‘그리고/또는/부정’이 각각 어떤 집합연산이 되는지 정리해 보세요.

확장 탐구

🔭 더 넓게, 더 깊게

배운 것을 옆으로(다른 분야와 잇기) 그리고 아래로(더 근본적인 이유로) 넓혀 봅시다. 정답을 맞히는 시간이 아니라 생각을 키우는 시간이에요.

↔ 수평 확장 · 어디에 쓰일까

프로그램의 if 조건, 계약서의 ‘~인 경우에 한하여’, 법률 조항이 모두 명제와 조건입니다. 조건을 잘못 쓰면 프로그램에 버그가 생기고 계약에 분쟁이 생기죠.

↕ 수직 확장 · 더 근본으로

‘모든’과 ‘어떤’은 기호로 ∀, ∃ 라 쓰고, 이것을 다루는 논리를 술어논리라 합니다. 조건 p 에 진리집합 P 를 대응시키는 순간 논리 문제가 집합 문제로 번역되는데, 이 다리가 수학 전체를 지탱합니다.
