갈릴레이의 사고 실험

옛사람들은 “무거운 물체가 더 빨리 떨어진다”고 믿었어요. 갈릴레이는 이렇게 생각했죠.

“무거운 물체가 더 빨리 떨어진다면, 무거운 것과 가벼운 것을 묶어서 떨어뜨리면? 가벼운 게 느리게 끌어 전체는 느려져야 하고, 무거운 게 포함됐으니 전체는 더 빨라져야 한다. 한꺼번에 더 느려지고 더 빨라질 수는 없잖아?”

이렇게 모순이 생기니 원래 믿음이 틀렸다는 걸 알 수 있죠. 그래서 👉 “무거운 물체와 가벼운 물체는 동시에 떨어진다!”

가설(명제)이 참임을 논리적 근거로 밝히는 것이 증명입니다. 갈릴레이가 쓴 방법이 바로 ‘틀렸다고 가정하니 모순’ → 귀류법의 원형이에요.

연역법

두 홀수의 합은 짝수

슬라이더로 두 홀수를 바꿔 보세요. 항상 합이 짝수임을, 대수(문자)로 증명합니다.

(2m+1) + (2n+1) = 2m + 2n + 2 = 2(m + n + 1) → 2의 배수 = 짝수. ∎
귀류법

√2 는 무리수이다

“√2 가 유리수다”라고 거짓 가정을 하면 모순이 생깁니다.

  1. √2 = q/p (p, q 는 서로소인 자연수) 라고 가정한다.
  2. 양변 제곱: 2 = q²/p² → q² = 2p² → q² 은 짝수 → q 도 짝수 (q = 2k).
  3. 대입: (2k)² = 2p² → 4k² = 2p² → p² = 2k² → p² 짝수 → p 도 짝수.
  4. 그런데 p, q 가 둘 다 짝수면 서로소라는 가정에 모순!
  5. 따라서 가정이 틀렸고, √2 는 무리수이다. ∎
귀류법의 힘: 직접 보이기 어려운 ‘무리수임(=유리수로 못 씀)’을, 유리수라고 가정 → 모순으로 깔끔하게 증명합니다.
절대부등식

산술평균 ≥ 기하평균

항상 성립하는 부등식을 절대부등식이라 합니다(예: a² ≥ 0). 대표적으로 양수 a, b 에 대해 산술평균 ≥ 기하평균 이 성립해요. 슬라이더로 확인하세요.

증명: (√a − √b)² ≥ 0 → a − 2√(ab) + b ≥ 0 → (a+b)/2 ≥ √(ab). 등호는 a = b 일 때만 성립!
정리 · 역설

정리, 그리고 러셀의 이발사

  • 증명 방법: 연역법 / 대우 이용 / 귀류법
  • 절대부등식: a²≥0, (a+b)/2 ≥ √(ab) (등호 a=b)

역설 — 자기 모순에 빠지는 문장. “크레타인은 모두 거짓말쟁이”(크레타인이 한 말), 그리고 러셀의 이발사 역설: “스스로 수염을 안 깎는 사람만 깎아주는 이발사”는 자기 수염을 깎아야 할까? 깎으면 규칙 위반, 안 깎으면 규칙상 깎아야 함 → 모순!

이 역설은 “아무 집합이나 만들 수 있다”는 순진한 믿음을 무너뜨렸고, 수학자들이 공리적 집합론으로 집합을 더 엄격히 정의하게 만들었습니다. 논리와 증명이 수학의 토대를 지킨 사건이죠.
