# 닮은 꼴 접어 넣기 — 전체 안에 전체가 들어 있다
- id / 과목 / 단원 / 성취기준: calc2-01-05 / 미적분Ⅱ / 수열의 극한 / [12미적Ⅱ-01-05] 등비급수의 합을 구하고, 이를 활용할 수 있다.
- slug: calc2-geometric-self-similar
- topic: 미적분Ⅱ · 수열의 극한
- summary: 첫 조각 a 옆에 '전체 그림을 r배로 줄인 복사본'을 끌어다 끼워 넣으며, 등비급수의 합 S가 S = a + rS 를 만족한다는 것을 눈으로 확인하고 S = a/(1−r) 를 이끌어 낸 뒤 순환소수·튀는 공 문제에 활용한다.
- 높이: 660

## 핵심 아이디어 (왜 이 조작이 이 성취기준인가)
등비급수 a + ar + ar² + … 의 합 공식은 "전체(S)에서 첫 항을 떼면, 남은 것은 전체를 r배 한 것(rS)"이라는 자기닮음에서 나온다.
학생은 길이 a 인 첫 띠 조각 오른쪽에 **'지금까지 만든 전체 그림'의 r배 축소 복사본을 직접 끌어다 끼우는** 조작을 반복한다. 끼울 때마다 그림은 a, a+ar, a+ar+ar², … 로 자라고, 끼운 복사본이 원래 그림과 꼭 닮았음이 겹쳐 보인다.
01-04(막대를 한 개씩 이어 붙여 Sₙ 관찰)와 달리 여기서는 항 하나가 아니라 **전체 그림을 통째로 축소·복사**한다. 01-03(rⁿ 지도)과 달리 판정이 아니라 합의 값을 구하는 식 S = a + rS 를 조작에서 얻는 것이 목표다.
마지막 '활용' 탭에서 같은 조작으로 0.2727…(= 27/100 + 그 1/100배 복사), 튀는 공의 총 이동거리를 푼다.

## 화면 구성
1. 상단: 탭 두 개 [합 공식 만들기] [활용하기] + [처음으로]. 오른쪽에 현재 식 "S = a + ar + ar² + …  (a = 1, r = 0.5)".
2. 설정 줄: 첫 조각 길이 a 손잡이(0.5~2, 0.1 단위), 축소 비율 r 손잡이(−0.8~0.9, 0.05 단위, 기본 0.5). 숫자 직접 탭 입력 가능.
   - r 은 '줄자 다이얼'(반원 눈금 위 바늘)을 돌려서 정한다. r < 0 이면 복사본이 좌우로 뒤집혀 끼워진다는 표시.
3. 작업대(가운데 큰 캔버스):
   - 위 줄 '현재 그림': 0에서 시작하는 가로 띠. 첫 조각 a(파랑) + 지금까지 끼운 조각들(색이 차례로 옅어짐). 아래에 0~(a/(1−r) 근처) 자 눈금.
   - 아래 줄 '복사본 대기칸': 현재 그림 전체를 r배로 줄인 회색 복사본. 손잡이(⇕ 아이콘, 48px)를 잡고 위 줄 첫 조각 오른쪽 끝(초록 점선 '꽂는 자리')으로 끌어 놓는다.
   - 끼우고 나면 1초 동안 "첫 조각 + (전체 × r)" 이라는 괄호 표시가 띠 위에 뜬다.
4. 상태 상자(오른쪽 위): "끼운 횟수 n = 4 / 그림 길이 Sₙ = 1.9375 / a/(1−r) = 2 / 차이 = 0.0625".
5. 식 패널(작업대 아래): 학생이 [식 맞추기]를 누르면 빈칸 식 "S = □ + □ × S" 가 나오고, 띠 위의 '첫 조각'과 '복사본'을 각각 탭하면 빈칸에 a, r 이 채워진다 → "S − rS = a → S = a/(1−r)" 이 한 줄씩 펼쳐진다(채점 없음, 탭할 때 해당 부분이 빛남).
6. 힌트 상자(왼쪽 아래, compass-straightedge.html 과 같은 모양), [질문 보기] 접이식 패널.
7. 하단 회색 문구: "화면은 최대 30번까지 끼운 유한한 그림입니다. 무한 번 끼운 '전체'는 |r| < 1 일 때만 길이가 정해지며, 그 길이가 Sₙ 의 극한 a/(1−r) 입니다."

### [활용하기] 탭
- 예제 버튼 3개, 누르면 a, r 이 고정되고 같은 작업대 조작을 한다.
  - ① 순환소수 0.272727… : 첫 조각 0.27, 복사본은 1/100배. 상태 상자에 "0.27 + 0.0027 + … → 27/99 = 3/11".
  - ② 튀는 공: 높이 3m 에서 떨어져 매번 2/3 높이로 튐. 그림은 가로 띠 대신 세로 지그재그 경로. 첫 조각 = 처음 낙하 3, 복사본 = "한 번 튄 뒤 전체 경로"를 2/3배 한 것인데 위아래 왕복이라 첫 복사본은 2·3·(2/3)=4 부터 시작함을 표시. 총 거리 3 + 4/(1−2/3) = 15m.
  - ③ 정사각형 안 정사각형: 한 변 2 인 정사각형의 각 변 중점을 이어 생기는 정사각형 넓이를 계속 더함. 첫 조각 넓이 4, r = 1/2 → 합 8.

## 조작과 반응
- a 손잡이를 끌면 → 첫 조각 길이·자 범위·모든 끼운 조각이 비례해서 즉시 바뀐다(r 고정이면 모양은 그대로, 크기만 a배).
- r 다이얼을 돌리면 → 끼운 조각 초기화(n=0), 대기칸 복사본 크기가 r배로 바뀐다. |r| ≥ 1 이면 복사본이 원본보다 같거나 크게 그려지고, 경고 "복사본이 줄어들지 않아요. 끼울수록 끝없이 커지거나 흔들립니다."
- 복사본을 꽂는 자리에 끌어 놓으면(또는 [복사본 끼우기] 단추) → 0.3초 동안 복사본이 미끄러져 첫 조각 뒤에 붙고, 새 그림 = 첫 조각 + r·(이전 그림). n 이 1 증가, 상태 상자 갱신, 대기칸에는 새 그림의 r배 복사본이 다시 생긴다.
- [10번 끼우기] → 빠르게 연속. [하나 되돌리기] → 이전 그림으로.
- 그림 끝에 a/(1−r) 위치를 초록 세로선으로 표시하는 [극한 위치 보기] 토글(기본 꺼짐; 질문 2 이후 켜 보도록 안내).
- r < 0 : 복사본이 뒤집혀 붙어 그림 끝이 a/(1−r) 의 양쪽을 오가며 다가간다.
- 모든 손잡이·단추 터치 영역 최소 44px. 끌기가 어려우면 단추로 같은 동작.

## 수학 계산 규칙
- 그림 길이: S₀ = 0 (복사본 없음, 첫 조각만 있는 상태를 S₁ = a 로 표시), Sₙ₊₁ = a + r·Sₙ. 이는 Sₙ = a(1 − rⁿ)/(1 − r) 와 같다(r ≠ 1). 화면은 점화식으로 계산하고, 상태 상자에는 공식값과 일치함을 보여 준다.
- r = 1 이면 Sₙ = na, 공식 대신 "n × a" 로 표시하고 a/(1−r) 칸에는 "정의되지 않음(0으로 나눔)".
- |r| < 1 : Sₙ → a/(1−r). |r| ≥ 1 (a ≠ 0) : 발산(r ≥ 1 은 +∞ 쪽, r ≤ −1 은 진동). r 손잡이 범위는 기본 −0.8~0.9, [범위 넓히기] 체크 시 −1.2~1.2 허용(발산 관찰용), 자 범위는 최대 [−10, 10] 으로 자르고 넘으면 가장자리 화살표 + 값.
- 그림: r > 0 이면 복사본을 그대로 축소, r < 0 이면 축소 후 첫 조각 오른쪽 끝을 기준으로 왼쪽으로 뒤집어 그린다(길이 = 부호 있는 합).
- 끼우기 최대 30회. 조각 폭이 0.5px 미만이면 그리지 않고 "(너무 작아 보이지 않음)" 표시, 계산은 계속.
- 활용 수치: 0.2727… = 0.27/(1 − 0.01) = 27/99 = 3/11. 튀는 공 총거리 = 3 + 2·3·(2/3)/(1 − 2/3) = 3 + 12 = 15. 정사각형 넓이 합 = 4/(1 − 1/2) = 8.

## 점검 포인트
1. Sₙ₊₁ = a + r·Sₙ (S₁ = a) 가 Sₙ = a(1−rⁿ)/(1−r) 와 일치하는가.
2. S = a + rS 에서 S = a/(1−r) 를 끌어내는 것은 S 가 존재(|r|<1)한다는 전제가 있어야 하며, 화면이 이를 밝히는가(r=1, r=−1, r=1.1 에서 오해 없는가).
3. 0.2727… = 3/11, 튀는 공 총거리 15m, 중점 정사각형 넓이 합 8 이 맞는가.
4. r < 0 일 때 그림 끝이 극한 양쪽을 번갈아 가며 다가가는가(부호 있는 합).
5. 화면 문구가 '30번 끼운 유한 그림'과 '무한 합(극한)'을 구분하는가.
