왜 그럴까?

“A 에 속하고 그리고 B 에 속한다” 와 “B 에 속하고 그리고 A 에 속한다” 는 같은 말입니다. ‘또는’ 도 마찬가지죠. 말의 순서가 바뀌어도 뜻이 그대로라서 교환법칙이 성립합니다.

∩ 과 ∪ 를 섞으면 — 분배법칙

수의 a × (b + c) = a × b + a × c 와 닮았습니다. 집합에서도 성립할까요?

　
　
식을 하나 눌러 보세요.
수와 다른 점

수에서는 + 가 × 에 분배되지 않습니다 (a + b × c ≠ (a+b) × (a+c)). 그런데 집합에서는 ∩ 도 ∪ 에, ∪ 도 ∩ 에 양쪽 모두 분배됩니다. 그림으로 직접 확인해 보세요.

📖 교과서를 펴는 화면📄 학습지 4-02 [정리하기] 집합의 연산법칙

집합의 연산법칙

법칙식
① 교환법칙 A ∩ B = B ∩ A   /   A ∪ B = B ∪ A
② 결합법칙 (A ∩ B) ∩ C = A ∩ (B ∩ C)
(A ∪ B) ∪ C = A ∪ (B ∪ C)
③ 분배법칙 A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)
A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)
기억하는 방법
  • 교환 — 자리를 바꾼다
  • 결합 — 괄호를 옮긴다
  • 분배 — 괄호를 풀어 나눠 준다. 이때 바깥 기호가 각각에 붙는다.

여집합과 차집합

전체집합 U = { x | x 는 10 이하의 자연수 }, A = { 1, 2, 5, 10 }, B = { 2, 4, 6, 8, 10 } 일 때. 버튼을 눌러 영역을 칠하고, 원소를 확인해 보세요.

기호원소나열법말로 설명하면
Ac U 에는 있고 A 에는 없는 것
A − B A 에는 있고 B 에는 없는 것
B − A B 에는 있고 A 에는 없는 것
A ∩ Bc A 에 속하면서 B 에 속하지 않는 것
같은 결과가 나온 두 칸은 A − B 와 A ∩ Bc 입니다. 그래서 A − B = A ∩ Bc 라고 쓸 수 있습니다. 차집합은 여집합과의 교집합으로 바꿔 쓸 수 있다는 뜻이에요.
A − B 와 B − A 는 같은가요?

{ 1, 5 } 와 { 4, 6, 8 } — 다릅니다. 즉 차집합에는 교환법칙이 성립하지 않습니다. 뺄셈에서 3 − 5 ≠ 5 − 3 인 것과 같습니다.

🔍 어디가 잘못되었을까?

A = { 2, 3, 6 }, B = { 1, 2, 4, 8 } 일 때 n(A − B) 를 구하려고 합니다. 어떤 학생이 이렇게 풀었습니다.

학생의 풀이

n(A − B) = n(A) − n(B) 이니까 …
= 3 − 4 = −1 ?   개수가 음수가 나왔다!

바르게 풀어 봅시다

A − B 는 A 에서 B 와 겹치는 부분만 덜어 낸 것입니다. B 에만 있는 1, 4, 8 은 애초에 A 에 없으므로 뺄 수 없습니다.

A ∩ B = { 2 } 이므로   A − B = { 3, 6 }  →  n(A − B) = 2

n(A − B) = n(A) − n(A ∩ B)

A − B = A ∩ Bc 로 바꿔 생각하면 “A 안에서 B 를 뺀다” 는 뜻이 분명해집니다.

‘또는’의 여집합은 ‘둘 다 아니다’   /   ‘그리고’의 여집합은 ‘적어도 하나는 아니다’
이어서 생각해 보기

(A − B)c 와 (B − A)c 는 어떻게 될까요? 위의 버튼으로 직접 칠해 보고, A − B = A ∩ Bc 를 이용해 정리해 보세요.

(A − B)c = (A ∩ Bc)c = Ac ∪ B  드모르간 + (Bc)c = B

(B − A)c = (B ∩ Ac)c = Bc ∪ A

개수로 계산하기

n(U) = 40, n(A) = 22, n(B) = 18, n(A ∩ B) = 7 일 때. 그림의 각 칸에 인원이 채워집니다.

구하는 것값세우는 식
n(A ∪ B) n(A) + n(B) − n(A ∩ B) = 22 + 18 − 7
n(Ac) n(U) − n(A) = 40 − 22
n(A − B) n(A) − n(A ∩ B) = 22 − 7
n(Ac ∩ Bc) n((A ∪ B)c) = n(U) − n(A ∪ B) = 40 − 33
넷째 칸에서 드모르간이 계산을 줄여 줍니다. Ac ∩ Bc 를 따로 세지 않고 (A ∪ B)c 로 바꿔 전체에서 빼면 끝입니다.
예제 1

[예제 1]

전체집합 U 의 두 부분집합 A, B 에 대하여
n(U) = 50, n(A) = 7, n(B) = 16, n(A ∪ B) = 21 일 때, n(Ac ∩ Bc) 을 구하시오.
풀이

드모르간의 법칙에서 Ac ∩ Bc = (A ∪ B)c 이므로

n(Ac ∩ Bc) = n(U) − n(A ∪ B) = 50 − 21 = 29

참고 — n(A ∩ B) = n(A) + n(B) − n(A ∪ B) = 7 + 16 − 21 = 2. 주어진 값들이 서로 어긋나지 않는지 이렇게 확인할 수 있습니다.
