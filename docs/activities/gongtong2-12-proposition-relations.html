‘p이면 q이다’ 는 언제 거짓일까?

A의 약속: “내가 로또 1등에 당첨된다면(p), 너에게 2억을 줄게(q).” 두 상황을 바꿔 가며, A가 약속을 어긴 경우를 찾아보세요.

로또 당첨 (p):
2억 줌 (q):
핵심: 명제 p → q 는 ‘가정 p 가 참인데 결론 q 가 거짓’ 일 때만 거짓입니다. (당첨됐는데 안 준 경우!) p 가 거짓이면(당첨 안 됨) 약속은 깨지지 않아 항상 참으로 봅니다.
구성요소

가정과 결론, 그리고 반례

명제 p → q 에서   p = 가정,   q = 결론.
명제가 거짓임을 보이려면 → 반례 하나면 충분! (가정은 만족하는데 결론이 안 되는 예)

예) 명제 “x가 4의 배수이면(p), x는 짝수이다(q)” → 참 (4의 배수는 늘 짝수).
명제 “x가 짝수이면(p), x는 4의 배수이다(q)” → 거짓, 반례 x = 6 (짝수지만 4의 배수 아님).

역 · 이 · 대우

역 · 이 · 대우

원명제 p → q 로부터 세 가지 명제를 만듭니다. 예: p: “x = 2”, q: “x² = 4”.

이름꼴예시참/거짓
원명제p → qx=2 → x²=4참
역q → px²=4 → x=2거짓 (x=−2)
이~p → ~qx≠2 → x²≠4거짓 (x=−2)
대우~q → ~px²≠4 → x≠2참
원명제와 대우는 참·거짓이 항상 같습니다! (원명제 참 ⟺ 대우 참) 반면 역과 이는 원명제와 참·거짓이 다를 수 있어요. 역과 이는 서로 대우 관계라 둘의 참·거짓은 같습니다.
진리집합

p ⇒ q ⟺ P ⊂ Q

조건 p, q 의 진리집합을 P, Q 라 하면, 명제 p → q 가 참 ⟺ P ⊂ Q (P 가 Q 안에 들어감).

“x=2 이면 x²=4” 가 참인 이유를 집합으로 보면: P={2} ⊂ Q={2, −2}. P 의 모든 원소가 Q 에 들어 있으니, p 를 만족하면 자동으로 q 도 만족! 대우가 참인 것도 Pᶜ ⊃ Qᶜ (여집합은 포함관계가 뒤집힘)로 설명됩니다.
필요 · 충분조건

필요조건과 충분조건

p ⇒ q 일 때 (P ⊂ Q):

이름뜻
p 는 q 이기 위한 충분조건p 면 충분히 q 가 됨 (작은 쪽 P)
q 는 p 이기 위한 필요조건p 가 되려면 q 는 반드시 필요 (큰 쪽 Q)
p ⇔ q (P = Q)필요충분조건 — 서로가 서로의 충분·필요
화살표로 기억! p ⇒ q 에서 화살표가 나가는 p 는 충분조건, 화살표가 들어오는 q 는 필요조건. (작은 집합 → 큰 집합)
정리

정리

  • p → q 는 p참·q거짓일 때만 거짓
  • 역(q→p), 이(~p→~q), 대우(~q→~p) — 원명제 ⟺ 대우
  • p ⇒ q ⟺ P ⊂ Q
  • p ⇒ q 이면 p 충분조건, q 필요조건 / p ⇔ q 필요충분조건

아래 ‘내 생각 적기’ 칸에, 역·이·대우를 각각 쓰고, 원명제와 대우의 참·거짓이 항상 같은 이유를 진리집합 P ⊂ Q ⟺ Qᶜ ⊂ Pᶜ 로 설명해 보세요.

의학 검사에서 ‘병이 있으면 양성’과 ‘양성이면 병이 있다’는 완전히 다른 말입니다(민감도와 정밀도). 이 둘을 혼동하면 오진이 생기죠. 재판의 알리바이 추론, 뉴스의 인과 주장 검증에도 그대로 쓰입니다.

↕ 수직 확장 · 더 근본으로

수학의 모든 정의는 필요충분조건(⟺)입니다. ‘짝수란 2로 나누어떨어지는 수’처럼요. 반면 정리는 보통 한쪽 방향(⟹)이고, 역이 성립하는지는 따로 증명해야 합니다. 이 구분이 수학적 엄밀함의 핵심이에요.
