# 3. 처음부터 만들기 — 클로드 코드와 페어코딩

2장의 복사 경로가 "완제품 조립"이라면, 이 장은 "밑바닥부터 지어 보기"다.
같은 걸 다시 만들 수도 있고, 아예 다른 나만의 시스템을 만드는 출발점으로
삼을 수도 있다. 핵심 도구는 **클로드 코드(Claude Code)** — 한국어로 지시하면
AI가 코드를 만들고 고쳐 주는 터미널 도구다.

솔직히 말하면 이 경로에서 사람이 하는 일은 세 가지다:
**시키기, 기다리기, 트집 잡기.** 교사에게 최적화된 업무 분장이다.

## 3-1. 클로드 코드 설치

터미널(맥: "터미널", 윈도우: "PowerShell")을 열고:

```bash
# 클로드 코드 설치
npm install -g @anthropic-ai/claude-code

# 작업할 폴더를 만들고 그 안으로 이동
mkdir 우리반-학습플랫폼
cd 우리반-학습플랫폼

# 실행 (처음엔 로그인 안내가 나온다)
claude
```

## 3-2. 설계 문서를 먼저 주기 (가장 중요)

무작정 "학습 플랫폼 만들어 줘"라고 하면 결과가 매번 다르게 나온다.
비유하자면 "맛있는 거 해줘"와 레시피를 건네는 것의 차이다.
**설계 문서를 먼저 주고 그대로 만들게** 해야 안정적이다.

이 프로젝트의 설계 문서는 저장소 `docs/` 폴더에 모두 공개되어 있다:

| 문서 | 내용 |
|---|---|
| `01_ARCHITECTURE.md` | 전체 구조·기술 선택·보안 원칙 |
| `02_CLAUDE_CODE_PROMPT.md` | 단계별(STEP) 제작 지시문 |
| `03_AI_FEATURES.md` | AI 기능 설계 (문답·첨삭·비용 통제) |
| `05_STRUCTURE_GUIDE.md` | 완성 후 화면·문구를 직접 고치는 법 |
| `.claude/skills/.../SKILL.md` | 클로드가 보안·비용 규칙을 지키게 하는 스킬 |

**가장 쉬운 방법**: 저장소를 통째로 받아서 시작한다. 설계 문서 + 완성된 코드가
같이 들어 있으니, 그 위에서 바꾸고 싶은 것만 시키면 된다.

```bash
git clone https://github.com/sced9120/math-platform
```

**정말 밑바닥부터 만들고 싶다면**: `docs/` 문서들만 새 폴더에 넣고 클로드에게:

```
docs/01_ARCHITECTURE.md 를 먼저 읽은 후,
docs/02_CLAUDE_CODE_PROMPT.md 의 "STEP 1" 을 진행해줘.
```

STEP 1 → 2 → … 순서로 시키면 로그인 → DB → 교사 기능 → 학생 기능 → AI 기능이
차례로 만들어진다. 실제로 이 플랫폼이 그렇게 태어났다.

## 3-3. 클로드에게 시킬 때의 요령

몇 달 함께 일하며 얻은 교훈이다.

- **한 번에 하나씩.** "로그인도 고치고 첨삭도 넣고 색도 바꿔줘"보다
  세 번 나눠 시키는 게 결과가 좋다. 학생 지도와 같다.
- **오류는 그대로 붙여넣기.** 해석하려 하지 말고 빨간 글씨를 통째로 복사해서
  "이거 고쳐줘"라고 하면 된다. 오류 메시지는 클로드의 모국어다.
- **끝나면 확인 요구.** "다 됐어?" 대신 "로컬에서 실행해서 로그인까지 되는지
  확인해줘"라고 하면 스스로 검증까지 한다.
- **잘 됐을 때 저장.** `git add -A && git commit -m "여기까지 잘 됨"` —
  이 한 줄이 나중에 여러분을 구원한다.

다음 장에서 만든 것을 데이터베이스·AI와 연결하고 인터넷에 공개한다.
