🔍 y = x² 는 정말 역함수가 없을까?

입력과 출력을 바꾸려면 출력 하나에 입력이 하나여야 합니다. 가로선(y = k)을 위아래로 움직이며 그래프와 몇 번 만나는지 세어 보세요.

일대일함수가 아니다
수평선 판정법 — x축과 평행한 직선을 어디에 그어도 최대 한 번만 만나야 일대일함수입니다. y = x² 는 k > 0 인 모든 가로선과 두 번 만나므로 실격이죠. 예를 들어 출력 4 를 보고는 입력이 2 였는지 −2 였는지 알 수 없습니다.
발상의 전환

정의역을 좁혀 보자

“역함수가 없다”가 아니라 “정의역을 너무 넓게 잡았다” 였다면 어떨까요? a 를 움직여 정의역을 x ≥ a 로 좁혀 봅시다. 언제부터 일대일함수가 될까요?

굵은 파란 곡선이 실제로 쓰는 부분입니다. 붉은 가로선은 가장 나쁜 경우(가장 많이 만나는 높이)를 자동으로 찾아 그린 것이에요.

역함수 등장

y = x² (x ≥ 0) 을 뒤집으면

정의역을 x ≥ 0 으로 정했더니 일대일대응이 되었습니다. 이제 입력과 출력을 바꿔 봅시다. 점 (t, t²) 이 (t², t) 로 옮겨 갑니다.

y = x² (x ≥ 0)  의 역함수는  y = x

두 점을 잇는 회색 선분의 한가운데가 직선 y = x 위에 있고, 선분이 그 직선과 수직입니다. 이것이 “y = x 에 대하여 대칭”의 정확한 뜻이에요.

왼쪽 반을 고르면 어떻게 될까?

정의역을 x ≤ 0 으로 정해도 일대일대응입니다. 그때의 역함수는 무엇일까요?

정의역치역역함수역함수의 정의역
x ≥ 0y ≥ 0y = xx ≥ 0
x ≤ 0y ≥ 0y = −xx ≥ 0
정의역과 치역이 맞바뀝니다. 원래 함수의 치역이 역함수의 정의역이 되죠. 그래서 x 의 정의역이 x ≥ 0 인 것은 우연이 아니라, 원래 함수 y = x² 의 치역이 y ≥ 0 이었기 때문입니다.
정리

무리함수로 가는 다리

오늘의 발상 전환
“이 함수는 역함수가 없다”  →  “이 함수는 정의역을 어떻게 잡느냐에 따라 역함수가 생긴다”
단계내용
1수평선 판정 — 가로선과 최대 한 번만 만나야 일대일함수
2정의역을 좁혀 일대일대응으로 만든다
3역함수의 그래프는 원래 그래프를 직선 y = x 에 대해 대칭이동한 것
4원래 함수의 치역 = 역함수의 정의역
다음 시간 예고 — 무리함수 y = ax 는 바로 y = x²/a (x ≥ 0) 의 역함수입니다. 그래서 무리함수 그래프가 포물선을 눕혀 놓은 모양이고, 정의역에 조건이 붙는 것이죠. 오늘 한 일이 그 단원의 준비 운동이었습니다.

아래 ‘내 생각 적기’ 칸에 정리해 보세요.
(1) y = x² 이 실수 전체에서는 왜 역함수를 갖지 못하는지 수평선 판정으로 설명하세요.
(2) 정의역을 x ≤ 0 으로 정하면 역함수가 y = −x 가 되는 이유를 쓰세요.
(3) 함수 y = (x − 2)² 이 역함수를 갖도록 하는 정의역을 하나 정하고, 그때의 역함수를 구하세요.

확장 탐구

🔭 더 넓게, 더 깊게

배운 것을 옆으로(다른 분야와 잇기) 그리고 아래로(더 근본적인 이유로) 넓혀 봅시다.

↔ 수평 확장 · 어디에 쓰일까

계산기의 sin⁻¹ 버튼이 정확히 이 이야기입니다. sin 은 주기함수라 역함수가 없지만, 정의역을 −90°~90° 로 잘라서 역함수를 만들어 놓은 것이죠. 암호에서 “되돌릴 수 있는 변환”을 설계할 때도 일대일대응이 필수 조건입니다.

↕ 수직 확장 · 더 근본으로

함수는 식만으로 정해지지 않습니다. 정의역·공역까지 정해야 비로소 하나의 함수예요. 같은 식 x² 도 정의역을 바꾸면 다른 함수가 되고, 어떤 것은 역함수를 갖고 어떤 것은 갖지 못합니다.

🧗 도전 질문
① y = x² 의 정의역을 x ≥ 1 로 정하면 역함수는 무엇이고, 그 정의역은 어떻게 될까요?
② 정의역을 [−1, 1] 로 정하면 일대일대응이 될까요? 안 된다면, 왜 ‘좁히기만’ 하면 되는 게 아닌지 설명해 보세요.
