📈 그래프는 어떻게 그렸었나 — y = x²

중학교 3학년으로 돌아가 봅시다. y = x² 의 그래프를 어떻게 그렸나요?

1) 위 식을 만족하는 순서쌍을 찾아보자.
2) x 의 값을 촘촘하게 하면 어떻게 그려질까?

점이 촘촘해지면서 매끄러운 곡선이 됩니다. 우리는 늘 이렇게 그래프를 그려 왔습니다.

① 표를 만든다 → ② 점을 찍는다 → ③ 부드럽게 잇는다

오늘 유리함수도 똑같이 그립니다. 다만 한 가지가 다릅니다 — 표에 넣을 수 없는 x 가 생깁니다.

1/x — 표에 넣을 수 없는 칸

x = 0 칸은 비워 둡니다. 1 ÷ 0 은 계산할 수 없으니까요.

두 가지를 관찰하세요.
  • x 가 0 에 가까워지면 |y| 가 한없이 커집니다 → 그래프가 y축에 달라붙습니다.
  • x 가 한없이 커지면 y 는 0 에 가까워집니다 → 그래프가 x축에 달라붙습니다.

그런데 절대로 닿지는 않습니다. 이 두 직선의 이름을 다음 화면에서 배웁니다.

🔍 y = k/x — k 를 움직여 보자

학습지의 y = 2/x, y = 3/x, y = −1/x 를 슬라이더로 한꺼번에 봅니다.

📗 점근선이란 — 곡선이 어떤 직선에 한없이 가까워지지만 만나지는 않을 때, 그 직선을 그 곡선의 점근선이라 합니다.
한자로 漸(점점 점)·近(가까울 근) — “점점 가까워지는 선”.
🔢 “가까워진다”를 눈이 아니라 수로 확인해 봅시다

y = 1/x 에 직접 넣어 봅니다.

버튼을 눌러 값을 채워 보세요.
⚠️ “y = 1/x 는 정의역 전체에서 감소한다” — 맞을까요?

x 가 커지면 y 가 작아지니 감소처럼 보입니다. x₁ = −1, x₂ = 1 을 넣어 보세요.

정의역 전체에서 감소가 아니라, x < 0 인 구간과 x > 0 인 구간에서 각각 감소

두 가지가 끊어져 있기 때문입니다. 끊긴 곳을 건너뛰어 비교하면 안 됩니다.

정의역{ x | x ≠ 0 인 실수 }
치역{ y | y ≠ 0 인 실수 }
대칭성원점에 대하여 대칭. 또 직선 y = x, y = −x 에 대하여도 대칭
그래프 위치k > 0 이면 제1·3사분면  /  k < 0 이면 제2·4사분면
점근선x축 (y = 0) 과 y축 (x = 0) — k 가 아무리 바뀌어도 그대로
k 의 값|k| 가 커질수록 그래프가 원점에서 멀어진다

k 의 부호가 사분면을, k 의 절댓값이 원점에서의 거리를 정합니다.

↔️ y = 3/x 를 옮겨 보자

Ⅰ단원에서 배운 평행이동이 그대로 쓰입니다. 슬라이더로 옮겨 보세요.

Q2. x축으로 2, y축으로 −1 만큼 평행이동한 식은?
y = 3/(x − 2) − 1

평행이동의 규칙 그대로입니다 — x 자리에 x−2, y 자리에 y+1.

y + 1 = 3/(x − 2)  →  y = 3/(x − 2) − 1

x 는 빼고(x−2), y 는 더한다(+q 로 넘어감) — 부호가 반대인 이유는 Ⅰ-3 에서 배운 그대로입니다.

🧭 Q4. (ax+b)/(cx+d) 를 그리는 전략

모양이 달라 보여도 전부 y = k/x 를 옮긴 것입니다. 그걸 드러내는 계산을 봅시다.

1
분자를 분모로 나눈다 → y = k/(x−p) + q 꼴로 고친다. 분자에서 분모의 배수를 억지로 만들어 내는 것이 요령입니다.
2
점근선을 긋는다 → x = p, y = q. 십자로 먼저 그으면 그래프 그릴 자리가 정해집니다.
3
k 의 부호로 방향을 정한다 → k > 0 이면 오른쪽 위·왼쪽 아래, k < 0 이면 오른쪽 아래·왼쪽 위.
4
확인점 두 개를 찍는다 → (p+1, q+k) 와 (p−1, q−k). 점근선에서 좌우로 한 칸씩. 분모가 ±1 이 되니 계산이 필요 없습니다.
왜 (p±1) 인가?  y = k/(x−p) + q 에 x = p+1 을 넣으면 분모가 1 이 되어 y = k + q. x = p−1 이면 분모가 −1 이라 y = −k + q. k 가 그대로 눈에 보입니다.
⚠️ 분모가 0 이 되면 언제나 수직점근선일까?
r(x) = (2x + 2)/(x + 1)

x = −1 에서 분모가 0 입니다. 그러면 x = −1 이 점근선일까요?

r(x) = 2(x+1)/(x+1) = 2, 단 x ≠ −1

쌍곡선이 아닙니다. 높이 2 인 수평인 직선에 (−1, 2) 한 점만 뚫린 모양입니다.

x 를 −1 에 가까이 보내도 r(x) 는 계속 2 — 한없이 커지지 않습니다. 그러니 x = −1 은 점근선이 아닙니다.

분자와 분모에 같은 인수가 있으면 → 점근선이 아니라 구멍

그래서 1단계(변형)를 먼저 해야 합니다. 변형해 보면 k 가 아예 없다는 걸 알게 되니까요.

🔬 점근선이 서로 뒤바뀐다

앞 화면은 숫자 하나짜리였습니다. 이제 일반형으로 해 봅시다.

y = k/(x − p) + q 의 역함수는?
1
역함수는 y = k/(x − q) + p — k 는 그대로이고 p 와 q 만 자리를 바꿉니다.
2
점근선은 x = p, y = q → x = q, y = p 로 서로 뒤바뀝니다. 점 (p, q) 가 (q, p) 로 간다 — 이것이 바로 y = x 대칭입니다.
3
원래 그래프를 (q − p, p − q) 만큼 평행이동하면 역함수와 완전히 겹칩니다. 이동 방향의 기울기가 −1 — y = x 와 수직입니다.
왜 겹칠까? 두 그래프는 모양(k)이 같고 위치(점근선)만 다릅니다. 점근선의 교점이 (p, q) → (q, p) 로 옮겨간 만큼만 밀어 주면 포개집니다.
적용 — y = (3x−1)/(x−2) 의 역함수를 점근선만으로 구해 보세요.

3x−1 = 3(x−2) + 5 → y = 5/(x−2) + 3   (k=5, p=2, q=3)

p 와 q 를 바꾸면 —

역함수 y = 5/(x−3) + 2 = (2x−1)/(x−3)

x, y 를 바꿔 직접 정리해도 같은 답이 나옵니다. 확인해 보세요.
