직선 하나를 정하려면?

종이 위에 자를 대고 직선을 그으려면 최소한 무엇이 있어야 할까요? 수학에서는 다음 두 가지 중 하나면 직선이 딱 하나로 정해집니다.

① 한 점 + 기울기 — 지나갈 점 하나와, 기울어진 정도
② 서로 다른 두 점 — 두 점을 이으면 직선은 하나뿐
점(파랑)을 드래그해 보세요. 조건이 정해지면 직선은 하나로 결정됩니다.
점-기울기형

📖교과서 18쪽 — 한 점과 기울기로 직선의 방정식을 세우는 부분을 함께 봅니다.

한 점과 기울기로 세우는 식

기울기가 m 이고 점 (x₁, y₁) 을 지나는 직선 위의 임의의 점 (x, y) 를 생각해 봅시다. 두 점으로 기울기를 계산하면 항상 m 이어야 하죠.

y − y₁x − x₁ = m   →   y − y₁ = m(x − x₁)
파란 점을 드래그하면 식이 실시간으로 바뀝니다.
두 점
🖥 보여주며 조작📄 학습지 1-02 [생각 틔우기] Q5 (2)

두 점을 지나는 직선

두 점 A, B 를 드래그 해 보세요. 기울기를 먼저 구하고, 점-기울기형에 대입하면 끝입니다.

x₁ = x₂ 이면 기울기를 구할 수 없어요 → 세로선 x = k
y − y₁ = y₂ − y₁x₂ − x₁ (x − x₁)   (단, x₁ ≠ x₂)

축에 평행한 직선과 일반형

직선방정식기울기
x축에 평행(가로)y = k0
y축에 평행(세로)x = k없음(정의 안 됨)
일반형 ax + by + c = 0 (a, b 중 적어도 하나 ≠ 0) 은 모든 직선을 한 가지 꼴로 표현합니다. b ≠ 0 이면 y = −(a/b)x − c/b 로 정리되어 기울기가 −a/b. b = 0 이면 x = −c/a 인 세로선이죠.

b 를 0 으로 만들어 보세요 — 기울기가 사라지고 세로선이 됩니다!

두 직선의 위치 관계

두 직선의 기울기 m₁, m₂ 와 y절편 n₁, n₂ 를 바꿔 보세요. 위치 관계가 실시간으로 판정됩니다.

두 직선이 평행 ⟺ 기울기가 같고(y절편은 다름): m₁ = m₂, n₁ ≠ n₂. 기울기·절편 모두 같으면 일치.

평행이란 무엇인가

📜 유클리드의 다섯 번째 약속

제5공준(평행선 공준)
임의의 직선이 두 직선과 교차할 때, 교차되는 각의 내각의 합이 두 직각(180°)보다 작으면, 두 직선을 계속 연장하면 그쪽에서 교차한다.

아래에서 두 번째 직선을 기울여 보세요. 내각의 합 α + β 가 180° 에서 조금만 벗어나도 두 직선은 언젠가 만납니다. 정확히 180° 일 때만 영원히 만나지 않습니다.

가로지르는 직선(회색)이 두 직선과 만드는 같은 쪽 내각입니다.

이 약속은 2000년 동안 수학자들을 괴롭혔습니다. “너무 당연해 보이니 다른 공준으로 증명할 수 있지 않을까?” 하고 수없이 시도했지만 모두 실패했죠. 19세기에 이르러 이 공준을 버린 기하학(비유클리드 기하)도 모순 없이 성립한다는 것이 밝혀졌습니다. 지구 위처럼 휜 공간에서는 ‘평행선’이 아예 없기도 합니다.

그렇다면 평행이란 무엇일까요? 아래 기록칸에 자신의 말로 적어 보세요. ‘만나지 않는다’ 와 ‘기울기가 같다’ 는 어떤 관계인지도 함께 생각해 보세요.

평행 조건 · 일치 조건

두 직선 y = m₁x + n₁, y = m₂x + n₂ 의 위치 관계는 이렇게 갈립니다.

위치 관계기울기y절편공통점 개수
한 점에서 만남m₁ ≠ m₂상관없음1개
평행m₁ = m₂n₁ ≠ n₂0개
일치m₁ = m₂n₁ = n₂무수히 많음
평행과 일치는 어디서 갈라질까?
둘 다 기울기는 같습니다. 갈라지는 곳은 y절편, 즉 상수항 하나뿐입니다. 기울기가 같다는 것은 “방향이 같다”는 뜻이고, y절편이 다르다는 것은 “서로 떨어져 있다”는 뜻입니다. 방향만 같고 떨어져 있으면 평행, 떨어진 거리마저 0 이면 일치입니다.

일반형으로 보면 — 두 직선 a₁x + b₁y + c₁ = 0, a₂x + b₂y + c₂ = 0 에 대해

  • 평행: a₁ : a₂ = b₁ : b₂ ≠ c₁ : c₂
  • 일치: a₁ : a₂ = b₁ : b₂ = c₁ : c₂

일반형은 기울기가 없는 직선(x = k) 까지 함께 다룰 수 있어서 편합니다.

평행 조건과 일치 조건을 스스로 정리하고, 두 조건이 어디에서 갈라지는지 적어 보세요.

↔ 수평 확장 · 어디에 쓰일까

데이터 점들이 흩어져 있을 때 ‘가장 잘 맞는 직선’을 긋는 것이 회귀분석(추세선)입니다. 키와 몸무게, 공부 시간과 성적처럼 두 양의 관계를 직선으로 요약하죠. 엑셀의 추세선, AI의 선형회귀가 모두 이것입니다.

↕ 수직 확장 · 더 근본으로

ax + by + c = 0 을 (a, b)·(x, y) = −c 로 보면, (a, b)는 그 직선에 수직인 벡터(법선벡터)입니다. 직선을 ‘기울기’가 아니라 ‘어느 방향에 수직인가’로 보는 관점이며, 3차원에서 평면 ax+by+cz+d=0 으로 그대로 이어집니다.
