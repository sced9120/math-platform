# 이 시스템을 처음부터 만들기 — 그리고 내 교과로 바꾸기

> 이 글 하나만 따라 하면, 개발 지식이 없어도 **AI 학습 플랫폼을 처음부터 만들어
> 인터넷에 배포**할 수 있다. 그리고 수학이 아닌 다른 교과(영어·과학·국어 등)로도
> 프롬프트와 메뉴 이름만 바꿔 그대로 쓸 수 있다.
>
> 핵심 도구는 **클로드 코드(Claude Code)** 다. 사람이 코드를 직접 짜지 않고,
> 한국어로 지시하면 클로드가 코드를 만들고 고쳐 준다.

이 시스템으로 만들 수 있는 것(수학 버전 기준):
- **3단계 계정**: 관리자(교사 계정 관리) · 교사(학생·활동 관리) · 학생
- 학번+비밀번호 로그인 (교사가 학생 계정 일괄 생성)
- 단원·활동 관리 (GeoGebra / 자료 / 문제 / 사진 / HTML 체험), 반별 활동 부여
- **AI 소크라테스 문답** (정답 대신 질문으로 유도)
- **AI 풀이 첨삭** (텍스트 또는 **사진/PDF 업로드** → 단계별 오류 첨삭 또는 발문형 힌트)
- 제출 기록 CSV 다운로드
- **관리자가 웹 화면에서 직접** 바꿀 수 있는 것 (코드 수정 불필요):
  AI 프롬프트(성격·규칙), AI 제공자 API 키(OpenAI·Gemini·Claude), 학생이 고를 모델 목록

> 💡 **가장 빠른 길**: 이미 만들어진 이 프로젝트를 복사해 쓸 거라면, 저장소 README의
> **"Deploy with Vercel" 원클릭 버튼**이 제일 쉽다. 아래 1~5절은 "클로드 코드로 밑바닥부터
> 직접 만드는" 경로이고, 이미 만든 걸 그대로 쓰려면 README → 3절(내 교과로 바꾸기)만 봐도 된다.

## 0. 준비물 (모두 무료로 시작 가능)

| 항목 | 용도 | 어디서 |
|---|---|---|
| **컴퓨터** (맥/윈도우) | 작업 | — |
| **Node.js** | 프로그램 실행 환경 | [nodejs.org](https://nodejs.org) — LTS 버전 설치 |
| **클로드 코드** | AI가 코드를 만들어 줌 | 아래 1절 |
| **Supabase 계정** | 데이터베이스(계정·기록 저장) | [supabase.com](https://supabase.com) |
| **Vercel 계정** | 인터넷에 공개(배포) | [vercel.com](https://vercel.com) |
| **AI API 키** | 챗봇·첨삭 (셋 중 하나 이상) | OpenAI([platform.openai.com](https://platform.openai.com)) / Google Gemini([aistudio.google.com](https://aistudio.google.com/app/apikey)) / Anthropic([console.anthropic.com](https://console.anthropic.com)) |
| (선택) **도메인** | 나만의 주소 | 가비아·Cloudflare 등 |

> API 키는 사용한 만큼 요금이 나온다. 한 반이 수업에서 쓰는 정도는 하루 수천 원
> 수준이고, 결제 페이지에서 **월 사용 한도**를 걸어 두면 초과 걱정이 없다.
> AI 키는 배포 후 **관리자 화면에서 붙여넣어도** 된다(3절 참고) — 코드나 환경변수를
> 몰라도 웹에서 등록·교체할 수 있다.

## 1. 클로드 코드 설치하고 시작하기

터미널(맥: 스포트라이트에서 "터미널", 윈도우: "PowerShell")을 열고:

```bash
# 클로드 코드 설치
npm install -g @anthropic-ai/claude-code

# 작업할 폴더를 만들고 그 안으로 이동
mkdir 우리반-학습플랫폼
cd 우리반-학습플랫폼

# 클로드 코드 실행 (처음엔 로그인 안내가 나온다)
claude
```

이제 클로드에게 한국어로 지시하면 된다.

## 2. 설계 문서를 먼저 주기 (가장 중요)

무작정 "만들어 줘"라고 하면 결과가 매번 달라진다. **설계 문서를 먼저 주고
그대로 만들게** 하면 안정적이다. 이 프로젝트의 `docs/` 폴더에 있는 설계 문서가
그 설계도다:

- `01_ARCHITECTURE.md` — 전체 구조·기술 선택·보안 원칙
- `02_CLAUDE_CODE_PROMPT.md` — 단계별(STEP) 제작 지시문
- `03_AI_FEATURES.md` — AI 기능 설계
- `05_STRUCTURE_GUIDE.md` — 완성된 뒤 화면·문구를 직접 고치는 법
- `.claude/skills/math-platform-builder/SKILL.md` — 클로드가 규칙을 지키게 하는 스킬

**가장 쉬운 방법:** 이 프로젝트 폴더를 통째로 복사해서 시작한다.
그러면 설계 문서 + 이미 완성된 코드가 모두 들어 있다. 그 상태에서
3절(나만의 것으로 바꾸기)만 하면 된다.

**밑바닥부터 만들고 싶다면:** 위 문서들을 새 폴더의 `docs/`에 넣고, 클로드에게:

```
docs/01_ARCHITECTURE.md 를 먼저 읽은 후,
docs/02_CLAUDE_CODE_PROMPT.md 의 "STEP 1" 을 진행해줘.
```

이렇게 STEP 1 → 2 → … 순서로 시키면 로그인·DB·교사기능·학생기능이 차례로 만들어진다.
(이 프로젝트가 실제로 그렇게 만들어졌다.)

## 3. 내 교과로 바꾸기

수학으로 만든 것을 **영어·과학·국어 등 다른 교과로** 바꾸는 건 어렵지 않다.
**대부분은 코드를 전혀 건드리지 않고, 관리자 웹 화면에서 바꿀 수 있다.**

### (1) AI의 성격·말투 = 프롬프트 → **관리자 화면에서 (코드 불필요)**

관리자로 로그인 → 상단 **"AI 프롬프트"** 메뉴. 세 가지 프롬프트를 그대로 편집·저장하면
다음 응답부터 바로 반영된다 (재배포도 코드 수정도 필요 없다):

- **소크라테스식 문답(챗봇)** — 질문으로 유도하는 튜터의 성격
- **단계별 오류 첨삭** — 풀이를 단계로 나눠 판정하는 기준
- **발문형 힌트** — 정답 대신 사고를 여는 질문

예: 프롬프트의 "수학"을 "영어"로 바꾸고 "영작문에서 문법·표현을 스스로 고치도록
질문한다" 식으로 규칙만 다시 적으면 된다. 과학이면 "실험 설계·개념 오류",
국어면 "논증 구조·근거" 식으로. **"정답을 직접 주지 않는다"는 원칙만 유지**하면
어느 교과든 잘 맞는다. (편집 화면에 이 경고가 이미 떠 있다.)

> 코드로 바꾸고 싶다면 기본 프롬프트는 `lib/ai/prompts.ts`에 있다. 하지만 웹 화면 편집이
> 훨씬 쉽고, 복제한 다른 교사도 코드 없이 자기 교과로 바꿀 수 있다.

### (2) 어떤 AI를 쓸지 = API 키·모델 → **관리자 화면에서 (코드 불필요)**

관리자 → 상단 **"AI 키·모델"** 메뉴.
- **API 키**: OpenAI·Gemini·Claude 중 원하는 것의 키를 붙여넣어 저장. 각 항목에
  **"❓ 키 발급 방법"** 도움말과 **"📖 사용 가능한 모델 목록(공식 문서)"** 링크가 있다.
- **모델 추가**: 공식 문서에서 최신 모델 ID(예: `gpt-5-mini`)를 확인해 추가하면,
  학생 화면에 그 모델이 선택지로 나온다. 여러 개 넣으면 학생이 고를 수 있다.

즉 최신 모델이 나와도 코드 배포 없이 관리자가 모델 ID만 추가하면 바로 쓸 수 있다.

### (3) 화면에 보이는 메뉴·문구 → 코드 (간단)

이건 아직 코드에서 바꾼다(문구 한 줄 수정 수준).

| 바꿀 것 | 파일 |
|---|---|
| 학생 사이드메뉴 항목 이름 | `components/student/side-menu.tsx` |
| 사이트 제목 | `app/layout.tsx`, `app/(student)/layout.tsx` |
| 첨삭 방식 버튼 이름(오류첨삭/발문) | `components/student/feedback-panel.tsx` |

예: 사이드메뉴의 `"💬 소크라테스식 문답"` → `"💬 영어 첨삭 도우미"` 처럼
따옴표 안 글자만 바꾸면 된다. (자세한 건 `docs/05_STRUCTURE_GUIDE.md` 참고.)
혹은 클로드에게 "사이드메뉴 이름을 영어 교과에 맞게 바꿔줘"라고 시키면 된다.

### (4) 활동 유형·평가 방식 → 클로드에게

문제 정답 채점 방식이나 활동 종류를 바꾸고 싶으면 클로드에게 설명하면 된다.
예: "영어는 정답이 하나가 아니니, 문제 활동에 '예시 답안'과 '채점 기준'을
넣고 AI가 기준대로 채점하게 해줘."

## 4. 연결 정보 넣기 (계정 3개의 키)

만든 코드가 데이터베이스·AI와 통신하려면 열쇠(키)가 필요하다.
`.env.local` 이라는 파일에 넣는다. 클로드에게:

```
.env.local.example 을 참고해서 .env.local 을 만들 건데,
값은 내가 붙여넣을게. 어디서 발급받는지 알려줘.
```

꼭 필요한 값:
- Supabase: `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`, `SUPABASE_SERVICE_ROLE_KEY`

AI 키(`OPENAI_API_KEY` 등)는 여기 넣어도 되고, **배포 후 관리자 화면에서 등록해도**
된다(3-(2) 참고). 후자가 코드·환경변수를 안 만져도 돼 더 쉽다.

> `.env.local` 은 **절대 인터넷에 올리거나 남에게 보여주면 안 된다.** (git이 자동 제외함)

**데이터베이스 만들기**: `supabase/setup.sql` 하나를 Supabase SQL Editor에 통째로
붙여넣고 Run 하면 표·보안정책·함수가 한 번에 만들어진다. (개별 마이그레이션은
`supabase/migrations/` 에 순서대로 있다.)

**관리자 계정 만들기** (최초 1회, 터미널):
```bash
npm run create-teacher -- admin 관리자 --admin
```
출력된 아이디/초기비번으로 로그인하면, 이후 교사·학생 계정과 AI 프롬프트·키·모델을
모두 웹 화면에서 관리할 수 있다.

## 5. 배포하기 (인터넷에 공개)

```bash
# 로컬에서 먼저 확인
npm run dev
# → 화면에 나온 http://localhost:3000 을 브라우저로 열어 테스트

# 문제 없으면 인터넷에 공개
npx vercel --prod
```

처음 `vercel` 명령을 쓰면 로그인·프로젝트 생성 안내가 나온다.
배포 후 `환경 변수(Environment Variables)`에 `.env.local`의 값들을
Vercel 사이트에서 등록해야 실제로 작동한다. (클로드에게 "Vercel에 환경변수
등록하는 법 알려줘"라고 하면 된다.)

1~2분 뒤 `https://프로젝트이름.vercel.app` 주소로 전 세계에서 접속된다.

### 나만의 도메인 붙이기 (선택)

도메인을 샀다면:
1. Vercel 프로젝트 → Settings → Domains → 도메인 입력
2. 도메인 구매처(또는 Cloudflare)의 DNS에 CNAME 레코드 추가
   (`math` → `cname.vercel-dns.com` 형태)

몇 분 뒤 내 도메인으로 접속되고, 보안 인증서(https)는 Vercel이 자동 발급한다.

## 6. 공유하고 알리기

이 시스템은 코드가 다 열려 있으므로 다른 선생님과 나눌 수 있다.

- **코드 공유**: 폴더를 GitHub에 올리면(`git`) 누구나 복제해 쓸 수 있다.
  단, `.env.local`(키)은 절대 올리지 말 것 — 이미 자동 제외되어 있다.
- **사용법 공유**: 이 `docs/` 문서들을 함께 주면 받는 사람도 자기 교과로 바꿀 수 있다.
- **주의**: 학생 데이터가 AI(외부 API)로 전송되므로, 학교 개인정보 방침을 확인하고
  학생·보호자 고지·동의 절차를 갖출 것. (이 시스템에는 동의 화면이 이미 들어 있다.)

## 자주 막히는 곳

| 증상 | 해결 |
|---|---|
| `npm` 명령을 모른다고 나옴 | Node.js 미설치. [nodejs.org](https://nodejs.org)에서 LTS 설치 후 터미널 재실행 |
| 배포는 됐는데 로그인이 안 됨 | Vercel에 환경변수(키)를 등록 안 했거나, DB SQL을 실행 안 함 |
| AI가 "동의가 필요합니다"만 뜸 | 학생이 첫 사용 시 AI 동의 버튼을 눌러야 함 (정상 동작) |
| AI 응답이 느림 | 첫 요청은 서버가 깨어나느라 느림. 수업 전 미리 한 번 접속해 두기 |
| 화면이 안 뜨고 오류 | 코드 오타. `git checkout .` 로 마지막 정상 상태로 되돌리기 |

**막히면 그냥 클로드에게 오류 메시지를 그대로 붙여넣고 "이거 고쳐줘"라고 하면 된다.**
이 폴더에서 클로드를 실행하면 프로젝트 규칙(보안·비용 통제)을 알아서 지키며 고쳐 준다.
