집합이 되려면?

다음 ‘모임’이 집합인지 아닌지 판단해 보세요. 기준이 명확해서 어떤 대상이 속하는지 누구나 똑같이 판정할 수 있으면 집합입니다.

표현

집합을 나타내는 방법

① 원소나열법 — 원소를 { } 안에 죽 나열
A = {1, 2, 3, 6},   B = {2, 4, 6, 8, ⋯}
② 조건제시법 — 원소가 만족하는 조건 제시
A = { x | x 는 6의 약수 },   B = { x | x 는 양의 짝수 }
③ 벤 다이어그램 — 원 안에 원소를 그려 넣기 (다음 화면)
  • 유한집합: 원소가 유한개   /   무한집합: 원소가 무수히 많음
  • 공집합 ∅: 원소가 하나도 없는 집합. 예) { x | x 는 x²=−1 인 실수 } = ∅
  • n(A): 집합 A 의 원소의 개수. A={2,3,5} → n(A)=3,   n(∅)=0
포함관계

부분집합 A ⊂ B

집합 A 의 모든 원소가 집합 B 에 속하면, A 는 B 의 부분집합: A ⊂ B.

∈ 와 ⊂ 는 다릅니다! 1 ∈ {1,2,3} (원소),   {1} ⊂ {1,2,3} (부분집합).
∅ ⊂ A (공집합은 모든 집합의 부분집합),   A ⊂ A (자기 자신도 부분집합).
진부분집합: 자기 자신을 뺀 부분집합.   A=B ⟺ A⊂B 이고 B⊂A.
부분집합 만들기

A = {1, 2, 3} 의 부분집합

각 원소를 클릭해 넣거나 빼면서 부분집합을 만들어 보세요. 만들 수 있는 부분집합은 모두 몇 개일까요?

각 원소마다 ‘넣는다 / 뺀다’ 두 가지 선택 → 2 × 2 × 2 = 2³ = 8개. 아래 8개를 모두 만들어 보며 확인하세요.

개수 공식

부분집합의 개수

원소가 n 개인 집합의 부분집합의 개수는 2ⁿ 입니다. (각 원소를 넣을지 뺄지 2가지씩 독립적으로 고르니까요.)

조건개수
부분집합 전체2ⁿ
특정 원소 1개를 반드시 포함2ⁿ⁻¹
특정 원소 1개를 포함하지 않음2ⁿ⁻¹
진부분집합 (자기 자신 제외)2ⁿ − 1
생각 키우기 — A = {1, 2, 3, 4, 5} (n=5)
(1) 부분집합의 개수 = 2⁵ = 32
(2) 원소 3 을 포함하는 부분집합 = 3 은 고정, 나머지 4개를 자유 선택 = 2⁴ = 16
정리 · 말장난

헷갈리기 쉬운 것

  • A = {∅} 의 원소의 개수 n(A) = 1 — 원소가 ‘∅’ 하나 있는 집합!
  • ∅ 과 {∅} 은 다릅니다. ∅ 은 원소가 없고, {∅} 은 원소가 1개.
  • 0 ∈ ∅ 은 거짓 (공집합엔 아무것도 없음),   ∅ ⊂ ∅ 은 참.

아래 ‘내 생각 적기’ 칸에, (1) 무엇이 집합이 되기 위한 조건인지, (2) 부분집합 개수가 2ⁿ 인 이유를 ‘각 원소를 넣거나 뺀다’로 설명해 보세요.

확장 탐구

🔭 더 넓게, 더 깊게

배운 것을 옆으로(다른 분야와 잇기) 그리고 아래로(더 근본적인 이유로) 넓혀 봅시다. 정답을 맞히는 시간이 아니라 생각을 키우는 시간이에요.

↔ 수평 확장 · 어디에 쓰일까

검색창에 태그를 걸어 좁혀 가는 일, 데이터베이스의 조건 검색, 생물의 분류 체계(종 ⊂ 속 ⊂ 과)가 모두 집합과 포함관계입니다. 파일 폴더 구조도 포함관계의 그림이죠.

↕ 수직 확장 · 더 근본으로

집합 A의 모든 부분집합을 모은 것을 멱집합 P(A)라 하고 원소는 2ⁿ개입니다. 칸토어는 어떤 집합이든 자기 멱집합보다 작다는 것을 증명했어요. 이 말은 ‘무한에도 더 큰 무한이 있다’는 뜻이고, 여기서 현대 집합론이 시작됩니다.

🧗 도전 질문
원소가 3개인 집합의 부분집합은 8개입니다. 그렇다면 부분집합들의 집합(멱집합)의 부분집합은 몇 개일까요? 2^(2³) 을 계산해 보세요.
