# 극한 조립기 — 수렴하는 수열을 더하고 곱하고 나누면

- slug: calc2-limit-assembler
- topic: 미적분Ⅱ · 수열의 극한
- summary: 수열 카드 두 장을 연산 기계에 끼워 넣어 합·차·실수배·곱·몫의 극한이 각 극한의 합·차·실수배·곱·몫이 되는지 확인하고, ∞/∞ 꼴은 분모의 최고차항으로 나누어 '수렴하는 조각'으로 쪼갠 뒤 조립해 본다.
- 높이: 660

## 핵심 아이디어 (왜 이 조작이 이 성취기준인가)
극한의 성질은 "aₙ→α, bₙ→β 로 **수렴**하면 aₙ±bₙ→α±β, kaₙ→kα, aₙbₙ→αβ, aₙ/bₙ→α/β (bₙ≠0, β≠0)"이다.
학생은 카드(수열)를 기계의 두 슬롯에 끌어 넣고 연산을 바꾸며, 결과 수열의 점들이 기계가 '예측'한 α∘β 선으로 모이는지 본다. (점 모양 표현은 calc2-01-01 띠 활동과 같은 말투를 쓰되, 띠·N 조작은 없다.)
반대로 발산 카드(n, n²)를 넣으면 기계가 "예측 불가(성질을 쓸 수 없음)"를 띄우고, ∞−∞, ∞/∞ 가 여러 값이 될 수 있음을 결과로 보여 준다.
2단계 '분해 작업대'에서 ∞/∞ 꼴 식을 분모의 최고차항으로 나누는 버튼을 누르면 식이 수렴 조각(상수, 1/n, 1/n²)으로 쪼개지고, 각 조각을 극한값 칩으로 바꾼 뒤 성질로 다시 조립해 극한값을 얻는다 — '극한값을 구하는 방법을 설명'에 대응한다.

## 화면 구성
상단 탭 2개: [① 조립기] [② 분해 작업대] + [처음으로].

### ① 조립기
1. 카드 서랍(위쪽 가로 줄, 좁으면 가로 스크롤 대신 2줄 줄바꿈): 카드 7장. 각 카드에 일반항과 작은 점 미리보기.
   - 수렴: 1/n (→0), 2 + 1/n (→2), (n+1)/n (→1), 3 − 2/n (→3), (−1)ⁿ/n (→0)
   - 발산: n (→∞), (−1)ⁿ (진동)
2. 연산 기계(가운데): 슬롯 A ㅡ [연산 단추] ㅡ 슬롯 B. 연산 단추를 누를 때마다 + → − → × → ÷ → k배 순환(k배일 때 슬롯 B 자리가 k 다이얼로 바뀜: −3~3, 0.5 단위).
   - 기계 아래 '예측 판': "lim aₙ = α, lim bₙ = β 이므로 lim(aₙ + bₙ) = α + β = 2" 처럼 성질 한 줄을 채워 보여 줌.
3. 결과 무대(캔버스): 가로축 n = 1~60, 세로축 값. 세 줄의 점을 겹쳐 그림 — aₙ(옅은 파랑, 작게), bₙ(옅은 초록, 작게), cₙ = 결과(진한 보라, 크게). 예측값이 있으면 y = 예측값 점선(보라).
   - 세로 범위: 보이는 세 수열 값과 예측값을 담도록 자동(위아래 10% 여유), 단 [−20, 20] 로 자름. 밖 점은 가장자리 화살표.
4. 상태 줄: "c₆₀ = 2.0167 / 예측 2" 처럼 마지막 보이는 항과 예측값의 차를 숫자로.

### ② 분해 작업대
1. 식 고르기 버튼 3개: (2n+1)/(n+3), (3n²−n)/(n²+5), (n+4)/(n²+1). (모두 ∞/∞ 꼴)
2. 식 판: 큰 글씨 분수식. 아래 버튼 [분모의 최고차항으로 위아래 나누기].
   - 누르면 식이 애니메이션으로 바뀜: (2n+1)/(n+3) → (2 + 1/n)/(1 + 3/n).
3. 조각 칩: 바뀐 식의 각 조각(2, 1/n, 1, 3/n …)이 손으로 누를 수 있는 칩이 됨. 칩을 탭하면 "1/n → 0" 처럼 극한값 칩으로 뒤집힘. 모든 칩을 뒤집으면 성질에 따라 자동 조립: "(2+0)/(1+0) = 2".
4. 작은 무대(캔버스): 원래 식의 점 n=1~60 과 조립 결과 점선. 나누기 전에는 분자·분모 점이 함께 위로 치솟는 것(둘 다 발산)도 옅게 표시.

공통: 힌트 상자(왼쪽 아래, compass-straightedge.html 과 같은 모양), [질문 보기] 접이식 패널, 하단 회색 문구 "화면은 n=60까지의 유한한 항만 보여 줍니다. 극한값은 일반항과 극한의 성질로 정합니다."

## 조작과 반응
- 카드를 슬롯에 끌어 놓으면(또는 카드 탭 → 빈 슬롯에 들어감) → 무대에 그 수열 점이 그려지고, 두 슬롯이 차면 cₙ 점과 예측판이 생긴다. 슬롯의 카드를 끌어 서랍으로 빼면 비워진다.
- 연산 단추를 누르면 → cₙ 점들이 새 연산으로 다시 계산되어 이동(0.3초 보간), 예측 판의 식과 점선이 함께 바뀐다.
- k 다이얼을 돌리면 → cₙ = k·aₙ 점과 예측선 kα 가 함께 늘고 줄며, k=0 이면 모두 0, k<0 이면 위아래로 뒤집힌다.
- 두 카드가 모두 수렴이면 예측판은 초록. 하나라도 발산 카드면 예측판이 회색 "성질을 쓸 수 없어요 — aₙ, bₙ 이 모두 수렴할 때만 쓰는 성질입니다" 로 바뀌고 점선은 사라진다(결과 점은 그대로 그려 학생이 스스로 본다).
- ÷ 에서 B 의 극한이 0 이면(1/n, (−1)ⁿ/n) → 예측판 주황 "β = 0 이라 몫의 성질을 쓸 수 없어요" (결과는 그려 둠).
- 같은 카드를 두 슬롯에 넣는 것 허용(n − n = 0 확인용으로 n 카드는 두 벌).
- ② 탭: 식 버튼 → 식 판·무대 초기화. 나누기 버튼 → 식 변형. 칩 탭 → 극한 칩으로 뒤집힘(다시 탭하면 원래대로). 모든 칩이 뒤집히면 조립식과 점선 표시.
- 모든 끌기·탭 대상 최소 40px. 끌기가 어려운 휴대폰을 위해 '탭으로 넣기'를 기본으로 함께 지원.

## 수학 계산 규칙
- n = 1~60 정수. 0으로 나누기: 카드 중 bₙ = 0 이 되는 항은 없음(1/n, (−1)ⁿ/n 등 모두 n≥1에서 0 아님). 그래도 ÷ 계산에서 |bₙ| < 1e−12 이면 그 점은 그리지 않는다.
- 카드 극한: 1/n→0, 2+1/n→2, (n+1)/n→1, 3−2/n→3, (−1)ⁿ/n→0, n→∞(양의 무한대로 발산), (−1)ⁿ→발산(진동).
- 예측 규칙: A·B 모두 수렴일 때만 α+β, α−β, αβ, kα, α/β(β≠0). 예측값은 정확한 유리수로 표시(예: 2/3 은 "2/3 ≈ 0.667").
- 발산 카드가 들어간 조합의 실제 결과(학생 관찰용, 예측판엔 쓰지 않음):
  - n − n = 0 (수렴), n + n → ∞, n × (1/n) = 1, n ÷ n = 1, n × (−1)ⁿ/n = (−1)ⁿ 진동, (−1)ⁿ × (−1)ⁿ = 1, (−1)ⁿ + (−1)ⁿ 진동.
  → "발산 + 발산"이나 "발산 × 수렴"의 결과는 정해져 있지 않음을 보여 줌.
- (2+1/n)/(1+3/n) 등 변형식:
  - (2n+1)/(n+3) = (2+1/n)/(1+3/n) → (2+0)/(1+0) = 2
  - (3n²−n)/(n²+5) = (3−1/n)/(1+5/n²) → 3
  - (n+4)/(n²+1) = (1/n+4/n²)/(1+1/n²) → 0/1 = 0
  - 나눈 뒤 분모의 극한이 1(≠0)이라 몫의 성질을 쓸 수 있다는 문장을 조립식 아래에 표시.
- 화면 문구에 '유한 단계(n ≤ 60)' 명시(위 공통 문구).

## 안내 문구와 탐구 질문
힌트:
- 시작: "카드 두 장을 기계의 빈칸에 넣어 보세요. 가운데 단추로 더하기·빼기·곱하기·나누기·실수배를 바꿀 수 있어요."
- 수렴+수렴: "보라색 점들이 점선(예측값)으로 다가가나요? 연산을 바꿔도 그런지 보세요."
- 발산 카드가 들어갔을 때: "기계가 예측을 멈췄어요. 그래도 결과 점은 어디로 가는지 직접 보세요. n − n 과 n + n 을 비교해 보세요."
- ÷ 이고 β = 0: "분모가 0으로 가면 몫의 성질을 쓸 수 없어요."
- ② 탭: "분자·분모가 둘 다 한없이 커져서 바로 성질을 쓸 수 없어요. 분모의 최고차항으로 위아래를 나눠 보세요."
- ② 나눈 뒤: "이제 조각마다 극한이 있어요. 칩을 눌러 극한값으로 바꿔 보세요."

탐구 질문:
1. 2 + 1/n 과 3 − 2/n 을 넣고 +, −, ×, ÷ 를 차례로 눌러 보세요. 결과의 극한은 각 극한값 2, 3 으로 어떻게 계산되나요?
2. n 카드 두 장으로 n − n 과 n + n 을 만들어 보세요. 또 n × (1/n) 은요? '∞ − ∞', '∞ × 0' 의 값을 하나로 정할 수 없는 까닭을 말해 보세요.
3. ② 에서 (2n+1)/(n+3) 을 바로 '∞/∞' 로 계산할 수 없는데, 분모의 최고차항 n 으로 나누면 왜 성질을 쓸 수 있게 되나요?
4. (n+4)/(n²+1) 과 (3n²−n)/(n²+5) 의 극한을 비교하세요. 분자와 분모의 차수가 극한값에 어떤 영향을 주나요?

## 점검 포인트
1. 예측판이 A·B 모두 수렴일 때만 α∘β 를 보이고, ÷ 에서는 β ≠ 0 조건까지 확인하는지.
2. 카드 극한값(0, 2, 1, 3, 0)과 발산 분류(n: 양의 무한대, (−1)ⁿ: 진동)가 맞는지.
3. n − n = 0, n + n → ∞, n × (1/n) = 1 처럼 발산 조합의 결과가 실제 값대로 그려지는지(성질이 아닌 관찰로).
4. 세 ∞/∞ 식의 변형과 극한값 2, 3, 0 이 맞고, 변형 후 분모 극한이 1 ≠ 0 임을 명시하는지.
5. '화면은 n=60까지의 유한한 항' 문구가 있는지.
