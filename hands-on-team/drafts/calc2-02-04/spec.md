# 넓이를 지키는 직사각형 — f = q·g 로 몫의 미분법 끌어내기
- id / 과목 / 단원 / 성취기준: calc2-02-04 / 미적분Ⅱ / 미분법 / [12미적Ⅱ-02-04] 함수의 몫을 미분할 수 있다.
- slug: calc2-quotient-rectangle
- topic: 미적분Ⅱ · 함수의 몫의 미분
- summary: 넓이가 f(x), 가로가 g(x)인 직사각형의 세로는 몫 f(x)/g(x)입니다. x 를 조금 움직이면 넓이와 가로가 바뀌고, 세로가 어떻게 따라 바뀌는지 조각 넓이로 따져 몫의 미분법을 만들어 봅니다.
- 높이: 660

## 핵심 아이디어 (왜 이 조작이 이 성취기준인가)
- 몫 q = f/g 는 "넓이 f, 가로 g 인 직사각형의 세로"다. 즉 f = q·g. 학생이 x 를 끌면 넓이와 가로가 정해지고, 세로(몫)는 넓이를 맞추려고 저절로 늘거나 준다.
- x 를 h 만큼 옮기면 새 직사각형은 옛 직사각형 + 오른쪽 띠(q·Δg) + 위쪽 띠(g·Δq) + 모서리 조각(Δq·Δg)으로 나뉜다. 넓이의 늘어난 양 Δf 가 이 세 조각의 합이므로 Δq = (Δf − q·Δg − Δq·Δg)/g.
- h 를 절반씩 줄이면 모서리 조각이 가장 빨리 사라지고, h 로 나누면 q′ = (f′ − q·g′)/g = (f′g − fg′)/g² 이 남는다. 직전 활동(곱의 미분이 들어간 덧셈정리·극한)과 같은 '조각 쪼개기 → h 로 나누기 → 작은 항 버리기' 흐름이다.
- 앞 활동들(단위원·사인 그래프)과 그림 소재가 겹치지 않는다.

## 조작과 반응
- x 손잡이를 끌면 g(x), q(x) 가 바뀌어 직사각형 모양이 즉시 바뀐다(넓이 = f(x) 유지 확인: 결과판 위 작은 글씨 "가로×세로 = f(x)").
- [h 를 절반으로]를 누르면 점선 직사각형이 실선에 다가가고, 세 조각이 얇아진다. 모서리(빨강)가 가장 먼저 안 보이게 된다. 결과판 Δq/h 가 공식값에 다가가며, 최근 4개 값이 한 줄씩 기록된다.
- 띠가 1px 미만으로 얇아지면 그림 옆 확대 창(×배율 표시)으로 모서리 부근을 보여 준다.
- 함수 버튼을 누르면 f, g 가 바뀌고 x, h 초기화.
- [다시]: 현재 함수 유지, x 초기값, h=1, 기록 지움.

## 수학 계산 규칙
- 함수 쌍 (f, g), q = f/g, x 범위(g>0 이 되도록 잡아 직사각형 가로를 양수로):
  ① f=x²+1, g=x+1, x ∈ [0.2, 3], 초기 x=1. q′ = (x²+2x−1)/(x+1)².
  ② f=x, g=x²+1, x ∈ [0.2, 3], 초기 x=1. q′ = (1−x²)/(x²+1)². (x=1 에서 q′=0 — 탐구 질문에 사용)
  ③ f=sin x, g=x, x ∈ [0.3, 3], 초기 x=1. q′ = (x cos x − sin x)/x². (f>0 유지: 범위 상한 3 < π)
  세 경우 모두 범위 안에서 f>0, g>0 이므로 q>0 (직사각형이 항상 1사분면).
- h ∈ {1, 1/2, …, 1/1024}, h≠0. x+h 가 범위 밖이면 h 의 부호를 뒤집어 x−h 를 쓰고 화면에 "h<0" 표시(그래도 g(x±h)>0 은 범위 하한 0.2 − 1 에서 깨질 수 있으므로: x+h, x−h 모두 범위를 벗어나면 h 를 범위 안에 들 때까지 절반으로 줄여 시작).
- Δf = f(x+h)−f(x), Δg = g(x+h)−g(x), Δq = q(x+h)−q(x). 항등식 Δf = q·Δg + g·Δq + Δq·Δg 가 수치로 성립(부동소수 오차 1e−9 이하)해야 함.
- 최소 h 에서 더 누르면 hint 에 "화면에서는 여기까지예요".
- 결과판 아래 작은 글씨: "숫자는 h 를 유한 번 줄인 근삿값이에요. 도함수는 h 를 한없이 0 에 가깝게 할 때의 값입니다."
- 그림 축척: 현재 함수 쌍의 범위 전체에서 g·(q 최대) 가 들어가도록 고정 축척(끌 때 축척이 흔들리지 않게).

## 안내 문구와 탐구 질문
- hint 기본: "x 를 끌어 보세요. 가로는 g(x), 넓이는 f(x)로 정해지고, 세로가 몫 f(x)/g(x)예요."
- hint h 줄일 때: "h 를 절반씩 줄여 보세요. 세 색 조각 중 어느 것이 가장 빨리 사라지나요?"
- 탐구 질문:
  1. 넓이가 Δf 만큼 늘 때, 그 늘어난 넓이는 어떤 세 조각으로 나뉘나요? 식으로 써 보세요.
  2. 양변을 h 로 나누고 h 를 줄이면 빨강 조각 Δq·Δg / h 는 어디로 가나요? 그 결과 q′ 을 f′, g′, q, g 로 나타내 보세요.
  3. q = f/g 를 넣어 정리하면 (f′g − fg′)/g² 이 되나요? 분자의 순서를 바꾸면 무엇이 달라지나요?
  4. ② 에서 x=1 근처를 끌어 보세요. 세로가 가장 길어지는 곳에서 Δq/h 는 어떻게 되나요? f′g 와 fg′ 은 어떤 관계인가요?

## 점검 포인트
1. Δf = q·Δg + g·Δq + Δq·Δg 가 정확한 항등식이며 그림의 세 조각 넓이와 결과판 숫자가 일치하는지.
2. 몫의 미분법 (f/g)′ = (f′g − fg′)/g² (g≠0) 과 세 함수 쌍의 공식값이 맞는지: ① (x²+2x−1)/(x+1)², ② (1−x²)/(x²+1)², ③ (x cos x − sin x)/x².
3. h=1/1024 에서 Δq/h 와 공식값 차이가 약 0.001 이하(전진차분 오차 O(h))인지, 그리고 문구가 '유한 단계 근삿값'임을 밝히는지.
4. 모든 범위에서 g>0, f>0 이라 직사각형이 정의되고 0 나누기가 없는지(③ 의 x 하한 0.3, 상한 3<π).
5. 390·360×660 첫 화면에서 hint·함수 버튼·그림·결과판·조작줄 bottom ≤ 660.
