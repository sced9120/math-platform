두 직선의 평행과 수직

직선 하나를 결정하는 가장 작은 정보는 무엇일까요? 그리고 두 직선이 나란히 가거나 직각으로 만나는 것을, 식만 보고 알 수 있을까요?

기울기 = x가 1 늘 때 y의 증가량, y절편 = x=0에서의 y값.

직선 y = mx + n 은 기울기 m 과 y절편 n, 이 두 수로 완전히 정해집니다.

직선은 무엇으로 정해질까?

① 기울기 + 한 점. 기울기가 3 으로 고정된 직선이, 파란 점을 지나도록 늘 따라옵니다. 점을 드래그 해 보세요 — 그래도 직선은 하나뿐입니다.

② 두 점 (−1, 1), (0, −1)

y절편 = −1 → y = −2x − 1

주어진 것직선의 방정식

평행: 기울기가 같다

두 직선의 기울기 m₁, m₂ 와 y절편 n₁, n₂ 를 바꿔 보세요. 위치 관계가 실시간으로 판정됩니다.

두 직선이 평행 ⟺ 기울기가 같고(y절편은 다름): m₁ = m₂, n₁ ≠ n₂. 기울기·절편 모두 같으면 일치.

수직: 기울기의 곱이 −1

두 직선의 기울기를 바꿔, 곱 m₁ · m₂ 가 −1 이 되는 순간을 찾아보세요. 그때 두 직선은 직각으로 만납니다.

m₂ = −1/m₁ 일 때 수직. (예: m₁=2 → m₂=−0.5)
왜 −1일까? 기울기 m 인 직선의 방향을 90° 돌리면, 방향벡터 (1, m) → (−m, 1) 이 됩니다. 새 기울기는 1/(−m) = −1/m. 따라서 m₁ · m₂ = m · (−1/m) = −1.
⚠️ 이 조건을 쓸 수 없는 경우가 있습니다

직선 x = 2 와 y = 3 은 누가 봐도 수직입니다. 그런데 위 슬라이더로는 이 두 직선을 만들 수 없습니다. 왜일까요?

x = 2 는 기울기가 없습니다(정의되지 않음). m₁ · m₂ = −1 은 두 직선 모두 기울기가 있을 때만 쓸 수 있는 조건이에요.

두 직선이 수직인 경우예판정
둘 다 기울기가 있다y = 2x,  y = −½x + 1m₁ m₂ = −1
하나는 x축에, 하나는 y축에 평행x = 2,  y = 3공식 사용 불가 — 그림으로 판단

일반형 a₁x + b₁y + c₁ = 0, a₂x + b₂y + c₂ = 0 으로 쓰면 수직 조건이 a₁a₂ + b₁b₂ = 0 이 되어 이런 예외가 사라집니다. x = 2 → (a,b) = (1,0), y = 3 → (a,b) = (0,1) 이므로 1·0 + 0·1 = 0 ✓

두 직선의 위치 관계

서로 다른 두 직선 y = m₁x + n₁, y = m₂x + n₂ 의 관계는 다음과 같이 판정합니다.

관계조건교점
한 점에서 만남m₁ ≠ m₂1개
평행m₁ = m₂, n₁ ≠ n₂없음
일치m₁ = m₂, n₁ = n₂무수히 많음
수직m₁ · m₂ = −11개(직각)

이제 아래 ‘내 생각 적기’ 칸에, 평행 조건과 수직 조건을 스스로 정리해 보세요.

확인 문제 직선 y = 2x + 3 에 평행하고 점 (1, 4) 를 지나는 직선, 그리고 수직이고 (1, 4) 를 지나는 직선의 방정식을 각각 구해보세요. (답을 먼저 스스로 → 필요하면 ‘AI 질문’ 탭)

도로·건물 설계, 컴퓨터 화면의 좌표계는 모두 수직인 두 축 위에 세워집니다. 게임에서 캐릭터를 90° 돌리는 것도 ‘수직 방향 찾기’이고, 로봇 팔의 자세 제어도 마찬가지예요.

↕ 수직 확장 · 더 근본으로

기울기 곱이 −1 이라는 조건은, 방향벡터 (1, m₁)과 (1, m₂)의 내적이 0이라는 말과 같습니다: 1·1 + m₁m₂ = 0. ‘수직 = 내적 0’ 은 3차원·n차원에서도 그대로 성립하는 더 근본적인 정의입니다.
