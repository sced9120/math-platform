# 1. 이 플랫폼이 하는 일

한 문장으로: **교사가 활동을 올리고, 학생이 로그인해서 활동하고, AI가 옆에서
"정답 빼고 다" 도와주는** 학급 학습 사이트다.

## 세 종류의 사용자

| 역할 | 하는 일 |
|---|---|
| **학생** | 학번+비밀번호로 로그인 → 배정된 활동 수행 → AI에게 질문·첨삭 |
| **교사** | 학생 계정 일괄 생성, 단원·활동 만들기, 반별 배정, 기록 CSV 다운로드 |
| **관리자** | 교사 계정 관리 + **AI 프롬프트·API 키·모델을 웹 화면에서** 관리 |

관리자도 교사가 겸한다. 우리 학교의 경우 관리자 = 나, 교사 = 나, 민원 담당 = 나다.

## 학생 화면에서 되는 것

- **활동**: GeoGebra 조작, 자료 읽기, 문제 풀기, 사진 제출, HTML 체험형 콘텐츠
- **소크라테스식 문답**: "이 문제 답이 뭐예요?"라고 물으면 AI가 "이차항의 계수가
  양수면 그래프가 어떻게 될까?"라고 되묻는다. 학생들은 처음에 배신감을 느끼지만
  곧 적응한다. 활동 안에서도, 활동과 무관한 **자유 질문 모드**로도 쓸 수 있다
  (단, 수학 학습 관련 주제만 — 잡담을 시도하면 정중히 수학으로 끌려온다).
- **풀이 첨삭**: 텍스트로 쓰거나 **풀이 사진/PDF를 올리면**(끌어다 놓기 지원)
  AI가 단계별로 판정한다. 방식은 두 가지 — 오류를 짚어 주는 첨삭형, 질문으로
  힌트만 주는 발문형. 교사가 낸 문제뿐 아니라 **문제집의 아무 문제나** 올려도 된다.
- **AI 모델 선택**: 관리자가 등록해 둔 모델(GPT·Gemini·Claude 계열) 중에서 고른다.

## 교사·관리자 화면에서 되는 것

- 명단(학년, 반, 번호, 이름) 붙여넣기 → 학생 계정 일괄 생성 + 초기비밀번호 배포
- 단원·활동 만들고 반별로 공개 설정
- **미리보기**: 만든 활동을 학생이 보는 화면 그대로 확인 (GeoGebra·HTML 포함)
- 제출 기록을 학생·반·활동 단위로 골라 CSV(엑셀) 다운로드
- **코드 수정 없이 웹에서**: AI의 성격(프롬프트) 편집, OpenAI·Gemini·Claude API 키
  등록, 학생에게 보여줄 모델 목록 관리

## 비용 걱정에 대한 답 (미리)

- 서버(Vercel)·데이터베이스(Supabase)는 **무료 요금제**로 시작해 학급 규모에선 충분하다.
- AI 사용료만 실비인데, 하루 한도(기본 1인 질문 20회·첨삭 10회, 관리자 화면에서
  조정 가능)가 걸려 있고 같은 질문은 캐시로 재사용한다. 한 반 수업 기준 하루 수천 원 수준.
- 결제 페이지에서 월 한도를 걸어 두면 밤에 몰래 크는 것은 학생뿐, 요금은 아니게 된다.
