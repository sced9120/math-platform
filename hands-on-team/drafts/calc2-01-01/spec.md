# 띠 안에 가두기 — 수열은 어디로 다가갈까

- slug: calc2-sequence-band
- topic: 미적분Ⅱ · 수열의 극한
- summary: 수열의 점들 위에 '가로 띠'를 직접 끌어 놓고 좁혀 보며, 어떤 값 L 둘레의 띠 안에 결국 모든 항이 들어오는지로 수렴과 발산을 판정해 본다.
- 높이: 660

## 핵심 아이디어 (왜 이 조작이 이 성취기준인가)
수렴의 뜻은 "n이 한없이 커질 때 aₙ이 L에 한없이 가까워진다"이다. 학생은 L(띠의 중심선)을 위아래로 끌고, 띠의 폭을 손가락으로 좁힌 뒤, "여기부터는 모두 띠 안" 이 되는 지점 N을 직접 찾는다.
띠를 아무리 좁혀도 그런 N이 매번 생기면 수렴, 어떤 L을 골라도 띠를 좁히면 결국 밖으로 나가는 항이 계속 생기면 발산이다.
발산하는 수열은 다시 '한없이 커짐(양의 무한대)', '한없이 작아짐(음의 무한대)', '진동'으로 나누어 띠에서 벗어나는 모양으로 구별한다.
수열을 바꿔 가며 "판정"을 스스로 내리는 것이 성취기준의 '판정할 수 있다'에 대응한다.

## 화면 구성
1. 상단 막대(#bar): 수열 고르기 버튼 묶음(6개, 좁은 화면에서 줄바꿈) + [처음으로] 버튼.
   - 목록: ① 1/n ② (n+1)/n ③ 2 + (−1)ⁿ/n ④ (−1)ⁿ ⑤ √n ⑥ 1 − n
   - 선택된 수열의 일반항을 막대 오른쪽(좁으면 아랫줄)에 크게 표시: "aₙ = 1/n"
2. 무대(#stage, 캔버스): 가로축 n(1~60), 세로축 aₙ. 각 항은 점 (n, aₙ)으로 찍힌다. 세로 범위는 수열마다 미리 정한 값(아래 계산 규칙) — 화면 밖 항은 위/아래 가장자리에 작은 삼각형 화살표로 표시.
   - 가로 띠: 중심선 y = L (진한 파란 선, 왼쪽 끝에 끌기 손잡이 동그라미), 위아래 경계 y = L ± ε (옅은 파란 칠).
   - 띠 폭 손잡이: 띠 위쪽 경계선 오른쪽 끝의 작은 네모. 위아래로 끌면 ε가 바뀐다(띠는 L 기준 대칭 유지).
   - N 깃발: 가로축 위의 세로 점선 + 깃발. 좌우로 끌어 정수 N에 붙는다(1~60).
   - 점 색: 띠 안 = 파랑, 띠 밖 = 주황. N 이후(n ≥ N) 점 중 띠 밖 점은 빨간 테두리로 강조.
3. 상태 상자(오른쪽 위, 반투명): "L = 0.00 / ε = 0.20 / N = 6" 과 판정 한 줄
   - n ≥ N 의 항(화면 범위 1~60 안)이 모두 띠 안: "✔ N=6 이후 보이는 항은 모두 띠 안" (초록)
   - 아니면: "✘ N 이후에 띠 밖 항 k개" (빨강)
   - 아래 작은 회색 글씨: "화면에는 n=60까지만 보입니다. 그 뒤의 항은 일반항으로 생각해 보세요."
4. 힌트 상자(왼쪽 아래, compass-straightedge.html 과 같은 모양): 단계별 안내 1~2문장.
5. 탐구 질문 접이식 패널(무대 아래 또는 힌트 위 [질문 보기] 버튼): 질문 4개. 정답 입력·채점 없음.
6. 오른쪽 아래 작은 버튼: [N 자동 찾기] — 현재 L, ε 에 대해 n=1~60 범위에서 "그 뒤로 모두 띠 안"이 되는 가장 작은 N을 찾아 깃발을 옮긴다. 없으면 "60까지 안에서는 찾을 수 없어요" 표시.

## 조작과 반응
- 수열 버튼을 누르면 → 점들이 새로 찍히고, 세로 범위가 바뀌며, L·ε·N 이 그 수열의 기본값으로 초기화된다(L=0, ε는 세로 범위의 1/8, N=1).
- 띠 중심선(L 손잡이)을 위아래로 끌면 → 띠가 따라 움직이고 점 색과 판정이 즉시 바뀐다. L은 0.01 단위로 반올림, 정수·간단한 분수 근처(±세로범위의 1%)에서는 그 값에 살짝 붙는다(자석).
- 띠 폭 손잡이를 끌면 → ε 이 바뀐다(최소 0.005, 최대 세로 범위의 절반). 띠가 얇아질수록 띠 밖 점이 늘어나는 것을 본다.
- N 깃발을 좌우로 끌면 → n ≥ N 인 점만 판정 대상이 되고, n < N 인 점은 흐리게(투명도 0.35) 바뀐다. "앞의 몇 항은 상관없다"는 것을 눈으로 본다.
- [N 자동 찾기] → 위 규칙대로 깃발 이동. 수렴 수열에서 ε을 줄이며 반복하면 N이 점점 오른쪽으로 가는 것을 본다.
- 두 손가락 핀치/확대 기능은 넣지 않는다(단순 유지). 모든 손잡이는 터치 영역 최소 32px.
- [처음으로] → 현재 수열의 기본값으로 되돌림.

## 수학 계산 규칙
- 항: n = 1, 2, …, 60 (정수). 각 수열 aₙ:
  - ① 1/n → 0 수렴. 세로 범위 [−0.5, 1.5]
  - ② (n+1)/n → 1 수렴. 범위 [0, 2.5]
  - ③ 2 + (−1)ⁿ/n → 2 수렴(위아래 번갈아 접근). 범위 [0.5, 3.5]
  - ④ (−1)ⁿ → 발산(진동). 범위 [−2, 2]
  - ⑤ √n → 발산(양의 무한대). 범위 [0, 9] (√60 ≈ 7.75 이므로 모두 보임)
  - ⑥ 1 − n → 발산(음의 무한대). 범위 [−62, 3]
- 띠 안 판정: |aₙ − L| < ε (엄격한 부등호. 경계 위 점은 밖으로 친다 — 정의 ‘|aₙ−L|<ε’와 맞춤). 부동소수 비교는 그대로 하되, ④처럼 aₙ이 정확히 ±1이고 L±ε가 정확히 같은 값이 되는 경우를 피하려고 ε 값은 0.005 단위로 반올림한 뒤 화면 비교에 쓴다(경계 일치 시 밖 처리 일관).
- N 자동 찾기: N = (n ≥ N 인 모든 n ≤ 60 에 대해 띠 안)을 만족하는 최소 N. a₆₀ 자체가 밖이면 '없음'.
- 수렴 수열의 실제 최소 N(점검용): ① L=0 일 때 1/n < ε ⇔ n > 1/ε. ② L=1 일 때 1/n < ε. ③ L=2 일 때 1/n < ε. ε=0.1 → N=11, ε=0.05 → N=21, ε=0.02 → N=51, ε=0.01 → N=101(화면 밖: "60까지 안에서는 찾을 수 없어요" — 이때 안내 문구로 '화면이 끝나도 N은 존재한다'를 짚는다).
- 0으로 나누기 없음(n ≥ 1). 화면 밖 값은 클리핑해서 가장자리 화살표로만 표시, 판정에는 실제 값 사용.
- 화면 문구로 반드시 밝힐 것: "화면은 n=60까지의 유한한 항만 보여 줍니다. 수렴·발산은 모든 n에 대한 이야기이므로, 마지막 판정은 일반항으로 합니다."

## 안내 문구와 탐구 질문
힌트(수열 바꿀 때마다 첫 문장으로 돌아감, 상황에 따라 교체):
- 기본: "파란 띠의 가운데 선을 끌어 수열이 다가가는 것 같은 값에 놓아 보세요. 오른쪽 네모로 띠를 좁힐 수 있어요."
- 판정이 ✔ 일 때: "좋아요! 이제 띠를 더 좁혀 보세요. 그래도 어떤 N부터는 모두 띠 안에 들어오나요?"
- N 자동 찾기 실패 시: "60까지 안에는 그런 N이 없어요. 일반항으로 따지면 N이 정말 없을까요, 화면이 짧은 것일까요?"
- ④ 선택 시 추가: "L을 어디에 두어도 띠를 0.5보다 좁히면 어떻게 되는지 보세요."
- ⑤⑥ 선택 시 추가: "띠를 어디에 놓아도 점들이 결국 띠를 뚫고 나가는 방향을 보세요."

탐구 질문(패널):
1. ① aₙ = 1/n 에서 L = 0, ε = 0.1 로 두면 N은 얼마부터인가요? ε = 0.05 이면? ε을 절반으로 줄이면 N은 어떻게 변하나요?
2. ③ 2 + (−1)ⁿ/n 은 2보다 컸다 작았다 합니다. 그래도 2로 수렴한다고 말할 수 있는 이유를 띠로 설명해 보세요.
3. ④ (−1)ⁿ 에서 L을 1, 0, −1 등 여러 곳에 두어 보세요. ε을 충분히 작게 하면 어느 L에서도 '어떤 N 이후 모두 띠 안'이 될 수 없는 까닭은 무엇인가요?
4. ⑤ √n 과 ⑥ 1 − n 은 둘 다 발산합니다. 띠에서 벗어나는 모양은 서로 어떻게 다른가요? 이 둘과 ④의 발산은 어떻게 다른가요? (양의 무한대로 발산 / 음의 무한대로 발산 / 진동)

## 제작 난이도 판단
보통 — 캔버스 한 장에 손잡이 3개(L, ε, N)와 점 60개 판정뿐이라 계산은 단순하지만, 터치 끌기 3종과 좁은 화면 배치·자석 처리에 손이 간다.

## 점검 포인트
1. 띠 안 판정이 |aₙ − L| < ε (엄격 부등호)이며, 판정 대상이 n ≥ N 인 항뿐인지.
2. ③에서 L=2, ε=0.1 일 때 최소 N=11, ε=0.05 일 때 N=21 (1/n < ε ⇔ n > 1/ε) 로 나오는지.
3. ④ (−1)ⁿ 은 ε ≤ 1 이면 어떤 L에서도 두 값 1, −1 을 동시에 띠 안에 넣을 수 없음(|1−(−1)|=2 ≥ 2ε) — 따라서 '자동 찾기'가 항상 실패하는지. (ε > 1 이면 성공할 수 있으나 그것은 수렴의 근거가 아님을 질문 3이 다룸)
4. ⑤ √n 은 양의 무한대, ⑥ 1 − n 은 음의 무한대로 발산, ①②③ 의 극한값이 각각 0, 1, 2 인지.
5. 화면에 '유한 단계(n ≤ 60)만 보임' 문구가 실제로 있는지.
