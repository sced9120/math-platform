무리식과 무리함수

근호 안에 문자가 들어 있고 유리식으로 나타낼 수 없는 식을 무리식, f(x) 가 무리식일 때 y = f(x) 를 무리함수라 합니다.

무리식의 예   √x, √(2x−3), √(4−x²), 1/√(x−2)
정의역 주의! 실수 범위에서 근호 안 ≥ 0 이어야 합니다. 예) y = √(5x+3) 의 정의역은 5x+3 ≥ 0, 즉 {x | x ≥ −3/5}.
실생활 — 지진 해일의 전파 속력 v(m/s)와 수심 h(m) 사이에는 h = v²/9.8 이 성립합니다. 수심 x 에서의 속력을 v 로 나타내면 v = √(9.8x) — 무리함수네요! 깊은 바다일수록 해일이 빨라지는 이유입니다.
기본형

y = ±√(ax) — 네 가지 방향

a 의 부호와 앞의 ± 부호에 따라 뻗는 방향이 네 가지로 갈립니다. 버튼과 슬라이더로 확인하세요.

a > 0 → 오른쪽(x≥0), a < 0 → 왼쪽(x≤0). − 를 붙이면 x축 아래로 뒤집힙니다.
일반형

y = √(ax + b) + c

근호 안이 0 이 되는 점이 시작점입니다: ax + b = 0 → x = −b/a. 거기서부터 a 의 부호 방향으로 뻗어 나가요.

√(ax+b) + c = √( a(x + b/a) ) + c  →  y = √(ax) 를 x축으로 −b/a, y축으로 c 만큼 평행이동한 것!
연결 · 역함수

√ 는 제곱의 역함수

y = √x 와 y = x² (단, x ≥ 0) 는 서로 역함수입니다. 그래서 두 그래프는 직선 y = x 에 대해 거울처럼 대칭이에요.

y = x² (x ≥ 0)  회색
y = √x  초록
y = x  주황 점선
점 (2, 4) ↔ (4, 2) 처럼 좌표가 서로 뒤바뀝니다.
그래서 무리함수의 그래프는 “이차함수의 반쪽을 눕힌 모양”입니다. 정의역·치역도 서로 뒤바뀌죠 — 앞서 배운 역함수 단원과 이어집니다!
정리

정리

y = √(a x + b) + c   (a ≠ 0)
항목내용
시작점(−b/a, c)
정의역a>0 → x ≥ −b/a  /  a<0 → x ≤ −b/a
치역y ≥ c  (앞에 −가 붙으면 y ≤ c)
모양이차함수의 반쪽을 눕힌 곡선(점근선 없음)
유리함수와 비교 — 유리함수는 점근선이 핵심, 무리함수는 시작점과 정의역이 핵심입니다.

아래 ‘내 생각 적기’ 칸에, y = √(ax+b) + c 의 정의역·치역이 a 의 부호에 따라 어떻게 달라지는지 그래프를 움직여 관찰한 내용을 바탕으로 정리해 보세요.

확장 탐구

🔭 더 넓게, 더 깊게

배운 것을 옆으로(다른 분야와 잇기) 그리고 아래로(더 근본적인 이유로) 넓혀 봅시다. 정답을 맞히는 시간이 아니라 생각을 키우는 시간이에요.

↔ 수평 확장 · 어디에 쓰일까

진자의 주기 T = 2π√(L/g), 높이 h 에서 볼 수 있는 최대 거리 d = 3.6√h, 지진 해일의 속도 v = √(9.8h), 자유낙하 시간 — 자연에는 제곱근 관계가 가득합니다. 높이 두 배로 올라도 시야는 √2배만 넓어지죠.

↕ 수직 확장 · 더 근본으로

√x 는 사실 x의 1/2제곱입니다. 지수를 정수에서 분수로 넓히면 무리함수는 거듭제곱함수 y = x^(1/2) 의 한 경우가 되고, 지수함수·로그함수로 자연스럽게 이어집니다. ‘역함수 관점’으로 보면 제곱의 되돌리기이기도 하죠.
