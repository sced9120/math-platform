공통수학2 · 함수

입력과 출력을 뒤집으면?

함수 f 가 x → y 로 보냈다면, 역함수 f⁻¹ 는 그 y 를 다시 x 로 되돌립니다. 버튼으로 화살표 방향을 뒤집어 보세요.

f(1)=2, f(2)=1, f(3)=3 → f⁻¹(2)=1, f⁻¹(1)=2, f⁻¹(3)=3

개념

역함수가 존재하려면?

역함수 f⁻¹ 가 존재하려면 f 가 일대일대응이어야 합니다. (출력이 겹치면 되돌릴 때 어디로 갈지 모르고, 빠진 출력이 있으면 그 값의 역이 없으니까요.)
f⁻¹(f(x)) = x    그리고    f(f⁻¹(y)) = y
  • f 의 정의역 ↔ 치역이 서로 뒤바뀝니다 (f 의 치역 = f⁻¹ 의 정의역).
  • f⁻¹ 의 역함수는 다시 f:   (f⁻¹)⁻¹ = f.
  • f 와 f⁻¹ 를 합성하면 항등함수 I 가 됩니다.
식 구하기

역함수의 식 구하기

예: f(x) = 2x + 1 의 역함수를 구해 봅시다.

  1. y = 2x + 1 로 놓는다.
  2. x 에 대해 푼다:   x = (y − 1) / 2.
  3. x 와 y 를 맞바꾼다:   y = (x − 1) / 2.
  4. ∴ f⁻¹(x) = (x − 1) / 2
그래프

y = f(x) 와 y = f⁻¹(x) 는 y = x 에 대칭

f(x) = ax + b (파랑)와 f⁻¹(x) (초록), 그리고 대칭축 y = x (점선). a, b 를 바꿔도 두 그래프는 항상 y=x 에 대해 거울처럼 대칭입니다.

점 (p, q) 가 f 위에 있으면, (q, p) 는 f⁻¹ 위에 있습니다 — 좌표가 바뀐 거울상!

합성함수의 역함수

순서가 뒤집힌다

(g ∘ f)⁻¹ = f⁻¹ ∘ g⁻¹
‘양말 → 신발’ 순서로 신었다면, 벗을 땐 ‘신발 → 양말’ 순서죠. 합성함수의 역함수도 적용한 순서를 거꾸로 되돌립니다. (f 먼저 g 나중이었으니, 되돌릴 땐 g⁻¹ 먼저 f⁻¹ 나중.)
성질내용
존재 조건f 가 일대일대응
합성f⁻¹∘f = f∘f⁻¹ = I (항등함수)
이중 역함수(f⁻¹)⁻¹ = f
합성의 역함수(g∘f)⁻¹ = f⁻¹∘g⁻¹
그래프y=f(x) 와 y=f⁻¹(x) 는 y=x 에 대칭
정리

정리

  • 역함수 존재 ⟺ f 가 일대일대응
  • 식: y=f(x) → x에 대해 풀고 → x, y 맞바꾸기
  • y=f(x) 와 y=f⁻¹(x) 는 y=x 에 대칭
  • (g∘f)⁻¹ = f⁻¹∘g⁻¹

아래 ‘내 생각 적기’ 칸에, 역함수가 존재하기 위한 조건을 쓰고, y=f(x) 와 y=f⁻¹(x) 의 그래프가 y=x 에 대해 대칭인 이유를 ‘점 (p,q) ↔ (q,p)’ 로 설명해 보세요.

↔ 수평 확장 · 어디에 쓰일까

암호화와 복호화, 로그와 지수, 섭씨↔화씨 변환이 모두 역함수 관계입니다. 현대 암호는 ‘계산은 쉬운데 역은 사실상 불가능한’ 함수(일방향 함수)를 일부러 골라 쓰는데, 이것이 인터넷 보안의 토대예요.

↕ 수직 확장 · 더 근본으로

역함수가 존재할 조건은 일대일대응입니다. 함수를 ‘정보를 잃지 않는 변환’으로 보면, 역함수가 있다는 것은 정보가 보존된다는 뜻이죠. 압축·암호·물리 법칙의 가역성 논의가 모두 이 관점 위에 있습니다.
