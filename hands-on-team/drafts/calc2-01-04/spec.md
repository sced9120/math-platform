# 막대 이어 붙이기 — 무한히 더하면 어디까지 갈까

- summary: 항 aₙ을 길이 막대로 하나씩 자 위에 이어 붙이며 부분합 Sₙ 깃발이 어디로 가는지 보고, 급수의 수렴·발산이 '항'이 아니라 '부분합 수열'로 정해진다는 것과 "aₙ→0 이어도 발산할 수 있다"를 직접 확인한다.
- 높이: 660

## 핵심 아이디어 (왜 이 조작이 이 성취기준인가)
급수 Σaₙ의 수렴은 "부분합 Sₙ = a₁+…+aₙ 이 이루는 수열이 수렴"하는 것이다. 학생은 항을 막대로 하나씩 자 위에 **직접 이어 붙이고**(탭 또는 끌어 놓기), 막대 끝에 꽂힌 Sₙ 깃발의 위치를 아래 그래프(n, Sₙ)에 점으로 남긴다.
같은 화면에 항 그래프(n, aₙ)를 함께 두어, '항이 0으로 가는 것'과 '부분합이 수렴하는 것'을 나란히 비교한다. 조화급수 Σ1/n 에서 막대는 점점 짧아지는데 깃발은 멈추지 않는 장면이 핵심 반례다.
01-01(띠: 수열 수렴의 뜻)·01-03(공비 지도: rⁿ)과 달리, 여기서 학생이 쌓는 것은 '항의 합'이고 판정 대상은 Sₙ 이라는 새 수열이다. 마지막으로 "Σaₙ 수렴 ⇒ aₙ→0", 그 대우 "aₙ↛0 ⇒ 발산"을 판정 도구로 정리한다.

## 화면 구성
1. 상단 막대: 급수 고르기 버튼 6개(좁으면 2줄) + [처음으로]. 오른쪽(좁으면 아랫줄)에 현재 급수 크게: "Σ 1/2ⁿ = 1/2 + 1/4 + 1/8 + …"
   - ① Σ 1/2ⁿ ② Σ 1/(n(n+1)) ③ Σ 1/n ④ Σ (−1)ⁿ⁻¹ ⑤ Σ n/(n+1) ⑥ Σ (2/3)ⁿ⁻¹
2. 자 무대(위쪽 1/3, 캔버스): 가로 자(눈금, 범위는 급수마다 고정). 0에서 시작해 막대가 오른쪽으로(음수 항은 왼쪽으로, 아래 줄로 살짝 내려) 이어 붙는다. 막대 색은 번갈아 두 색, 처음 8개 막대 위에 a₁, a₂ … 이름. 막대 끝에 Sₙ 깃발(빨강). 자 오른쪽 끝을 넘으면 깃발이 가장자리 화살표 + 실제 값.
   - '목표선' 손잡이: 자 위 세로 점선(초록), 학생이 좌우로 끌어 "여기로 다가가는 것 같다"는 값 S를 놓는다.
3. 두 그래프(아래 2/3, 좌우 나란히; 좁은 화면이면 위아래):
   - 왼쪽 "항 aₙ": 점 (n, aₙ), y=0 기준선.
   - 오른쪽 "부분합 Sₙ": 점 (n, Sₙ), 목표선 값 S 를 가로 점선(초록)으로 표시. 가로축 n = 1~50.
4. 상태 상자(자 무대 오른쪽 위): "n = 7 / a₇ = 0.0078 / S₇ = 0.9922 / |S − S₇| = 0.0078"
5. 조작 단추: [+1 항] [+10 항] [끝까지(50항)] [하나 빼기]. 각 40px 이상.
6. 힌트 상자(왼쪽 아래, compass-straightedge.html 과 같은 모양), [질문 보기] 접이식 패널.
7. 하단 회색 문구: "화면은 50번째 부분합까지만 보여 줍니다. 급수의 합은 n→∞ 일 때 Sₙ 의 극한이므로, 판정은 Sₙ 의 일반항이나 성질로 합니다."

## 조작과 반응
- 급수 버튼 → 자·그래프 비움, n=0, S₀=0, 자 범위·그래프 세로 범위 교체, 목표선은 자 가운데.
- [+1 항] 또는 '다음 막대'(자 왼쪽 위 대기 막대)를 끌어 깃발 끝에 놓기 → 막대 하나가 0.25초 미끄러져 붙고, 깃발이 Sₙ 으로 이동, 두 그래프에 점 하나씩 추가.
- [+10 항] / [끝까지] → 빠르게(막대당 0.05초) 연속 추가. [하나 빼기] → 마지막 막대·점 제거.
- 목표선을 끌면 → 부분합 그래프의 가로 점선과 상태 상자의 |S − Sₙ| 가 즉시 바뀐다. 자석: 0, 1, 2, 3, 0.5 근처(자 범위의 1%)에 붙음.
- ③ 조화급수에서 [끝까지] 후 → 힌트가 "막대는 짧아지는데 깃발은 멈췄나요?"로 바뀌고, 작은 [더 멀리 보기] 단추가 나타나 상태 상자에 S₁₀₀, S₁₀₀₀, S₁₀₀₀₀ 값만 숫자로 보여 준다(그래프는 50항 유지).
- ④ 에서 깃발이 1과 0 사이를 왕복 → 부분합 그래프 점이 두 줄로 갈라진다.
- 모든 손잡이 터치 영역 최소 40px. 끌기가 어려운 휴대폰을 위해 [+1 항] 단추가 기본.

## 수학 계산 규칙
- n = 1~50 (정수), Sₙ = Σₖ₌₁ⁿ aₖ 를 누적합으로 계산(double). [더 멀리 보기]의 S₁₀₀·S₁₀₀₀·S₁₀₀₀₀ 도 직접 누적합.
- 급수별 사실·범위(자 / 항 그래프 y / 부분합 그래프 y):
  - ① aₙ = 1/2ⁿ, Sₙ = 1 − 1/2ⁿ → 1 수렴. 자 [0, 1.5], 항 [0, 0.6], 부분합 [0, 1.5]
  - ② aₙ = 1/(n(n+1)) = 1/n − 1/(n+1), Sₙ = 1 − 1/(n+1) → 1 수렴. 자 [0, 1.5], 항 [0, 0.6], 부분합 [0, 1.5]
  - ③ aₙ = 1/n, aₙ→0 이지만 Sₙ → ∞ 발산. S₅₀ ≈ 4.499, S₁₀₀ ≈ 5.187, S₁₀₀₀ ≈ 7.485, S₁₀₀₀₀ ≈ 9.788. 자 [0, 6], 항 [0, 1.1], 부분합 [0, 6]
  - ④ aₙ = (−1)ⁿ⁻¹, Sₙ = 1, 0, 1, 0, … 진동 → 발산(aₙ↛0). 자 [−0.5, 1.5], 항 [−1.5, 1.5], 부분합 [−0.5, 1.5]
  - ⑤ aₙ = n/(n+1) → 1 ≠ 0 이므로 발산(Sₙ → ∞, Sₙ > n/2). 자 [0, 50], 항 [0, 1.1], 부분합 [0, 50]
  - ⑥ aₙ = (2/3)ⁿ⁻¹, 첫째항 1, 공비 2/3 → 합 3 수렴. Sₙ = 3(1 − (2/3)ⁿ). 자 [0, 3.5], 항 [0, 1.1], 부분합 [0, 3.5]
- 음수 항(④)은 막대를 왼쪽으로 그린다. 0으로 나누기 없음(n ≥ 1).
- 판정 문구는 화면에 자동으로 띄우지 않는다(학생이 판정). 단 [끝까지] 후 상태 상자 아래 회색으로 "이 급수의 합: 1" / "발산" 을 보이는 [답 보기] 작은 단추만 둔다(채점·저장 없음).
- 반드시 지킬 표현: "aₙ→0 이면 수렴"이라고 쓰지 않는다. 쓰는 문장은 "급수가 수렴하면 aₙ→0" 과 "aₙ 이 0으로 수렴하지 않으면 급수는 발산" 뿐.

## 안내 문구와 탐구 질문
힌트:
- 시작: "[+1 항]을 눌러 막대를 하나씩 이어 붙여 보세요. 빨간 깃발이 지금까지의 합 Sₙ 이에요."
- 몇 항 뒤: "초록 목표선을 깃발이 다가가는 것 같은 곳으로 끌어 놓아 보세요."
- ①②⑥ 끝까지: "깃발이 목표선에 한없이 가까워지나요? 그렇다면 그 값이 급수의 합이에요."
- ③ 끝까지: "막대는 점점 짧아져 0에 가까워지는데, 깃발은 멈췄나요? [더 멀리 보기]로 확인해 보세요."
- ④: "깃발이 왔다 갔다 해요. Sₙ 이 한 값에 다가가지 않으면 급수는 어떻게 될까요?"
- ⑤: "막대 길이가 1에 가까워져요. 거의 1씩 계속 더하면 깃발은 어디로 갈까요?"

탐구 질문:
1. ① 과 ② 는 막대 모양이 다른데 깃발은 둘 다 1에 다가갑니다. 급수의 합은 무엇의 극한인가요? (부분합 Sₙ 의 극한)
2. ③ 의 항 그래프와 부분합 그래프를 비교해 보세요. 항이 0으로 가는데도 급수가 발산할 수 있나요?
3. ④ 와 ⑤ 는 항이 0으로 다가가지 않습니다. 이런 급수가 수렴할 수 없는 까닭을 깃발의 움직임으로 설명해 보세요. (수렴하면 aₙ = Sₙ − Sₙ₋₁ → S − S = 0)
4. 여섯 급수를 '수렴(합)'과 '발산'으로 나누어 보세요. 'aₙ 이 0으로 가는지'만으로 판정이 끝나는 것은 어느 쪽인가요?

## 제작 난이도 판단
보통 — 계산은 누적합뿐이지만 자·두 그래프·막대 애니메이션·목표선 손잡이를 좁은 화면에 함께 배치하고 급수마다 다른 범위를 관리해야 한다.

## 점검 포인트
1. 부분합 공식: ① 1 − 1/2ⁿ, ② 1 − 1/(n+1), ⑥ 3(1 − (2/3)ⁿ) 와 화면 누적합이 일치하는지, 합이 각각 1, 1, 3 인지.
2. 조화급수 수치: S₅₀ ≈ 4.499, S₁₀₀ ≈ 5.187, S₁₀₀₀ ≈ 7.485, S₁₀₀₀₀ ≈ 9.788 (확인 필요: 소수 셋째 자리까지 구현값으로 대조).
3. 문구가 "수렴 ⇒ aₙ→0", "aₙ↛0 ⇒ 발산" 만 말하고 그 역을 말하지 않는지.
4. ④ 부분합이 1, 0, 1, 0 … 으로 진동(발산)하고, ⑤ 의 aₙ → 1 이 발산 근거로 쓰이는지.
5. 유한 단계(50항) 문구가 화면에 있는지.
