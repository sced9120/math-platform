# 7. 운영 팁 — 비용·보안·자주 막히는 곳

만드는 것보다 굴리는 것이 진짜다. 담임 업무와 같다.

## 7-1. 비용 통제 — 잠은 편히 자자

AI 사용료만 실비이고, 나머지(Vercel·Supabase)는 학급 규모에선 무료 요금제로 충분하다.
이 시스템에는 요금 폭탄 방지 장치가 이미 들어 있다:

- **일일 한도**: 학생 1인당 하루 질문 20회, 첨삭 10회가 기본값. 관리자 화면
  "AI 키·모델"에서 언제든 조정할 수 있다 (초과 시 내일 다시 오라고 안내)
- **응답 캐시**: 같은 활동에서 같은 질문이 오면 AI를 다시 부르지 않고 저장된 답 재사용
- **서버에서만 호출**: 학생 브라우저에는 키가 없으므로 키를 훔쳐 마음껏 쓰는 일이 불가능

그래도 이것 하나는 꼭 하자: **AI 제공자 결제 페이지에서 월 사용 한도(hard limit) 걸기.**
5분 걸리고, 최악의 시나리오가 "이번 달 AI 그만"으로 바뀐다.

## 7-2. 보안 — 세 문장 요약

1. **`.env.local`과 `service_role` 키는 절대 공유 금지.** 노출됐다면 Supabase
   대시보드에서 즉시 rotate(재발급)한다.
2. 문제 정답은 학생에게 **어떤 경로로도 내려가지 않는다** (채점은 DB 안에서 수행).
   AI 프롬프트를 바꿔도 이 구조는 유지된다.
3. 학생 데이터가 외부 AI로 전송되므로 **학생·보호자 고지와 동의**를 갖출 것.
   동의 화면은 시스템에 이미 들어 있다 — 학교 개인정보 방침 확인은 여러분 몫이다.

## 7-3. 학기 운영 루틴

| 시기 | 할 일 |
|---|---|
| 학기 초 | 명단 붙여넣기 → 학생 계정 일괄 생성 → 초기비밀번호 인쇄 배포 |
| 수업 전 | 활동 만들고 **공개 토글 켜기** (안 켜면 학생 눈에 안 보인다 — 최다 빈출 실수) |
| 수업 전 | 사이트에 미리 한 번 접속 (첫 요청은 서버가 깨어나느라 느리다) |
| 수업 후 | 기록 다운로드에서 CSV 뽑아 확인 |
| 방학 | 아무것도 안 해도 된다. 무료 요금제는 방학도 무료다 |

## 7-4. 자주 막히는 곳

| 증상 | 해결 |
|---|---|
| `npm` 명령을 모른다고 나옴 | Node.js 미설치. [nodejs.org](https://nodejs.org)에서 LTS 설치 후 터미널 재실행 |
| 배포는 됐는데 로그인이 안 됨 | Vercel에 환경변수를 등록 안 했거나, DB SQL을 실행 안 함 |
| AI가 "동의가 필요합니다"만 뜸 | 학생이 첫 사용 시 동의 버튼을 눌러야 함 (정상 동작) |
| AI가 응답하지 않음 | 관리자 "AI 키·모델"에서 키가 등록됐는지, 모델이 켜져 있는지 확인 |
| AI 응답이 느림 | 첫 요청은 서버 기동 때문에 느림. 수업 전 미리 접속해 두기 |
| 화면이 안 뜨고 오류 | 코드 오타. `git checkout .` 으로 마지막 정상 상태로 복귀 |
| 새 모델을 추가했는데 학생에게 안 보임 | 모델의 "사용" 토글 확인 + 해당 제공자 키 등록 여부 확인 |

**만능 해결책**: 오류 메시지를 통째로 복사해 클로드에게 "이거 고쳐줘".
이 책에서 가장 많이 반복된 문장이지만, 실제로 가장 많이 쓰게 될 문장이다.

## 7-5. 다른 선생님과 나누기

이 시스템은 코드가 전부 공개되어 있으니 마음껏 나누자.

- **링크 하나면 된다**: https://github.com/sced9120/math-platform
  받는 분은 README의 Deploy 버튼으로 **자기만의 독립된 사이트**를 만든다.
  여러분의 사이트·데이터·요금과는 완전히 무관하다.
- **같이 주면 좋은 것**: 이 책 링크. "2장부터 보세요"라는 말과 함께.
- **절대 주면 안 되는 것**: `.env.local`, API 키, 관리자 비밀번호.
  "코드는 공유, 열쇠는 각자" — 이 원칙 하나면 충분하다.

## 맺음말

여기까지 왔다면 여러분은 학습 플랫폼을 **가진** 교사가 아니라
**만들고 고칠 줄 아는** 교사다. 둘의 차이는 크다. 전자는 업체에 전화를 걸고,
후자는 클로드에게 한국어로 말한다.

다음 학기, 여러분의 교실에서 학생이 AI에게 "답 알려줘"라고 조르다
결국 스스로 풀어내는 장면을 보게 되길 바란다. 그 장면이 이 책의 전부다.
