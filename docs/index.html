각 활동은 설치도 로그인도 없이 브라우저에서 바로 열립니다. 점을 끌어 보고 슬라이더를 움직이면 값과 식이 실시간으로 바뀝니다. 수업 중 화면에 띄우거나, 학생에게 링크를 그대로 보내 주셔도 됩니다.
