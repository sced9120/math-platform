# 위키독스 원고 사용법

이 폴더의 파일들이 위키독스 책 한 권 분량의 원고다.
파일 하나 = 위키독스 페이지(챕터) 하나. **번호 순서대로** 페이지를 만들고
내용을 그대로 복사해 붙여넣으면 된다. (위키독스는 마크다운을 그대로 지원한다)

## 추천 책 제목 (하나 고르기)

1. **코드 한 줄 몰라도 됩니다 — 수학 교사의 AI 학습 플랫폼 만들기** ← 추천
2. 칠판 대신 배포 버튼 — 교사를 위한 AI 학습 플랫폼 DIY
3. 우리 반 전용 AI 튜터 만들기 — 코드는 클로드가 짭니다

## 챕터 구성

| 순서 | 파일 | 위키독스 페이지 제목 |
|---|---|---|
| 머리말 | `00_머리말.md` | 머리말 — 수학 교사가 이걸 왜 만들었나 |
| 1 | `01_이_플랫폼이_하는_일.md` | 1. 이 플랫폼이 하는 일 |
| 2 | `02_10분_만에_내_것으로.md` | 2. 가장 빠른 길 — 10분 만에 내 학교 것으로 |
| 3 | `03_처음부터_만들기.md` | 3. 처음부터 만들기 — 클로드 코드와 페어코딩 |
| 4 | `04_연결하고_배포하기.md` | 4. 연결하고 배포하기 |

| 6 | `06_구조_이해하고_고치기.md` | 6. 구조 이해하고 직접 고치기 |

바쁘면 **머리말 + 2장 + 5장**만 올려도 "복사해서 자기 교과로 쓰기"까지는 전달된다.
나머지는 여유 있을 때 채워도 된다.
