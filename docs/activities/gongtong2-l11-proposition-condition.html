Q2. 명제가 아니지만 ‘논의를 할 만한’ 문장은?

‘운동장은 매우 넓다.’ 입니다. ‘넓다’의 기준이 없어 명제가 아니지만, 기준을 정하면 명제가 됩니다. 예) ‘운동장의 넓이는 5000 m² 이상이다.’

조건 → 진리집합

문자를 포함하는 문장이나 식이 문자의 값에 따라 참·거짓이 정해질 때, 이를 조건이라 합니다. 전체집합 U의 원소 중 그 조건을 참이 되게 하는 모든 원소의 집합이 진리집합입니다.

전체집합 U = { x | x 는 10 이하의 자연수 } 로 통일합니다. 아래 조건을 눌러 진리집합을 확인해 보세요.
교과서 본문 예시
  • 자연수 전체의 집합에서 조건 ‘p : x 는 16의 약수이다’ 의 진리집합은 P = { 1, 2, 4, 8, 16 }
  • 조건 ‘q : x 는 10 이하의 짝수이다’ 의 진리집합은 Q = { x | x 는 10 이하 짝수 } = { 2, 4, 6, 8, 10 }
Q4. 집합들 사이의 관계는?

①과 ②가 서로 여집합, ③과 ④도 서로 여집합입니다. U 안에서 두 집합을 합치면 U 가 되고, 겹치는 부분은 없습니다.

조건 p 의 진리집합이 P 이면, ~p 의 진리집합은 Pc

부정 ~p 와 여집합

용어뜻
명제참, 거짓을 명확하게 판별할 수 있는 문장이나 식
조건문자를 포함하는 문장이나 식이 그 문자의 값에 따라 참, 거짓이 정해질 때 그 문장이나 식
진리집합전체집합 U 의 원소 중에서 어떤 조건이 참이 되게 하는 모든 원소의 집합
부정명제 또는 조건 p 에 대하여 ‘p 가 아니다’ — 기호로 ~p (not p)

명제 또는 조건 p 에 대하여 ‘p 가 아니다’를 p 의 부정이라 하고 ~p (not p) 로 씁니다.

원래 조건 p부정 ~p
x > 2x ≤ 2  ‘크지 않다’ 는 ‘작거나 같다’
x = 3x ≠ 3
√2 는 무리수이다√2 는 무리수가 아니다 (거짓)
~(~p) 는 p — 두 번 부정하면 제자리로
전체집합 U 에서 ~p 가 참이 되게 하는 원소는 P 의 원소가 아닌 것들입니다. 그래서 ~p 의 진리집합 = Pc 입니다.

‘그리고’와 ‘또는’ 을 부정하면

자연수 전체에서 두 조건 p : x 는 6의 약수, q : x 는 8의 약수 를 생각합시다. P = {1, 2, 3, 6}, Q = {1, 2, 4, 8} 입니다.

‘p 그리고 q’ 의 부정 = ‘~p 또는 ~q’
‘p 또는 q’ 의 부정 = ‘~p 그리고 ~q’
실수 전체에서 한 번 더

조건 p : (x + 2)(x − 4) = 0 의 진리집합은 P = { −2, 4 } 입니다.

이때 부정은 ~p : (x + 2)(x − 4) ≠ 0 이고, 그 진리집합은 Pc = { x | x ≠ −2 이고 x ≠ 4 인 실수 } 입니다.

‘= 0’ 의 부정이 ‘≠ 0’ 이고, ‘−2 또는 4’ 의 부정이 ‘−2 도 아니고 그리고 4 도 아니다’ 로 바뀌는 것에 주목하세요.

집합으로 보면 드모르간의 법칙

(P ∩ Q)c = Pc ∪ Qc  ·  (P ∪ Q)c = Pc ∩ Qc
집합에서 배운 그 법칙이 말로 옮겨진 것뿐입니다. ‘또는’의 여집합은 ‘둘 다 아니다’ — 기억나시나요?

진리집합으로 판별하기

‘모든 x 에 대하여 p 이다’ → P = U 이면 참
‘어떤 x 에 대하여 p 이다’ → P ≠ ∅ 이면 참

전체집합 U = { 1, 2, 3, 4 } 에서 네 명제를 확인해 봅시다. 명제를 눌러 보세요.

‘모든’은 하나라도 어긋나면 거짓, ‘어떤’은 하나만 맞으면 참입니다. 그래서 ‘모든’을 무너뜨릴 때는 반례 하나면 충분합니다.

조건을 바꾸어 참인 명제 만들기

명제 1 — ‘모든 실수 x 에 대하여 x² = 4 이다.’

조건 ‘p : x² = 4’ 의 진리집합은 P = { −2, 2 } 이고 U 는 실수 전체입니다. P ≠ U 이므로 이 명제는 거짓입니다. 반례: x = 1 일 때 1 ≠ 4

조건을 바꾸어 참인 명제를 만들어 봅시다. 아래를 눌러 확인하세요.

명제 2 — ‘어떤 실수 x 에 대하여 x² + 3 ≤ 0 이다.’

x² ≥ 0 이므로 x² + 3 ≥ 3 > 0. 진리집합은 P = ∅ 이고, ‘어떤’ 명제는 P = ∅ 이면 거짓입니다.

명제 (1) ‘우리 반의 모든 학생은 걸어서 등교한다.’ 를 부정하면 무엇이 될까요?

아래 두 문장 중, 부정한 명제에 가까운 쪽을 골라 보세요.

왜 (3)은 아닐까?

‘모든 학생이 걸어서 등교한다’ 가 틀렸다는 말은, ‘모든 학생이 교통수단을 이용한다’ 는 정반대의 주장이 아닙니다.

걸어서 오지 않는 학생이 한 명이라도 있으면 원래 명제는 무너집니다. 그래서 부정은 ‘어떤 학생은 걸어서 등교하지 않는다’ 입니다.

‘모든 x 에 대하여 p’ 의 부정 → ‘어떤 x 에 대하여 ~p’
‘어떤 x 에 대하여 p’ 의 부정 → ‘모든 x 에 대하여 ~p’

진리집합으로 보면 (교과서 86쪽) — ‘P = U’ 의 부정은 ‘P ≠ U’, 즉 Pc ≠ ∅ 이고, ‘P ≠ ∅’ 의 부정은 ‘P = ∅’, 즉 Pc = U 입니다.

부정하고, 참·거짓까지

다음 명제의 부정을 말하고, 그것의 참·거짓을 판별하시오. 먼저 스스로 해 본 뒤 여세요.

원래 명제부정부정의 참거짓
(1) 모든 실수 x 에 대하여
   | x − 2 | > 0 이다.
(2) 어떤 실수 x 에 대하여
   x² = x + 1 이다.
까닭

(1) x = 2 일 때 | x − 2 | = 0 이므로 원래 명제는 거짓. 따라서 그 부정은 참입니다. 거짓의 부정은 참

(2) x² − x − 1 = 0 의 판별식 D = 1 + 4 = 5 > 0 이라 실근이 있습니다. 원래 명제가 참이므로 그 부정은 거짓입니다.

🧩 찬우와 지영, 누구의 방법으로?

문제 — 명제 ‘어떤 실수 x 에 대하여 x² − 8x + a ≤ 0’ 이 거짓이 되도록 하는 실수 a 의 값의 범위를 구하시오.
찬우 — 주어진 명제가 거짓이라면, 조건 x² − 8x + a ≤ 0 에 대한 진리집합이 공집합이어야 해. 그러니까…
지영 — 어떤 명제가 거짓이면, 그 명제의 부정은 참이야! 주어진 명제의 부정이 참이라는 사실을 이용해서 풀어 보면…
두 길은 같은 곳에서 만납니다

찬우의 길 — P = ∅ 이려면 x² − 8x + a ≤ 0 을 만족하는 실수가 없어야 합니다. 즉 모든 실수에서 x² − 8x + a > 0. 판별식 D/4 = 16 − a < 0 → a > 16

지영의 길 — 부정은 ‘모든 실수 x 에 대하여 x² − 8x + a > 0’ 이고 이것이 참이어야 합니다. 같은 판별식 조건 → a > 16

답   a > 16

‘어떤 ~ 이다’ 가 거짓 = 진리집합이 공집합 = ‘모든 ~ 이 아니다’ 가 참. 세 표현이 같은 말입니다.
