합성함수의 정의

두 함수 f : X → Y, g : Y → Z 의 합성함수는
g ∘ f : X → Z,   (g ∘ f)(x) = g( f(x) )
합성할 수 있으려면

f 의 치역이 g 의 정의역의 부분집합이어야 합니다. f 가 뱉은 값을 g 가 받을 수 있어야 하니까요.

환전으로 치면 — f 가 내놓는 것이 유로인데 g 가 엔화만 받는다면 이어 붙일 수 없겠죠.

읽는 순서에 주의! g ∘ f 는 f 를 먼저, 그 다음 g 입니다. 기호는 g 가 앞에 있는데 계산은 f 가 먼저예요. g(f(x)) 의 괄호 안쪽부터 푼다고 생각하세요.

순서를 바꾸면 달라진다

두 함수 f(x) = x − 1, g(x) = x² + 1 로 식을 직접 구해 봅시다.

일반적으로   g ∘ f ≠ f ∘ g
함수의 합성에서는 교환법칙이 성립하지 않습니다.
교과서 예제 1 — 두 함수 f(x) = 2x² − 3, g(x) = x² + 5 에 대하여
(1) (f ∘ g)(x)
(2) (g ∘ f)(x)

안쪽 함수의 식을 통째로 바깥 함수의 x 자리에 넣습니다. 이번엔 둘 다 이차식이라 4차식이 나옵니다 — 전개하기 전에 괄호째로 넣는 것이 먼저예요.

두 답이 전혀 다르죠. 이것이 바로 g ∘ f ≠ f ∘ g 입니다.

🥤 어느 할인을 먼저 받을까?

어느 카페에서 천 원 할인(음료 주문 시 1000원 할인)과 포장 할인(포장하면 반값)을 함께 운영합니다. 정가가 x 원인 음료를 주문하려고 합니다. (x > 2000)

f(x) = x − 1000  (천 원 할인)   /   g(x) = ½ x  (포장 할인)
정리해 봅시다

포장 먼저 → 천 원 할인
(f ∘ g)(x) = f( ½x ) = ½x − 1000

천 원 할인 먼저 → 포장
(g ∘ f)(x) = g( x − 1000 ) = ½x − 500

(g ∘ f)(x) − (f ∘ g)(x) = 500

포장 할인을 먼저 받는 것이 언제나 500원 더 쌉니다. 정가에 관계없이 차는 늘 500원이에요.

왜 그럴까? 천 원 할인을 먼저 받으면 그 1000원까지 반으로 깎여 500원의 효과밖에 못 냅니다. 앞의 이중 환전은 두 함수가 모두 곱셈이라 순서를 바꿔도 같았지만, 여기는 곱셈과 뺄셈이 섞여 순서가 중요해집니다.

결합법칙
✍️ 학생이 직접 푸는 화면📄 교과서 115쪽 [함께 완성하기] · 학습지 6 · 1-02 ① ◑ 추가 문제

괄호를 옮겨도 될까?

세 함수에 대하여 f ∘ (g ∘ h) 와 (f ∘ g) ∘ h 가 같은지 확인해 봅시다. 아래에서 함수 묶음을 골라 보세요.

f ∘ (g ∘ h) = (f ∘ g) ∘ h
함수의 합성에서는 결합법칙이 성립합니다.
그래서 괄호 없이 f ∘ g ∘ h 라고 써도 됩니다. 어디에 괄호를 넣든 결과가 같기 때문이에요. 단, 순서를 바꾸는 것은 안 됩니다 — 교환법칙은 성립하지 않으니까요.

(1) (g ∘ f)(x)

4. 세 함수 f, g, h 에 대하여 (g ∘ f)(x) = 4x − 3, h(x) = x² + x 일 때 ((h ∘ g) ∘ f)(x) 를 구하시오.

결합법칙에 의해 ((h∘g)∘f)(x) = (h∘(g∘f))(x) = h( (g∘f)(x) )

= h(4x − 3) = (4x−3)² + (4x−3)

f(2) + (f∘f)(2) + (f∘f∘f)(2) 의 값은?

⚙️ 점의 여행 — 합성함수의 그래프

첫 출력이 다음 입력으로. 마지막 점의 가로좌표는 다시 처음의 x 입니다. 이 한 줄이 합성함수 그래프의 전부입니다.

그리는 요령 4단계
  • ① 왼쪽 위에서 x 를 넣어 중간값을 얻는다
  • ② 그 중간값을 오른쪽 위 그래프의 가로축에 넣는다
  • ③ 나온 값이 최종값
  • ④ 아래 좌표평면에 (처음 x, 최종값) 을 찍는다 — 중간값은 쓰지 않는다

④ 가 가장 많이 틀리는 곳입니다. 가로좌표에 중간값을 찍으면 안 됩니다. 반드시 처음 x 입니다.

순서를 뒤집어 보세요. 회색 빈 원으로 이전 순서의 자취가 남습니다. 입력이 똑같은데 자취가 달라진다면, 그것이 f∘g ≠ g∘f 의 그림 증거입니다.

📐 꺾이는 곳에서 자른다 — n축 방식

식이 없고 그래프만 주어져도 합성함수를 그릴 수 있습니다. 비결은 한 가지입니다 — 바깥 함수가 꺾이는 높이를 안쪽 함수 위에 그어 보고, 그 높이에 닿는 x 를 경계로 정의역을 잘라 구간마다 따로 합성하는 것입니다.

n축 방식 네 단계
  • ① 바깥 함수가 꺾이는 가로좌표 u = k 를 찾는다
  • ② 안쪽 함수 그래프에 y = k 를 그어 만나는 x 를 모두 찾는다
  • ③ 그 x 들과 안쪽이 꺾이는 x 로 정의역을 n 개 구간으로 자른다
  • ④ 구간마다 안쪽 식을 바깥 식의 자리에 넣어 합성식을 쓰고, 양 끝점을 찍어 잇는다

왜 자르나요? 한 구간 안에서는 안쪽 값이 바깥 함수의 같은 조각 위에만 머무릅니다. 그래야 식 하나로 쓸 수 있어요. 구간이 바뀌는 순간 쓰는 식이 바뀌므로 그래프가 꺾입니다.

경계는 두 종류입니다. ⓐ 안쪽이 k 에 닿는 x (바깥의 조각이 바뀜) ⓑ 안쪽이 스스로 꺾이는 x (안쪽의 조각이 바뀜). 둘을 모두 모아야 구간이 빠지지 않습니다.
직선 조각끼리 합성하면 결과도 직선 조각입니다. 그래서 양 끝점만 찍어 이으면 끝납니다.

🚗 자동차 연비 — 합성함수로 잇기

주행 성능 검사 중인 어느 자동차의 검사 시작 t 시간 후의 속도 v km/h 가
v(t) = 400t + 60  (0 ≤ t ≤ 0.2)

이고, 이 자동차의 속도 x km/h 에서의 연비 r km/L 가

(1) t 시간 후의 연비는 (r ∘ v)(t) = r( v(t) ) 입니다.

(r ∘ v)(t) = −0.003(400t + 60)² + 0.48(400t + 60) + 2.3

(2) 먼저 연비가 21.5 가 되는 속도를 구합니다.

양변에 −1000/3 을 곱하면   x² − 160x + 6400 = 0 → (x − 80)² = 0 → x = 80

이제 v(t) = 80 을 풀면   400t + 60 = 80 → t = 0.05 시간
