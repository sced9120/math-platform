도형을 대칭시키기

비대칭인 ‘ㄱ’ 모양 깃발(회색)을 기준별로 대칭시켜 봅니다(파랑). 버튼을 눌러 기준을 바꿔 보세요.

회색이 원래 도형, 파랑이 대칭이동한 도형입니다. 점선은 대칭축(또는 중심).
정리 · 도형
🖥 보여주며 조작📄 학습지 3-02 Q5 도형의 대칭이동 규칙

도형 f(x, y) = 0 의 대칭이동

기준이동한 도형
x축f(x, −y) = 0
y축f(−x, y) = 0
원점f(−x, −y) = 0
직선 y=xf(y, x) = 0
점의 이동과 완전히 같습니다! 도형은 “그 도형 위의 모든 점”을 옮긴 것이므로, 점에 적용한 규칙(부호 반대 / 자리 바꿈)을 방정식의 x, y 자리에 그대로 넣으면 됩니다. (평행이동과 달리 부호를 되돌리는 −a 가 아니라, x→−x 처럼 변수 자체를 바꿔치기합니다.)

두 대칭을 이으면 무엇이 될까?

대칭을 두 번 연달아 하면 전혀 다른 이동이 됩니다. 두 개를 골라 결과를 확인해 보세요. 회색 F → 연한 파랑(1차) → 진한 파랑(2차) 순서로 움직입니다.

꼭 확인해 볼 조합
① x축 → y축  (순서를 바꿔도 같은가?)
② x축 → y = x  /  y = x → x축  (이 둘은 다를까?)
③ 원점 → y = x  (생각지 못한 대칭축이 나옵니다)
④ 같은 대칭을 두 번 (예: x축 → x축)

🖥 보여주며 조작📄 학습지 3-02 Q7 포물선의 대칭이동

포물선 y = x² + 1 은 어떻게 될까?

버튼을 눌러 네 가지 대칭의 식을 확인하세요. 하나는 아무 일도 일어나지 않습니다. 어느 것인지, 그리고 왜 그런지 찾아보세요.

y = x 대칭의 결과 x = y² + 1 은 y 에 대한 이차식이라 옆으로 누운 포물선이 됩니다. 이것은 함수가 아닙니다(x 하나에 y 가 둘). 도형의 방정식 f(x, y) = 0 으로 다루는 이유예요.

생각 키우기 · 이동의 순서
🖥 보여주며 조작📄 학습지 3-02 [생각 키우기] 순서를 바꾸면?

🔁 순서를 바꾸면 결과도 바뀔까?

포물선 y = x² 에 평행이동과 x축 대칭이동을 차례로 적용합니다. 순서만 바꿔 보면 어떻게 될까요?

두 결과는 왜 다를까?

x축 대칭은 y 의 부호를 뒤집는 조작입니다. 먼저 위로 b 만큼 올려 두고 뒤집으면 그 b 까지 함께 뒤집혀 −b 가 되지만, 먼저 뒤집고 나서 올리면 b 는 그대로 남습니다.
경로① 꼭짓점 (a, −b)  /  경로② 꼭짓점 (a, +b)

그래서 y 축 방향 이동이 0 일 때(= x축 방향으로만 옮길 때) 순서를 바꿔도 결과가 같습니다. b ≠ 0 이라면, 대칭을 먼저 한 쪽의 y 이동량을 −b 로 바꾸면 두 결과가 같아집니다.

도형의 이동은 순서를 마음대로 바꿀 수 없다 — 이것이 이 활동의 결론입니다.
