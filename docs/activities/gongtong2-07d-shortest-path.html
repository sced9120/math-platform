🚶 강가에 물 뜨러 가기

마을 A 에서 출발해 강(x축)에서 물을 뜬 뒤 마을 B 로 갑니다. 강 위의 어느 지점 P 에 들러야 가장 짧게 갈 수 있을까요?

P 를 좌우로 드래그하며 거리 합을 직접 줄여 보세요.

지금까지 최소
—

어림짐작으로 찾기는 꽤 어렵습니다. 다음 화면에서 대칭이동을 쓰면 계산 없이 단번에 찾을 수 있어요.

대칭의 마법

B 를 강 건너로 뒤집으면?

마을 B(3, 5) 를 강(x축)에 대해 대칭이동한 점을 B′(3, −5) 라 합시다. P 가 강 위에 있으면 PB = PB′ 이므로,

AP + PB  =  AP + PB′  ≥  AB′

즉 A, P, B′ 가 한 직선 위에 있을 때가 최소! 아래 토글을 켜서 확인해 보세요.

왜 PB = PB′ 일까? P 는 x축 위의 점이고, B 와 B′ 은 x축에 대해 대칭입니다. 대칭이동은 거리를 바꾸지 않으므로(합동변환) 대칭축 위의 점에서 잰 거리는 항상 같습니다.
빛도 같은 길로 간다

입사각 = 반사각

거울에 빛을 비추면 들어온 각과 나가는 각이 같습니다. 놀랍게도 이것은 빛이 가장 짧은(=가장 빠른) 길을 택하기 때문입니다. P 를 움직이며 두 각을 비교해 보세요.

두 각이 같아지는 순간, 거리 합도 최소가 됩니다. 기원전 1세기 헤론이 이미 이 사실을 증명했어요 (헤론의 반사 법칙).

응용

🎱 당구 — 한 쿠션 치기

흰 공 A(−5, −3) 로 오른쪽 벽(x = 6)을 한 번 맞혀 빨간 공 B(2, 4) 를 맞히려 합니다. 이번엔 대칭축이 세로선입니다. 어디를 겨냥해야 할까요?

벽 위의 점 P 를 위아래로 드래그해서 최단 경로를 찾아보세요. 힌트가 필요하면 토글을 켜세요.

직선 x = 6 에 대한 대칭은 이 단원의 네 가지(x축·y축·원점·y=x)에는 없지만, 원리는 똑같습니다 — 벽에서 같은 거리, 반대쪽으로 보내면 됩니다.

정리

대칭이동으로 최단 거리 풀기

전략 3단계
  1. 반드시 들러야 하는 선(강·거울·벽)을 대칭축으로 삼는다.
  2. 두 점 중 하나를 대칭이동 시킨다 → B′
  3. 나머지 점과 B′ 을 직선으로 잇는다. 그 직선이 대칭축과 만나는 점이 답!
상황대칭축최단 거리
A(−4, 3) → 강(x축) → B(3, 5)x축AB′ = 7² + 8² = 113 ≈ 10.63
A(−5, −3) → 벽(x = 6) → B(2, 4)직선 x = 6AB′ = 15² + 7² = 274 ≈ 16.55
핵심은 하나 — 꺾인 길은 비교하기 어렵지만, 대칭이동은 길이를 바꾸지 않으므로 꺾인 길을 곧은 길로 바꿔 놓을 수 있습니다. 그리고 두 점을 잇는 가장 짧은 길은 언제나 직선이죠.

아래 ‘내 생각 적기’ 칸에 정리해 보세요.
(1) 왜 B 를 대칭이동해도 되는지, PB = PB′ 을 근거로 설명하세요.
(2) 마을 A(−4, 3), B(3, 5) 일 때 최단 지점 P 의 좌표를 직접 계산해 구하세요. (직선 AB′ 의 방정식을 세우고 y = 0 을 대입)

↔ 수평 확장 · 어디에 쓰일까

당구·풋살의 벽 패스, 음향 설계(소리의 반사 경로), 통신 기지국 배치, 물류 창고에서 통로를 반드시 지나야 할 때의 최단 동선 — 모두 같은 문제입니다.

↕ 수직 확장 · 더 근본으로

빛이 최단(최소 시간) 경로를 택한다는 생각을 페르마의 원리라 합니다. 공기에서 물로 들어갈 때 빛이 꺾이는 굴절도 여기서 나오고, 이 발상은 물리학 전체를 떠받치는 최소 작용의 원리로 이어집니다.
