원의 방정식

원 = 한 평면에서 한 점(중심)으로부터 일정한 거리(반지름)에 있는 모든 점의 모임. 중심을 드래그 하고 반지름을 바꿔 보세요. 원 위의 초록 점은 항상 중심에서 거리 r 만큼 떨어져 있습니다.

(x−a)² + (y−b)² = r²

원 위의 점 (x, y) 는 중심 (a, b) 와의 거리가 r → √((x−a)²+(y−b)²)=r → 양변 제곱!

표준형
🖥 보여주며 조작📄 학습지 2-01 Q4 [스스로 정리하기]

표준형과 예시

중심 (a, b), 반지름 r  →  (x − a)² + (y − b)² = r²
중심 · 반지름방정식
(0, 0), r = 5x² + y² = 25
(−3, 2), r = 4(x + 3)² + (y − 2)² = 16
(−2, 3), r = 4(x + 2)² + (y − 3)² = 16
부호 주의! 중심이 (−3, 2) 이면 식에서는 (x + 3)² 처럼 반대 부호로 들어갑니다. 중심좌표를 그대로 빼 준다고 생각하면 됩니다: (x − (−3))² = (x + 3)².

두 점을 지름의 양 끝으로

두 점 A, B 를 지름의 양 끝점으로 하는 원. A, B 를 드래그 하면 중심(=중점)과 반지름(=거리의 절반)이 따라옵니다.

중심 = AB의 중점, 반지름 = AB 길이의 ½.
일반형 ↔ 표준형
🖥 보여주며 조작📄 학습지 2-01 Q6 일반형과 C 의 값

일반형을 완전제곱으로

일반형 x² + y² + Ax + By + C = 0 의 A, B, C 를 바꿔 보세요. 완전제곱으로 정리해 중심과 반지름을 찾습니다.

중심 (−A/2, −B/2),   r = (A/2)² + (B/2)² − C
정리
📖 교과서를 펴는 화면
📖교과서 33쪽 — [스스로 익히기] 문제를 해결합니다.

정리

꼴식읽는 법
표준형(x−a)²+(y−b)²=r²중심·반지름이 바로 보임
일반형x²+y²+Ax+By+C=0완전제곱해서 표준형으로
  • 중심 = (−A/2, −B/2)
  • 반지름 r = √((A/2)² + (B/2)² − C)  — 근호 안이 양수여야 진짜 원!
  • 근호 안 = 0 이면 점, 음수면 실제 원이 없음.

아래 ‘내 생각 적기’ 칸에, 표준형이 왜 “거리 = r” 에서 나오는지, 그리고 일반형을 완전제곱으로 고치는 과정을 예를 들어 설명해 보세요.

아폴로니오스의 원

두 정점 A, B 로부터의 거리의 비 PA : PB 가 일정한 값 k (≠1) 인 점 P 들의 자취는 놀랍게도 원이 됩니다. 이것을 아폴로니오스의 원이라 합니다.

k = 1 이면 원이 아니라 수직이등분선(직선)이 됩니다.

↔ 수평 확장 · 어디에 쓰일까

GPS는 위성 3개로부터의 거리를 재어 위치를 찾습니다. 각 위성을 중심으로 한 구(원)를 그리면 교점이 내 위치죠. 지진의 진원 찾기, 와이파이 실내 측위도 같은 원리입니다(삼변측량).

↕ 수직 확장 · 더 근본으로

원은 ‘중심에서 거리가 일정한 점의 모임’입니다. 이 정의를 3차원으로 올리면 구, n차원으로 올리면 초구가 되고 식은 (x₁−a₁)² + ⋯ + (xₙ−aₙ)² = r² 로 똑같습니다. 차원이 올라가도 정의는 그대로인 것이 수학의 힘이에요.
