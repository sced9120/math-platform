선분의 내분

한 선분 위의 점 하나가 그 선분을 두 조각으로 나눕니다. 이 조각들의 길이 비율을 우리가 원하는 대로 정확히 맞추려면 어디에 점을 찍어야 할까요?

내분(內分)
선분을 그 위의 점을 경계로 하여 두 부분으로 나누는 일
등분(等分)
몫을 똑같이 나눔 (내분의 특별한 경우, 1 : 1)

🔑 생각해보기 — “똑같이 나눈다”는 아이디어를 “m : n 으로 나눈다”로 넓히면, 점의 위치를 어떻게 정할 수 있을까요? 오른쪽 » 로 넘기며 직접 움직여 봅시다.

1차원 · 수직선

수직선 위에서 내분

수직선 위 두 점 A(a) B(b) 사이를 m : n 으로 내분하는 점 C 를 찾아봅시다. 슬라이더를 움직이며 규칙을 발견해 보세요.

m 을 키우면 점 C 가 B 쪽으로, n 을 키우면 A 쪽으로 다가갑니다. (여기선 n = 1 고정, m 조절)

C 의 좌표를 a, b, m, n 으로 나타내면? 값을 바꿔 보며 규칙을 예상해 보세요.

2차원 · 좌표평면

좌표평면 위에서 내분

A 와 B 를 직접 드래그하고, 슬라이더로 m : n 을 바꿔 보세요. 내분점 P 와 공식이 실시간으로 바뀝니다.

AP : PB = m : n. 회색 점은 A, B 를 잡아 끌어 옮길 수 있어요.
일반화

내분점 공식

두 점 A(x₁, y₁), B(x₂, y₂) 를 잇는 선분 AB 를 m : n 으로 내분하는 점 P 는 다음과 같습니다.

P = (  m x₂ + n x₁m + n,  m y₂ + n y₁m + n  )

왜 이렇게 될까? 한 점의 좌표는 “양 끝 좌표의 가중평균”입니다. B 쪽 비중이 m, A 쪽 비중이 n 이므로, 각 좌표에 상대편 비율을 곱해 더한 뒤 (m+n) 으로 나눕니다.

  • 중점은 m : n = 1 : 1 인 경우 → P = ( (x₁+x₂)/2 , (y₁+y₂)/2 )
  • m 이 클수록 P 는 B 에 가깝고, n 이 클수록 A 에 가깝습니다.

앞 화면으로 돌아가 슬라이더를 움직이며, 화면에 뜬 P 값이 이 공식과 일치하는지 확인해 보세요.

추가 탐구 · 외분

선분의 연장선 위: 외분 교육과정 외 · 심화

잠깐! ‘선분의 외분’은 2022 개정 교육과정에서 빠진 내용입니다. 시험 범위가 아니라 내분을 더 깊이 이해하기 위한 확장으로 살펴봅니다. 부담 없이 구경하세요!

점이 선분 바깥(연장선 위)에 있어도 “A 로부터의 거리 : B 로부터의 거리”를 m : n 으로 맞출 수 있습니다. 이것을 외분이라 합니다.

m = n 이면 외분점이 무한히 멀어져 정의되지 않아요.
Q = (  m x₂ − n x₁m − n,  m y₂ − n y₁m − n  )

내분 공식에서 n → −n 으로 바꾼 꼴입니다. 부호 하나 차이!

실생활 연결 · 물리

지레의 원리 = 내분

막대 양 끝에 공을 올리면, 평형(균형)을 이루는 받침점은 두 공을 잇는 선분을 어떤 비율로 내분할까요? 무게를 바꿔 보세요.

핵심 발견: 받침점은 무거운 쪽에 가깝습니다. 무게가 wA : wB 일 때, 받침점은 AB 를 wB : wA (무게의 반대 비율)로 내분합니다. 5 kg 과 20 kg → 받침점은 A 로부터 4 : 1 지점!
심화 탐구

여러 무게의 무게중심

세 꼭짓점에 서로 다른 구슬을 올리면 전체 무게중심 G 는 어디일까요? 각 점의 좌표를 무게로 가중평균 하면 됩니다.

G = (  w₁x₁ + w₂x₂ + w₃x₃w₁ + w₂ + w₃,  w₁y₁ + w₂y₂ + w₃y₃w₁ + w₂ + w₃  )

심화 과제 — 아래 삼각형에서 전체 무게중심 G 를 구해 봅시다.

  • A(0, 0) 에 200 g,   B(6, 0) 에 300 g,   C(0, 8) 에 400 g

아래 ‘내 생각 적기’ 칸에 풀이 과정과, 무게가 클수록 G 가 어느 쪽으로 끌리는지 서술하세요. (스스로 먼저 계산해 본 뒤, 필요하면 ‘AI 질문’ 탭에서 힌트를 받아도 좋아요.)

확장 탐구

🔭 더 넓게, 더 깊게

배운 것을 옆으로(다른 분야와 잇기) 그리고 아래로(더 근본적인 이유로) 넓혀 봅시다. 정답을 맞히는 시간이 아니라 생각을 키우는 시간이에요.

↔ 수평 확장 · 어디에 쓰일까

컴퓨터 그래픽에서 두 색을 섞는 그라데이션, 애니메이션에서 두 자세 사이를 채우는 트위닝은 모두 내분입니다. 색 A와 색 B를 m:n으로 내분하면 중간 색이 나오죠. 게임·영상의 부드러운 움직임이 여기서 나옵니다.

↕ 수직 확장 · 더 근본으로

내분점 공식 P = (n·A + m·B)/(m+n) 은 가중평균입니다. 점을 3개로 늘리면 삼각형 안의 모든 점을 (αA + βB + γC), α+β+γ=1 로 나타낼 수 있어요(무게중심 좌표). 이 아이디어가 3D 그래픽의 삼각형 색칠·질감 입히기의 핵심입니다.
