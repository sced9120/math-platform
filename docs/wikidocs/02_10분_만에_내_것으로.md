# 2. 가장 빠른 길 — 10분 만에 내 학교 것으로

이 장만 따라 하면 **여러분 계정으로 돌아가는 여러분만의 사이트**가 생긴다.
코드는 한 줄도 안 본다. 필자의 사이트를 같이 쓰는 게 아니라, 완전히 독립된
복사본이 생기는 것이니 마음껏 망가뜨려도 된다. (망가뜨리는 법은 의외로 어렵다)

> 전체 코드 저장소: **https://github.com/sced9120/math-platform**
> README에 있는 **"Deploy with Vercel"** 버튼이 오늘의 주인공이다.

## 준비물 (전부 무료 가입)

| 계정 | 용도 | 어디서 |
|---|---|---|
| GitHub | 코드 복사받을 곳 | [github.com](https://github.com) |
| Supabase | 데이터베이스(계정·기록 저장) | [supabase.com](https://supabase.com) |
| Vercel | 사이트를 인터넷에 공개 | [vercel.com](https://vercel.com) |
| AI 키 1개 | 챗봇·첨삭 (이것만 사용량 과금) | [platform.openai.com](https://platform.openai.com/api-keys) 등 |

## 순서 (버튼 누르기 전에 Supabase부터)

### ① Supabase 프로젝트 만들기 (3분)

1. [supabase.com](https://supabase.com) → **New project** (Region은 Seoul 권장)
2. 왼쪽 메뉴 **SQL Editor** → 저장소의 [`supabase/setup.sql`](https://github.com/sced9120/math-platform/blob/main/supabase/setup.sql)
   내용 **전체**를 복사해 붙여넣고 **Run**
   → 표·보안정책·함수가 한 번에 만들어진다. "Success"가 뜨면 끝.
3. **Project Settings → API**에서 세 값을 복사해 둔다:
   **URL / anon key / service_role key**

### ② Deploy 버튼 누르기 (3분)

저장소 README의 **Deploy with Vercel** 버튼을 누르면:

1. 코드가 여러분의 GitHub로 복사(fork)되고
2. 환경변수 입력칸이 나온다 — ①-3에서 복사한 세 값과 AI 키를 붙여넣는다
3. Deploy → 1~2분 뒤 `https://프로젝트이름.vercel.app` 완성

### ③ 관리자 계정 만들기 (3분, 터미널 한 번만)

여기서만 터미널이 잠깐 등장한다. 복사-붙여넣기 네 줄이다.

```bash
git clone https://github.com/내아이디/math-platform && cd math-platform
npm install
cp .env.local.example .env.local   # 파일을 열어 ①-3의 세 값 입력
npm run create-teacher -- admin 관리자 --admin
```

화면에 출력된 **아이디/초기비밀번호**로 사이트에 로그인하면 비밀번호 변경을
거쳐 관리자 화면이 열린다. 이후로는 모든 일이 웹에서 된다:

- **학생 관리**: 명단 붙여넣기 → 계정 일괄 생성
- **AI 키·모델**: API 키 등록·교체 (환경변수 몰라도 됨)
- **AI 프롬프트**: AI의 성격을 우리 교과에 맞게 편집

### ④ 확인

학생 계정 하나를 만들어 로그인해 보고, AI 질문 탭에서 "이 문제 답 알려줘"라고
해 본다. AI가 정중하게 거절하고 되물으면 성공이다.

## 여기서 막히면

| 증상 | 원인 |
|---|---|
| 배포됐는데 로그인이 안 됨 | ①-2의 SQL을 안 돌렸거나, 환경변수 값이 잘못 붙음 |
| AI가 응답 안 함 | AI 키 미등록 — 관리자 화면 "AI 키·모델"에서 등록 |
| `npm` 명령이 없다고 함 | [nodejs.org](https://nodejs.org)에서 LTS 설치 후 터미널 재시작 |

더 자세한 문제 해결은 7장에 모아 두었다. 다음 장부터는 "복사"가 아니라
"처음부터 만들기"가 궁금한 분들을 위한 이야기다 — 급하지 않다면 바로
5장(내 교과로 바꾸기)으로 건너뛰어도 된다.
