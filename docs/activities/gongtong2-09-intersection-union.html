교집합과 합집합

버튼을 눌러 영역을 강조해 보세요. 교집합 A∩B 는 양쪽 모두에, 합집합 A∪B 는 어느 한쪽에라도 속하는 원소입니다.

U = {1~10}, A = {1,2,3,4,6}, B = {2,4,6,8,10}
정의

정의 정리

기호뜻조건제시법
A ∩ B교집합 — 둘 다 속함{ x | x∈A 그리고 x∈B }
A ∪ B합집합 — 하나라도 속함{ x | x∈A 또는 x∈B }
서로소 — 두 집합이 공통 원소가 하나도 없을 때, 즉 A ∩ B = ∅ 이면 A 와 B 는 서로소입니다.
연산 법칙

교환 · 결합 · 분배법칙

법칙교집합/합집합
교환법칙A∩B = B∩A,   A∪B = B∪A
결합법칙(A∩B)∩C = A∩(B∩C),   (A∪B)∪C = A∪(B∪C)
분배법칙A∩(B∪C) = (A∩B)∪(A∩C)
A∪(B∩C) = (A∪B)∩(A∪C)
덧셈·곱셈의 교환·결합·분배법칙과 똑같은 구조예요. ∩ 을 ×, ∪ 를 + 처럼 생각하면 기억하기 쉽습니다 (단, 집합은 양방향 분배가 모두 성립!).
벤 다이어그램으로 확인

분배법칙, 눈으로 확인하기

법칙은 외우는 게 아니라 확인하는 것입니다. 왼쪽 식과 오른쪽 식 버튼을 번갈아 눌러 보세요 — 칠해지는 영역이 완전히 같습니다.

두 식이 서로 짝입니다. 짝끼리 눌러 비교하면 같은 그림이 나와요.
원소의 개수

n(A ∪ B) 세기

세 영역의 원소 개수를 바꿔 보세요. 겹치는 부분(A∩B)을 두 번 세지 않도록 빼 주는 것이 핵심입니다.

n(A∪B) = n(A) + n(B) − n(A∩B)
정리

정리

  • A∩B: 둘 다 속하는 원소   /   A∪B: 하나라도 속하는 원소
  • 교환·결합·분배법칙 성립, 서로소 ⟺ A∩B=∅
  • n(A∪B) = n(A) + n(B) − n(A∩B)
  • 세 집합: n(A∪B∪C) = n(A)+n(B)+n(C) − n(A∩B) − n(B∩C) − n(C∩A) + n(A∩B∩C)

아래 ‘내 생각 적기’ 칸에, n(A∪B) 공식에서 왜 n(A∩B) 를 빼는지를 ‘겹치는 부분을 두 번 세지 않기’로 설명해 보세요.

확장 탐구

🔭 더 넓게, 더 깊게

배운 것을 옆으로(다른 분야와 잇기) 그리고 아래로(더 근본적인 이유로) 넓혀 봅시다. 정답을 맞히는 시간이 아니라 생각을 키우는 시간이에요.

↔ 수평 확장 · 어디에 쓰일까

검색엔진의 AND/OR 조건, 쇼핑몰의 다중 필터, ‘축구도 하고 농구도 하는 학생 수’ 조사가 모두 교집합·합집합입니다. 유전 형질 분석에서 두 형질을 함께 가진 개체를 세는 일도 같은 계산이에요.

↕ 수직 확장 · 더 근본으로

n(A∪B) = n(A)+n(B)−n(A∩B) 를 3개로 늘리면 −(쌍의 교집합) +(셋의 교집합) 이 되고, n개로 가면 더하고 빼기를 번갈아 하는 규칙이 됩니다(포함·배제 원리). 확률·경우의 수·정수론에서 두루 쓰이는 강력한 도구예요.
