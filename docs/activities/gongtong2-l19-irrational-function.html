√ y = √x 의 그래프를 그려 보자

(1) 근호(루트)가 실수가 되려면 근호 안에 어떤 수만 넣을 수 있을까?

아래 수를 눌러 넣을 수 있는지 판정해 보세요.

수를 하나 눌러 보세요.
근호 안의 값은 반드시 0 이상이어야 한다

제곱해서 음수가 되는 실수는 없기 때문입니다. (−2)² = 4, 2² = 4 — 어느 쪽이든 결과는 0 이상이죠.

그래서 무리함수에는 늘 정의역이라는 조건이 따라붙습니다. 유리함수가 “분모 ≠ 0” 이었다면, 무리함수는 “근호 안 ≥ 0” 입니다.

⚠️ √4 = ±2 일까요?

아주 많이 헷갈리는 곳입니다. 두 가지를 따로 적어 봅시다.

x² = 4 의 해
√4 의 값
방정식의 해는 둘, √ 라는 기호의 값은 하나

√ 는 음이 아닌 쪽만 골라 주는 약속입니다. 그래서 y = √x 의 치역이 y ≥ 0 이고, 그래프가 위쪽 반만 그려집니다.

이 약속을 잊으면 마지막 [생각키우기] 에서 가짜 해에 걸립니다.

두 가지 스위치만 있습니다.
  • 근호 안 x 의 부호 → 그래프가 오른쪽이냐 왼쪽이냐 (y축 대칭)
  • 근호 앞 부호 → 그래프가 위냐 아래냐 (x축 대칭)

두 스위치의 조합으로 네 방향이 모두 나옵니다.

🔍 y = √(ax) — a 를 움직여 보자

y = √(ax) 에 대하여

①
a > 0 이면 정의역 { x | x ≥ 0 }, 치역 { y | y ≥ 0 }
a < 0 이면 정의역 { x | x ≤ 0 }, 치역 { y | y ≥ 0 } 치역은 둘 다 y ≥ 0 입니다. 근호값은 음수가 될 수 없으니까요.
②
함수 y = x²/a  (x ≥ 0) 의 그래프와 직선 y = x 에 대하여 대칭이다. 즉 서로 역함수 관계입니다. Ⅲ-1 에서 배운 그대로죠.
③
|a| 가 커질수록 x축에서 멀어진다. 같은 x 에서 y 값이 더 크게 나오니까요.
④
y = √(ax) 와 y = √(−ax) 는 y축 대칭,
y = √(ax) 와 y = −√(ax) 는 x축 대칭

↔️ y = √(2x) 를 옮겨 보자

유리함수 때와 완전히 같은 방법입니다. x 자리에 x−p, 오른쪽에 +q.

Q2. x축으로 2, y축으로 −1 만큼 평행이동한 식은?
y = √(2(x − 2)) − 1 = √(2x − 4) − 1

x 자리에 x − 2 를 넣고, 오른쪽에 −1 을 붙입니다.

문제에서 √(2x−4) 처럼 펼쳐진 꼴로 주어지면, 거꾸로 √(2(x−2)) 로 묶어서 시작점을 찾습니다. 이것이 다음 화면의 전략입니다.

정의역·치역의 이동

📍 Q3. 정의역과 치역은 어떻게 바뀌었나

y = √(2x)y = √(2x−4) − 1
시작점(0, 0)(2, −1)
정의역{ x | x ≥ 0 }{ x | x ≥ 2 }
치역{ y | y ≥ 0 }{ y | y ≥ −1 }
유리함수의 점근선과 똑같은 일이 일어납니다. 도형 전체를 (2, −1) 만큼 옮겼으니, 시작점도 그만큼 옮겨졌습니다. 그리고 정의역·치역은 그 시작점이 정합니다.
무리함수에서는 시작점 (p, q) 가 유리함수의 점근선 노릇을 한다

🧭 Q4. √(ax+b) + c 를 그리는 전략

유리함수에서 분자를 분모로 나눴듯이, 무리함수에서는 근호 안을 묶습니다.

1
근호 안에서 x 의 계수를 밖으로 묶는다 → y = √(a(x − p)) + q 꼴. ax + b = a(x + b/a) 이므로 p = −b/a 입니다.
2
시작점을 찍는다 → (p, q). 근호 안이 0 이 되는 곳이 바로 곡선이 시작하는 점입니다.
3
a 의 부호로 좌우를 정한다 → a > 0 이면 오른쪽, a < 0 이면 왼쪽.
4
근호 앞 부호로 위아래를 정한다 → + 이면 위, − 이면 아래. 그리고 지나는 점 하나를 더 찍어 확인합니다.
정의역·치역은 저절로 나옵니다. 시작점 (p, q) 에서 오른쪽이면 x ≥ p, 왼쪽이면 x ≤ p. 위로 뻗으면 y ≥ q, 아래로 뻗으면 y ≤ q.
💡 점을 쉽게 얻는 요령 — 근호 안을 0, 1, 4 로 두기

무리함수는 값이 대부분 무리수라 점 찍기가 번거롭습니다. 그런데 근호 안이 제곱수가 되게 x 를 고르면 계산이 없어집니다.

근호 안 = 0 → 시작점, = 1 → y 가 시작점보다 1 만큼, = 4 → 2 만큼 떨어진 점. 세 점이면 모양이 잡힙니다.

💬 발문 — 학생 의견 듣기📄 학습지 2-02 [생각키우기] · [생각 키우기 이어서] (1)

🕵️ 가짜 해를 찾아라

학습지에 실린 풀이입니다. 정말 맞을까요?

√(x−2) = 2x + t
x − 2 = (2x + t)²
x − 2 = 4x² + 4tx + t²
4x² + (4t − 1)x + t² + 2 = 0
서로 다른 두 점에서 만나야 하므로 판별식 D > 0
(4t−1)² − 4·4(t²+2) > 0
16t² − 8t + 1 − 16t² − 32 > 0
−8t − 31 > 0
t < −31/8

🔎
계산은 한 군데도 틀리지 않았습니다. 그런데도 답은 틀렸습니다. t = −5 로 확인해 봅시다. (−5 < −31/8 = −3.875 이므로 교점이 2개여야 합니다)
t = −5 를 넣으면 4x² − 21x + 27 = 0 → x = 3 또는 x = 2.25

두 값을 원래 식 √(x−2) = 2x − 5 에 직접 넣어 보세요. 위 버튼을 누르면 검산해 줍니다.

💬 발문 — 학생 의견 듣기📄 학습지 2-02 [생각 키우기 이어서] (2)📗 Ⅱ단원 명제 — 충분조건·필요조건

⚖️ 제곱은 부호를 지운다

A = B  ⟹  A² = B²  (참)
A² = B²  ⟹  A = B  (거짓)

0.5 ≠ −0.5 이지만 0.5² = (−0.5)² 입니다. 제곱하는 순간 부호가 지워집니다.

Ⅱ단원의 말로 하면

A = B 는 A² = B² 이기 위한 충분조건일 뿐, 필요충분조건이 아닙니다.

그래서 양변을 제곱해 얻은 방정식의 해는 “후보” 일 뿐입니다. 반드시 원래 식에 넣어 확인해야 하고, 통과하지 못한 것을 무연근(가짜 해) 이라 부릅니다.

✅ 올바른 답을 찾아라

빠뜨린 조건 두 가지
  • x ≥ 2 — 근호 안이 0 이상이어야 합니다.
  • 2x + t ≥ 0 — 왼쪽이 √(…) 이므로 0 이상입니다. 오른쪽도 0 이상이어야 하죠.

t = −5, x = 2.25 가 걸린 것은 두 번째 조건이었습니다. 2(2.25) − 5 = −0.5 < 0 이니까요.

1
직선이 시작점 (2, 0) 을 지날 때 — 0 = 2·2 + t → t = −4. 이때 교점은 (2, 0) 과 (2.25, 0.5) 로 2개. 포함됩니다.
2
직선이 곡선에 접할 때 — D = 0 → −8t − 31 = 0 → t = −31/8. 이때는 한 점에서만 만나므로 제외합니다.
3
t 를 −4 에서 −31/8 로 키우는 동안 교점이 2개로 유지됩니다.
올바른 답  −4 ≤ t < −31/8
t 의 범위판별식이 말하는 개수실제 교점
t < −421 (하나는 가짜)
−4 ≤ t < −31/822 ✅
t = −31/81 (접함)1
t > −31/800

판별식은 제곱한 뒤의 세계를 셉니다. 우리가 원한 것은 제곱하기 전의 세계 였습니다.

🎯 다른 길 — 제곱근을 새 변수로 삼으면 판별식이 필요 없습니다

u = √(x − 2) 라 두면 u ≥ 0 이고 x = u² + 2 입니다. 원래 식에 넣으면—

u = 2(u² + 2) + t  →  t = −2u² + u − 4

완전제곱 : t = −2(u − 1/4)² − 31/8  (단, u ≥ 0)

이제 t 는 u 에 대한 포물선입니다. 수평선 t = 일정 과 만나는 u ≥ 0 인 점의 개수를 세면 끝입니다.
u 가 다르면 x = u² + 2 도 다르므로, u 의 개수 = 교점의 개수 입니다.
tu ≥ 0 인 해교점
t < −41 개 (다른 하나는 u < 0 이라 버림)1
t = −42 개 (u = 0, 1/2)2
−4 < t < −31/82 개2
t = −31/81 개 (꼭짓점 u = 1/4)1
t > −31/80 개0
−4 ≤ t < −31/8 — 앞의 방법과 같은 답

u ≥ 0 이라는 한 줄이 빠뜨렸던 조건을 통째로 대신합니다. 가짜 해가 아예 생기지 않으니 검산도 필요 없죠.
