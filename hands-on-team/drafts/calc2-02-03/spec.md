# 활과 줄을 맞대 보기 — sin x / x → 1 에서 (sin x)′ = cos x 까지

- slug: calc2-arc-chord-sine
- topic: 미적분Ⅱ · 삼각함수의 극한과 미분
- summary: 단위원 위의 점을 끌어 각을 줄여 보세요. 높이 sin x 와 호의 길이 x 가 거의 같아지는 것을 보고, 그 사실 하나로 사인 그래프의 접선 기울기가 cos x 가 되는 것까지 이어 봅니다.
- 높이: 660

## 핵심 아이디어 (왜 이 조작이 이 성취기준인가)
- 학생이 단위원 위의 점 P 를 끌어 각 x 를 직접 줄이면, 수직선분(sin x)·호(x)·접선분(tan x)이 함께 줄어들며 길이가 서로 붙는다. sin x < x < tan x 의 부등식과 sin x / x → 1 이 '끄는 동작'으로 보인다.
- 2단계(탭 전환)에서는 사인 그래프 위의 점 a 를 끌고 h 를 줄여, 할선 기울기 {sin(a+h)−sin a}/h 가 cos a 높이로 모이는 것을 아래 cos 그래프 위의 점으로 찍는다. 1단계의 극한이 미분 공식으로 바로 쓰인다.
- 직전 활동(덧셈정리, 단위원 판)과 같은 단위원 그림을 이어 써서, sin(a+h) 전개 → 극한 → 도함수 흐름이 연결된다.

## 조작과 반응
- P 를 끌면(①) x 가 (0, π/2) 범위에서 바뀌고 세 선분·결과판이 즉시 바뀐다. x 가 0.3 미만이면 그림이 자동 확대(원점 대신 A 근처 확대 창, 배율 표시 "×4" 등)되어 짧은 선분도 보인다.
- [x 를 절반으로]를 누르면 x 가 반으로 줄고 결과판 sin x/x 가 1 에 다가가는 것이 한 줄씩 기록(최근 4개)된다.
- ②에서 a 를 끌면 할선과 결과판이 바뀐다. [h 를 절반으로] 누르면 할선이 접선에 가까워진다.
- [점 찍기]를 누르면 아래 칸에 (a, 현재 할선 기울기) 점이 찍힌다. h 가 작을 때 찍은 점들이 cos 곡선 위에 놓인다. h 를 바꾸면 이전 점은 흐리게 남긴다.
- [다시]: 현재 단계 초기화(x=1, a=π/4, h=1, 점 지우기).

## 수학 계산 규칙
- x 는 라디안. ① 범위 x ∈ [0.001, 1.5]; 끌기 시 각도 atan2 로 계산 후 이 범위로 자름(x=0, π/2 제외 → tan 발산·0 나누기 방지).
- 길이: sin x, x(호, 반지름 1), tan x. 비 sin x/x, x/tan x 표시.
- 반쪽 버튼으로 x 최소 0.001 미만이면 더 줄이지 않고 hint 에 "화면에서는 여기까지예요" 표시.
- ② a ∈ [0, 2π], h ∈ {1, 1/2, …, 1/1024} (최소 1/1024, h≠0). 할선 기울기 = (sin(a+h) − sin a)/h. 비교값 cos a.
- 결과판 숫자는 Math.sin 계산값(근삿값)임을 명시: "숫자는 계산기 근삿값".
- 극한은 화면에서 '유한 단계'만 보임을 hint/질문 문구로 밝힌다.

## 안내 문구와 탐구 질문
- hint ①: "점 P 를 끌어 각 x 를 줄여 보세요. 빨강(sin x)·파랑 호(x)·초록(tan x) 길이를 비교해요."
- hint ②: "점 a 를 고르고 h 를 절반씩 줄인 뒤 [점 찍기]. 찍힌 점이 어느 곡선에 놓이나요?"
- 극한 주의 문구(결과판 아래 작은 글씨): "화면은 x, h 를 유한 번 줄인 근삿값이에요. 극한은 '한없이' 줄일 때의 값입니다."
- 탐구 질문:
  1. 세 길이 sin x, x, tan x 의 크기 순서는 항상 같나요? 이 부등식에서 sin x / x 는 어떤 두 값 사이에 끼나요?
  2. x 를 절반씩 줄일 때 sin x / x 는 어디로 다가가나요? (cos x < sin x/x < 1 을 떠올려 보세요)
  3. sin(a+h) − sin a 를 덧셈정리로 펼치면 어떤 두 극한이 필요할까요? (sin h/h, (cos h − 1)/h)
  4. 찍은 점들이 놓인 곡선은 무엇인가요? 같은 방법으로 cos x 의 도함수를 짐작해 보세요.

## 제작 난이도 판단
보통 — 단위원 끌기는 직전 활동 코드 재사용 가능하나, 작은 x 확대 창과 2단계 그래프 두 칸을 360×660 안에 넣는 배치가 까다롭다.

## 점검 포인트
1. 0 < x < π/2 에서 sin x < x < tan x (단위원 넓이 비교: 삼각형 OAP < 부채꼴 < 삼각형 OAT) 가 그림과 숫자에 맞게 보이는지.
2. lim_{x→0} sin x / x = 1, lim_{h→0} (cos h − 1)/h = 0 — 문구가 '근삿값/유한 단계'임을 밝히는지.
3. 할선 기울기 (sin(a+h) − sin a)/h 가 h→0 에서 cos a 로 가고, 찍힌 점이 y=cos x 위에 놓이는지(h=1/1024 에서 오차 < 0.001).
4. 각은 라디안이어야 극한이 1 임(도 단위면 π/180) — 화면 단위 표기가 라디안인지.
5. 390·360×660 첫 화면에서 hint·탭·조작 버튼·결과판 bottom ≤ 660.
