스테이지 1
학습지 3-01 · Q4 도형의 평행이동

직선으로 별 4개 모으기

회색 점선은 원래 직선 y = x 입니다. 이것을 평행이동해 별 4개를 모두 지나가게 하세요.
옮긴 직선의 식은 y = (x − a) + b 입니다. x 자리에 x − a 가 들어가는 것에 주목!

⭐ 0 / 4

클리어했다면 a, b 를 다르게 해서도 클리어되는지 시험해 보세요. 직선에서는 답이 하나가 아닙니다 — 왜 그럴까요?

스테이지 2
학습지 3-01 · Q3 포물선의 평행이동

포물선으로 별 5개 모으기

원래 포물선은 y = x². 옮기면 y = (x − a)² + b 가 됩니다. 꼭짓점이 어디로 가야 하는지 먼저 눈으로 찾아보세요.

⭐ 0 / 5

포물선은 직선과 달리 클리어하는 (a, b) 가 딱 하나입니다. 꼭짓점의 위치가 곧 (a, b) 이기 때문이에요.

스테이지 3
학습지 3-01 · Q2 원의 평행이동

원으로 별 4개 모으기

원래 원은 x² + y² = 9 (중심 원점, 반지름 3). 옮기면 (x − a)² + (y − b)² = 9. 중심만 옮기면 되니까, (a, b) = 새 중심 입니다.

⭐ 0 / 4

반지름은 변하지 않습니다. 평행이동은 모양과 크기를 그대로 두고 위치만 바꾸는 이동이에요.

정리

게임에서 배운 것

대상(a, b) 만큼 평행이동게임에서
점 (x, y)(x + a, y + b)좌표에 더한다
방정식 f(x, y) = 0f(x − a, y − b) = 0식에는 빼서 넣는다
직선 y = mx + ny = m(x − a) + n + b답이 여러 개
포물선 y = x²y = (x − a)² + b답이 하나 (꼭짓점)
원 x² + y² = r²(x − a)² + (y − b)² = r²(a, b) = 새 중심
왜 점은 +a 인데 식은 −a 일까?
옮긴 도형 위의 새 점 (x, y) 는, 원래 도형 위의 어떤 점을 (a, b) 만큼 민 결과입니다. 그러니 민 것을 되돌린 점 (x − a, y − b) 가 원래 도형 위에 있어야 하죠. 그래서 원래 식 f 에 되돌린 좌표를 넣어 f(x − a, y − b) = 0 이 됩니다.

아래 ‘내 생각 적기’ 칸에 두 가지를 적어 보세요.
(1) 스테이지 1(직선)은 왜 클리어하는 (a, b) 가 여러 개이고, 스테이지 2(포물선)는 왜 하나뿐인가요?
(2) 점은 +a, 도형의 식은 −a 로 부호가 반대인 이유를 자신의 말로 설명해 보세요.

확장 탐구

🔭 더 넓게, 더 깊게

배운 것을 옆으로(다른 분야와 잇기) 그리고 아래로(더 근본적인 이유로) 넓혀 봅시다.

↔ 수평 확장 · 어디에 쓰일까

이 게임이 바로 게임 개발의 원리입니다. 캐릭터가 움직일 때 프로그램은 좌표에 이동량을 더하고, 카메라(화면)가 따라갈 때는 반대로 세상 전체를 −a 만큼 밀어 그립니다. 부호가 반대인 그 규칙이 실제 코드에 그대로 있어요.

↕ 수직 확장 · 더 근본으로

스테이지 1에서 답이 여러 개였던 이유는, 직선 y = x 를 자기 자신으로 되돌리는 이동 (a, a) 가 무수히 많기 때문입니다. 도형을 자기 자신으로 보내는 이동들의 모임을 그 도형의 대칭군이라 부릅니다.
