원과 직선의 위치 관계

원과 직선은 두 점에서 만나거나, 한 점에서 접하거나, 만나지 않습니다. 직선을 움직여(기울기 m, y절편 k) 세 경우를 모두 만들어 보세요. 원은 중심 O, 반지름 r 입니다.

공통수학2 · 원과 직선
🖥 보여주며 조작📄 학습지 2-02 [생각 틔우기] Q2 (1)~(4)

🎚 a 를 움직여라

원 x² + y² = 8 과 직선 y = x + a 입니다. 기울기는 1 로 고정이고 a 만 변합니다. 슬라이더를 움직이며 세 가지 위치 관계를 모두 만들어 보세요.

a 가 커지면 직선은 왼쪽 위로, 작아지면 오른쪽 아래로 평행이동합니다. 기울기가 그대로이므로 평행이동이죠 — 앞 단원에서 배운 그대로예요.

두 가지 방법
💬 발문 — 학생 의견 듣기📄 학습지 2-02 [생각 틔우기] Q2 (7)

거리로 볼까, 판별식으로 볼까

같은 상황을 기하적으로(중심과 직선 사이의 거리) 그리고 대수적으로(연립 후 판별식) 판단해 봅시다. 두 방법이 언제나 같은 답을 주는지 확인하세요.

① 중심과 직선 사이의 거리

직선을 x − y + a = 0 으로 쓰면
d = |0 − 0 + a| / 1² + (−1)² = |a| / 2
반지름 r = 8 = 22
d < r ⟺ |a| < 4

② 연립 후 판별식

y = x + a 를 대입하면
x² + (x + a)² = 8 → 2x² + 2ax + a² − 8 = 0
D/4 = a² − 2(a² − 8) = 16 − a²
D > 0 ⟺ |a| < 4
왜 같은 답이 나올까? 판별식은 “교점의 개수”를 세는 도구이고, 거리는 “직선이 원에 얼마나 가까운가”를 재는 도구입니다. 원은 중심에서 거리가 r 인 점들의 모임이니, 두 이야기는 결국 같은 이야기예요.

a 의 범위를 말해 보자

원 x² + y² = 8, 직선 y = x + a 입니다. 앞 화면에서 관찰한 것을 바탕으로 답해 보세요.

예제 1
✍️ 학습지에 적기📄 학습지 2-02 Q3 [예제 1] 거리로 판단

중심이 원점이 아니라면?

원 (x + 1)² + (y − 2)² = 8 과 직선 y = x − 1 의 위치 관계를 판단해 봅시다. 중심이 원점이 아니어도 방법은 똑같습니다 — 중심에서 직선까지의 거리를 재면 됩니다.

중심 (−1, 2), r = 22 ≈ 2.83
직선: x − y − 1 = 0
d = |(−1) − 2 − 1| / 2
  = 4 / 2 = 22 ≈ 2.83
d = r 이므로 접합니다 (교점 1개)

그림에서도 직선이 원에 살짝 스치듯 닿아 있습니다. 접점의 좌표는 중심에서 직선에 내린 수선의 발이에요.

예제 2
✍️ 학습지에 적기📄 학습지 2-02 Q4 [예제 2] 판별식으로 범위

서로 다른 두 점에서 만날 k 의 범위

원 x² + y² = 5 와 직선 y = 2x + k 가 서로 다른 두 점에서 만나도록 하는 실수 k 의 범위를 구해 봅시다. 슬라이더로 먼저 눈으로 찾고, 계산으로 확인하세요.

거리로

2x − y + k = 0 이므로
d = |k| / 5 < 5 = r
→ |k| < 5 → −5 < k < 5

판별식으로

x² + (2x + k)² = 5
→ 5x² + 4kx + k² − 5 = 0
D/4 = 4k² − 5(k² − 5) = 25 − k² > 0
→ −5 < k < 5

한눈에 정리

위치 관계교점거리로판별식으로
서로 다른 두 점에서 만남2개d < rD > 0
접함1개d = rD = 0
만나지 않음0개d > rD < 0
어느 쪽을 쓸까?
· 위치 관계만 알면 될 때 → 거리가 훨씬 빠릅니다(제곱·전개가 없음).
· 교점의 좌표까지 필요할 때 → 연립해야 하므로 판별식 쪽이 자연스럽습니다.
주의 — 직선이 x = k 꼴(세로선)이면 y = mx + n 으로 쓸 수 없습니다. 원과 직선 문제에서 기울기가 없는 경우를 빠뜨리지 않도록 늘 확인하세요. (다음 활동 ‘원의 접선의 방정식’에서 이 함정을 자세히 다룹니다.)

아래 ‘내 생각 적기’ 칸에 정리해 보세요.
(1) 두 판단 방법이 왜 같은 답을 주는지 자신의 말로 설명하세요.
(2) 원 x² + y² = 8 과 직선 y = x + a 가 접할 a 를 두 방법으로 각각 구해 보세요.
(3) 어떤 상황에서 어느 방법이 유리한지 예를 들어 적어 보세요.

스스로 확인

연습 1. 원 x² + y² = 9 와 직선 y = x + k 가 서로 다른 두 점에서 만나도록 하는 k 의 범위는?
힌트: d = |k|/√2 < 3 → |k| < 3√2 → −3√2 < k < 3√2
연습 2. 원 (x−1)² + (y−2)² = 4 와 직선 3x − 4y + 1 = 0 의 위치 관계는?
힌트: d = |3·1 − 4·2 + 1| / 5 = 4/5 = 0.8, r = 2 → d < r → 두 점에서 만남
다음 활동 예고 — 세 경우 중 ‘접함’만 따로 떼어 깊이 파고들면 접선의 방정식이 나옵니다. 기울기가 주어졌을 때, 접점이 주어졌을 때, 원 밖의 점에서 그을 때 — 세 유형을 다음 활동에서 다룹니다!

아래 ‘내 생각 적기’ 칸에, d 와 r 의 대소로 세 위치 관계를 정리하고, 기하적 방법과 대수적 방법 중 어떤 상황에서 어느 쪽이 편한지 자신의 생각을 적어 보세요.

‘d와 r의 대소’와 ‘판별식 D의 부호’가 왜 항상 같은 답을 줄까요? 직선을 원에 대입해 얻은 이차방정식의 D를 정리하면 D = 4(r² − d²)·(1+m²) 꼴이 나옵니다. 기하(거리)와 대수(판별식)가 한 식 안에서 만나는 순간입니다.
