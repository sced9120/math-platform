원과 직선의 위치 관계

원과 직선은 두 점에서 만나거나, 한 점에서 접하거나, 만나지 않습니다. 직선을 움직여(기울기 m, y절편 k) 세 경우를 모두 만들어 보세요. 원은 중심 O, 반지름 r 입니다.

판정

거리 d 와 반지름 r 을 비교

핵심은 원의 중심에서 직선까지의 거리 d 와 반지름 r 의 대소입니다. (앞 활동의 ‘점과 직선 사이 거리’ 공식을 그대로 사용!)

위치 관계거리 조건판별식 D교점
두 점에서 만남d < rD > 02개
접함d = rD = 01개
만나지 않음d > rD < 00개
두 가지 판정법은 결국 같은 말입니다. 직선을 원에 대입해 얻은 이차방정식의 판별식 D 의 부호와, d 와 r 의 대소가 정확히 대응합니다.
두 가지 방법

거리로 볼까, 판별식으로 볼까

같은 문제를 기하(거리)로도, 대수(판별식)로도 풀 수 있습니다. 두 방법은 언제나 같은 답을 줘요.

기하적 방법대수적 방법
하는 일중심에서 직선까지 거리 d 를 구해 r 과 비교직선을 원에 대입해 얻은 이차방정식의 판별식 D
두 점에서 만남d < rD > 0
접함d = rD = 0
만나지 않음d > rD < 0
편한 때교점의 개수만 알면 될 때 (계산이 짧음)교점의 좌표까지 필요할 때
왜 둘이 같을까? 직선 y = mx + k 를 x² + y² = r² 에 대입해 정리하면 D = 4(1+m²)(r²(1+m²) − k²) 꼴이 나오고, 여기서 r² − d² 가 그대로 나타납니다. 즉 D 의 부호 = r² − d² 의 부호 — 기하와 대수가 한 식에서 만납니다.
정리 · 연습

스스로 확인

연습 1. 원 x² + y² = 9 와 직선 y = x + k 가 서로 다른 두 점에서 만나도록 하는 k 의 범위는?
힌트: d = |k|/√2 < 3 → |k| < 3√2 → −3√2 < k < 3√2
연습 2. 원 (x−1)² + (y−2)² = 4 와 직선 3x − 4y + 1 = 0 의 위치 관계는?
힌트: d = |3·1 − 4·2 + 1| / 5 = 4/5 = 0.8, r = 2 → d < r → 두 점에서 만남
다음 활동 예고 — 세 경우 중 ‘접함’만 따로 떼어 깊이 파고들면 접선의 방정식이 나옵니다. 기울기가 주어졌을 때, 접점이 주어졌을 때, 원 밖의 점에서 그을 때 — 세 유형을 다음 활동에서 다룹니다!

아래 ‘내 생각 적기’ 칸에, d 와 r 의 대소로 세 위치 관계를 정리하고, 기하적 방법과 대수적 방법 중 어떤 상황에서 어느 쪽이 편한지 자신의 생각을 적어 보세요.

확장 탐구

🔭 더 넓게, 더 깊게

배운 것을 옆으로(다른 분야와 잇기) 그리고 아래로(더 근본적인 이유로) 넓혀 봅시다. 정답을 맞히는 시간이 아니라 생각을 키우는 시간이에요.

게임과 3D 영화의 광선 추적은 ‘빛(직선)이 물체(구)와 만나는가’를 매 픽셀마다 계산합니다. 총알이 목표에 맞았는지, 캐릭터가 벽에 부딪혔는지 판정하는 충돌 검사도 정확히 이 문제예요.

↕ 수직 확장 · 더 근본으로

‘d와 r의 대소’와 ‘판별식 D의 부호’가 왜 항상 같은 답을 줄까요? 직선을 원에 대입해 얻은 이차방정식의 D를 정리하면 D = 4(r² − d²)·(1+m²) 꼴이 나옵니다. 기하(거리)와 대수(판별식)가 한 식 안에서 만나는 순간입니다.
