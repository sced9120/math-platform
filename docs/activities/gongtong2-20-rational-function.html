유리식과 유리함수

분모에 문자가 들어 있는 식을 유리식이라 하고, f(x) 가 x 에 대한 유리식일 때 y = f(x) 를 유리함수라 합니다.

유리식의 예   1/x, (2x−1)/(x+1), 3/(x²−1)
다항식도 넓게 보면 유리식입니다(분모가 1). 분모에 문자가 있는 것이 우리가 다룰 유리함수예요.
정의역 주의! 유리함수는 분모 ≠ 0 이 되게 하는 실수 전체가 정의역입니다. 예) y = 1/(x−2) 의 정의역은 {x | x ≠ 2}.

분모를 0으로 만드는 x 는 “그래프가 지나갈 수 없는 세로선”이 됩니다 — 다음 화면에서 확인해요.

기본형

y = k/x 의 그래프

k 를 바꿔 보세요. 원점에 대칭인 쌍곡선이고, x축·y축이 점근선입니다 (닿을 듯 닿지 않는 선).

|k| 가 클수록 원점에서 멀어집니다. k>0 → 1·3사분면, k<0 → 2·4사분면.
평행이동

y = k/(x − p) + q

y = k/x 를 x축으로 p, y축으로 q 만큼 평행이동! 점근선도 함께 옮겨져 x = p, y = q 가 됩니다(주황 점선).

일반형 · 핵심

y = (ax+b)/(cx+d) 를 변형하기

교과서에 나오는 유리함수는 대부분 이 꼴입니다. 그런데 이대로는 점근선이 보이지 않아요. 분자를 분모로 나누어 k/(x−p) + q 꼴로 바꾸면 점근선이 바로 보입니다.

기본값은 교과서 예제와 같은 y = (2x−1)/(x+1) 입니다. 직접 계산해 보고 화면과 비교하세요!

정리

정리

y = a x + bc x + d  →  y = kx − p + q
항목내용
점근선x = p,   y = q
정의역{x | x ≠ p}
치역{y | y ≠ q}
대칭점근선의 교점 (p, q) 에 대하여 점대칭
모양쌍곡선(두 갈래). k>0 이면 1·3사분면 방향
그래프 그리는 순서 ① 분자를 분모로 나누어 k/(x−p)+q 꼴로 변형 → ② 점근선 x=p, y=q 를 점선으로 그리기 → ③ k 의 부호로 두 갈래 위치 정하기.

아래 ‘내 생각 적기’ 칸에, y = (ax+b)/(cx+d) 를 변형해 점근선을 찾는 과정을 예를 하나 들어 직접 계산해 보이세요.

확장 탐구

🔭 더 넓게, 더 깊게

배운 것을 옆으로(다른 분야와 잇기) 그리고 아래로(더 근본적인 이유로) 넓혀 봅시다. 정답을 맞히는 시간이 아니라 생각을 키우는 시간이에요.

↔ 수평 확장 · 어디에 쓰일까

볼록렌즈의 공식 1/f = 1/a + 1/b, 병렬 저항 계산, 효소 반응 속도(미카엘리스–멘텐), 약물 농도 변화가 모두 유리함수입니다. ‘한쪽이 커질수록 다른 쪽이 어떤 값에 다가가는’ 현상은 대부분 이 모양이에요.

↕ 수직 확장 · 더 근본으로

점근선은 ‘x가 한없이 커질 때 y가 다가가는 값’ — 바로 극한의 개념입니다. 미적분에서 배울 lim 의 첫 만남이죠. 한편 y = (ax+b)/(cx+d) 를 복소수까지 넓히면 뫼비우스 변환이 되어, 원을 원으로 보내는 아름다운 성질을 갖습니다.
