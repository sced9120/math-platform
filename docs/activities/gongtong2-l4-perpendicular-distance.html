직각으로 만나는 순간을 찾아라

두 직선의 기울기를 이리저리 바꿔 보세요. 직각으로 만나는 순간 그림에 직각 표시가 뜹니다. 그때 기울기의 곱이 얼마인지 눈여겨보세요.

m₂ = −1/m₁ 일 때 수직. (예: m₁=2 → m₂=−0.5)
규칙을 찾았나요? 두 직선이 직각으로 만나는 순간, 기울기의 곱은 늘 같은 값이 됩니다. 여러 값으로 바꿔 가며 확인해 보세요.
왜 하필 그 값인지는 다음 화면에서 두 가지 방법으로 증명합니다.
⚠️ 이 조건을 쓸 수 없는 경우가 있습니다

직선 x = 2 와 y = 3 은 누가 봐도 수직입니다. 그런데 위 슬라이더로는 이 두 직선을 만들 수 없습니다. 왜일까요?

x = 2 는 기울기가 없습니다(정의되지 않음). m₁ · m₂ = −1 은 두 직선 모두 기울기가 있을 때만 쓸 수 있는 조건이에요.

두 직선이 수직인 경우예판정
둘 다 기울기가 있다y = 2x,  y = −½x + 1m₁ m₂ = −1
하나는 x축에, 하나는 y축에 평행x = 2,  y = 3공식 사용 불가 — 그림으로 판단

일반형 a₁x + b₁y + c₁ = 0, a₂x + b₂y + c₂ = 0 으로 쓰면 수직 조건이 a₁a₂ + b₁b₂ = 0 이 되어 이런 예외가 사라집니다. x = 2 → (a,b) = (1,0), y = 3 → (a,b) = (0,1) 이므로 1·0 + 0·1 = 0 ✓

수직 조건, 두 가지로 증명하기

두 직선이 수직이면 왜 기울기의 곱이 −1 일까요? 서로 다른 두 방법으로 확인해 봅시다. 버튼을 누르면 그림과 식이 함께 바뀝니다.

m₁ 을 바꿔도 결론은 늘 같습니다 — 그래서 공식이 됩니다.

학습지 [수직의 조건] 의 대수적 방식이 ② 입니다. 수직은 “기울어진 정도의 차이가 90°” 라서 직선의 위치와 상관이 없고, 그래서 계산하기 편하도록 두 직선을 원점으로 옮겨 놓고 따집니다.

두 증명 중 더 잘 이해되는 쪽을 골라, 왜 m₁ · m₂ = −1 인지 자신의 말로 적어 보세요.

두 직선의 위치 관계

서로 다른 두 직선 y = m₁x + n₁, y = m₂x + n₂ 의 관계는 다음과 같이 판정합니다.

관계조건교점
한 점에서 만남m₁ ≠ m₂1개
평행m₁ = m₂, n₁ ≠ n₂없음
일치m₁ = m₂, n₁ = n₂무수히 많음
수직m₁ · m₂ = −11개(직각)

이제 아래 ‘내 생각 적기’ 칸에, 평행 조건과 수직 조건을 스스로 정리해 보세요.

확인 문제 직선 y = 2x + 3 에 평행하고 점 (1, 4) 를 지나는 직선, 그리고 수직이고 (1, 4) 를 지나는 직선의 방정식을 각각 구해보세요. (답을 먼저 스스로 → 필요하면 ‘AI 질문’ 탭)

↕ 수직 확장 · 더 근본으로

기울기 곱이 −1 이라는 조건은, 방향벡터 (1, m₁)과 (1, m₂)의 내적이 0이라는 말과 같습니다: 1·1 + m₁m₂ = 0. ‘수직 = 내적 0’ 은 3차원·n차원에서도 그대로 성립하는 더 근본적인 정의입니다.

축에 평행한 직선까지의 거리

직선이 축에 평행하면 거리는 눈으로 바로 보입니다. 점 P 를 끌어 옮기고, 직선도 움직여 보세요.

파란 점 P 를 끌어 보세요. 수선은 언제나 축에 나란한 방향으로 놓입니다.
  • 점 (x₀, y₀) 와 직선 x = k 사이 거리 = |x₀ − k|
  • 점 (x₀, y₀) 와 직선 y = k 사이 거리 = |y₀ − k|

점과 직선 사이 거리 공식

직선의 기울기 m 과 y절편 k 를 바꾸고(직선 y = mx + k, 즉 mx − y + k = 0), 점 P 를 드래그해 보세요. 파란 수선과 거리 d 가 공식과 함께 실시간 계산됩니다.

d = |a x₀ + b y₀ + c|a² + b²  (직선 ax + by + c = 0, 점 (x₀, y₀))

정리 & 증명의 큰 흐름

거리 공식 — 직선 ax + by + c = 0 과 점 (x₀, y₀) 사이 거리:
d = |a x₀ + b y₀ + c| / a² + b²

증명 두 가지 — 버튼을 누르면 그림이 바뀌고, 아래에 증명 과정이 이어집니다.

직선은 3x − 4y + 1 = 0 으로 고정해 두었습니다.

아래 ‘내 생각 적기’ 칸에서 점 (2, 3) 과 직선 3x − 4y + 1 = 0 사이 거리를 공식으로 구해보세요. (참고: d = |3·2 − 4·3 + 1| / √(9+16) = |−5|/5 = 1)

데카르트, 그리고 필즈 메달

17세기 초 르네 데카르트는 “평면 위 한 점의 위치를 두 개의 수(좌표)로 나타내면, 기하학 문제를 대수 방정식으로 바꿀 수 있지 않을까?”라는 발상을 합니다. 이것이 바로 좌표평면(데카르트 평면)의 탄생입니다.

원·직선·포물선 같은 도형이 방정식이 되고, 방정식을 해석하면 도형의 성질이 드러납니다. “대수 ↔ 기하”가 서로 번역 가능한 언어로 연결된 것이죠. 이 전환이 뉴턴·라이프니츠의 미적분학과 현대 해석기하학을 낳았습니다.

20세기 이후 이 연결은 대수기하학으로 정교해졌고, 들린·미르자하니 같은 필즈 메달 수상자들이 “좌표를 통한 기하 연구”의 최전선에 섰습니다. 오늘 우리가 쓴 거리 공식도, 400년 전 “공간과 수를 같은 언어로 보는” 사고 전환의 후손입니다.

오늘 배운 거리 공식이 바로 “기하(거리)를 대수(식)로 번역”한 대표적인 예입니다.

↕ 수직 확장 · 더 근본으로

거리 공식은 사실 벡터의 사영입니다. 직선 위 한 점에서 목표점까지의 벡터를, 직선의 법선벡터 (a, b) 방향으로 사영한 길이가 곧 거리죠. 그래서 3차원에서 점과 평면 사이 거리는 |ax₀+by₀+cz₀+d| / √(a²+b²+c²) 로 똑같은 꼴이 됩니다.
