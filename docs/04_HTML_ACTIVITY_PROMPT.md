# HTML 체험 활동 만들기 — AI에게 시키는 프롬프트

수학 플랫폼의 "HTML 콘텐츠" 활동은 학생 화면의 **격리된 iframe**(`sandbox="allow-scripts"`)
안에서 실행된다. 클로드(Opus/Sonnet)나 챗GPT에게 아래 템플릿으로 요청하면
결과물을 활동 폼의 "HTML 코드" 칸에 **그대로 붙여넣기**만 하면 된다.

---

## 붙여넣기용 프롬프트 템플릿

> `[...]` 부분만 바꿔서 사용. 뒤의 제약 조건은 그대로 유지할 것.

```
고등학교 수학 수업용 인터랙티브 웹 체험 활동을 만들어줘.

[활동 내용]
- 주제: [예: 이차함수 y = a(x-p)² + q 에서 p, q를 바꾸며 꼭짓점 이동 관찰]
- 학생이 할 조작: [예: p, q 슬라이더 2개를 움직이면 그래프와 꼭짓점 좌표가 실시간으로 바뀜]
- 화면에 표시할 것: [예: 좌표평면 그래프, 현재 식, 꼭짓점 좌표]

[기술 제약 — 반드시 지켜줘]
1. 파일 하나의 완결된 HTML로 만들어줘 (<!DOCTYPE html>부터). CSS와 JavaScript는
   전부 HTML 안에 인라인으로 넣고, 외부 CDN·라이브러리·폰트·이미지 링크는 쓰지 마.
2. 이 HTML은 sandbox="allow-scripts" iframe 안에서 실행돼. 그래서
   localStorage, sessionStorage, 쿠키, alert/confirm/prompt는 동작하지 않으니
   절대 사용하지 마. 상태는 자바스크립트 변수로만 관리해.
3. 그래프는 canvas로 직접 그려줘.
4. 가로폭은 컨테이너에 맞게 반응형으로(max-width 사용), 세로 높이는 약 [600]px
   안에 들어가게 해줘.
5. 스마트폰 터치에서도 조작 가능해야 해 (슬라이더/버튼 위주, 드래그 최소화).
6. 모든 문구는 한국어로, 수식은 읽기 쉬운 일반 텍스트로 (LaTeX 금지).
7. 고등학생이 설명 없이도 바로 쓸 수 있게 상단에 한 줄 사용 안내를 넣어줘.
```

## 사용 절차

1. 클로드/챗GPT에 위 프롬프트를 채워서 요청 → HTML 코드 받기
2. 교사 로그인 → 단원/활동 관리 → 새 활동 추가 → 유형 **HTML 콘텐츠**
3. 받은 코드를 "HTML 코드" 칸에 통째로 붙여넣기, 높이(px)를 프롬프트의 값과 맞추기
4. (선택) "학생 글 작성란 안내문"에 관찰 과제 입력 — 예: "p, q를 바꿀 때
   꼭짓점이 어떻게 움직이는지 규칙을 적어 보세요"
5. 공개 대상(전체/반 선택) 지정 → 공개 체크 → 추가
6. 학생 화면에서 직접 열어 동작 확인

## 잘 안 될 때

- **화면이 하얗게 나옴**: 코드가 localStorage/alert를 쓰고 있을 가능성이 큼.
  AI에게 "sandbox iframe이라 localStorage와 alert가 없다는 전제로 고쳐줘"라고 다시 요청.
- **아래가 잘림**: 활동 수정에서 높이(px)를 늘리기.
- **수정하고 싶을 때**: 기존 HTML을 통째로 복사해서 AI에게 주고 "여기서 [원하는 변경]만
  바꿔줘. 기존 기술 제약은 그대로 유지."라고 요청.

## 참고: 어떤 모델에게 시킬까

- **Claude Opus / Sonnet**: 인터랙티브 시각화·수학적 정확성이 좋음. 복잡한 체험은 Opus.
- 간단한 슬라이더/퀴즈 수준이면 Sonnet이나 GPT로도 충분.
- 같은 프롬프트를 재사용하므로 어느 모델이든 결과물 형식은 동일하게 나온다.
