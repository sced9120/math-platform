두 번 거치면? — 합성함수

환전처럼 함수를 연달아 거칠 수 있어요. 입력 x 를 함수 f 에 넣어 f(x) 를 얻고, 그것을 다시 g 에 넣어 g(f(x)) 를 얻습니다. 슬라이더로 확인하세요.

f(x) = 2x (환율 ×2),   g(y) = y − 3 (수수료 −3)
개념

합성함수의 정의

(g ∘ f)(x) = g( f(x) )
읽는 순서 주의! g ∘ f 는 “f 를 먼저, 그다음 g” 입니다. (안쪽 f 부터 계산 → 바깥 g)
정의되려면 f 의 치역 ⊂ g 의 정의역 이어야 합니다 (f의 출력이 g의 입력으로 들어갈 수 있어야 함).

예) f(x)=x+1, g(x)=x² 일 때   (g∘f)(x) = g(x+1) = (x+1)².

교환법칙

g ∘ f 와 f ∘ g 는 다르다!

f(x)=x+1, g(x)=2x. 순서를 바꾸면 결과가 달라집니다. 슬라이더로 두 결과를 비교하세요.

일반적으로 g ∘ f ≠ f ∘ g — 합성은 교환법칙이 성립하지 않습니다. (g∘f)(x)=2(x+1)=2x+2,   (f∘g)(x)=2x+1. 서로 달라요!
결합법칙

결합법칙은 성립

(h ∘ g) ∘ f = h ∘ (g ∘ f)
세 함수를 합성할 때는 묶는 순서를 바꿔도 결과가 같습니다(결합법칙 성립). 단, 함수를 적용하는 순서(f→g→h) 자체는 바뀌면 안 됩니다.
성질합성함수
교환법칙성립 안 함 (g∘f ≠ f∘g)
결합법칙성립 ( (h∘g)∘f = h∘(g∘f) )
항등함수 If ∘ I = I ∘ f = f
추가 탐구 · 그래프

합성함수의 그래프

f(x) = ax + b (파랑 직선), g(x) = x² (회색). 합성 (g∘f)(x) = (ax+b)² (초록)를 관찰하세요. a, b 를 바꾸면 초록 포물선의 꼭짓점이 어떻게 움직이나요?

정리

정리

  • (g∘f)(x) = g(f(x)) — f 먼저, g 나중 (안쪽부터)
  • 정의 조건: f 의 치역 ⊂ g 의 정의역
  • 교환법칙 성립 안 함 (g∘f ≠ f∘g), 결합법칙 성립

아래 ‘내 생각 적기’ 칸에, (g∘f)(x) 의 계산 순서를 설명하고, 구체적인 f, g 를 골라 g∘f ≠ f∘g 임을 직접 보이세요.

확장 탐구

🔭 더 넓게, 더 깊게

배운 것을 옆으로(다른 분야와 잇기) 그리고 아래로(더 근본적인 이유로) 넓혀 봅시다. 정답을 맞히는 시간이 아니라 생각을 키우는 시간이에요.

↔ 수평 확장 · 어디에 쓰일까

사진 앱의 필터를 여러 개 겹치는 일, 데이터 처리 파이프라인(정제 → 변환 → 요약), 원화→달러→엔화 이중 환전이 모두 합성입니다. 함수형 프로그래밍은 아예 ‘함수를 이어 붙이는 것’으로 프로그램을 짜요.

↕ 수직 확장 · 더 근본으로

합성은 교환법칙은 없지만 결합법칙은 성립합니다. ‘결합법칙이 성립하고 항등원이 있는 연산’ 구조를 수학에서는 모노이드·군이라 부르고, 대칭·암호·물리 법칙을 기술하는 언어가 됩니다. 미적분의 연쇄법칙도 합성함수의 미분이에요.
