Q4. 입력과 출력을 바꾸어 함수를 만들려면?

뒤집었을 때 한 입력에 출력이 둘이 되면 함수가 아닙니다. y = x² 에서 −3 과 3 이 둘 다 9 로 갔기 때문에, 뒤집으면 9 가 −3 과 3 둘로 갈라졌죠.

원래 함수가 일대일대응이어야 뒤집어도 함수가 된다

겹치면 뒤집었을 때 갈라지고, 남으면 뒤집었을 때 짝이 없어집니다. 그래서 겹치지도 남지도 않아야 해요.

역함수의 정의

함수 f : X → Y 가 일대일대응이면
Y 를 정의역, X 를 공역으로 하는 새 함수를 정의할 수 있다.
이것을 f 의 역함수 라 하고 f⁻¹ : Y → X 로 쓴다.
y = f(x) ⟺ x = f⁻¹(y)
같은 화살표를 어느 쪽에서 읽느냐의 차이일 뿐입니다.
역함수의 성질
📖 교과서를 펴는 화면📄 교과서 117쪽 역함수의 성질 ①~④

역함수의 성질 네 가지

함수 f : X → Y 가 일대일대응일 때

①f 의 역함수 f⁻¹ : Y → X 가 존재한다
②y = f(x) ⟺ x = f⁻¹(y)
③(f⁻¹ ∘ f)(x) = x (x ∈ X),   (f ∘ f⁻¹)(y) = y (y ∈ Y)
④(f⁻¹)⁻¹(x) = f(x) (x ∈ X)
③ 을 말로 풀면 — f 로 보냈다가 f⁻¹ 로 되돌리면 제자리입니다. 즉 f⁻¹ ∘ f 는 X 에서의 항등함수, f ∘ f⁻¹ 는 Y 에서의 항등함수. 로봇이 turn_left 를 4번 해서 제자리로 온 것과 같은 이야기죠.

🧦 양말과 신발

아침에 양말을 신고 → 신발을 신었다.
저녁에 되돌리는 순서는?  →  신발을 벗고 → 양말을 벗는다.

되돌릴 때는 나중에 한 것부터 풉니다. 순서가 뒤집히죠.

(g ∘ f)⁻¹ = f⁻¹ ∘ g⁻¹
순서가 뒤집힙니다
순서가 정말 중요할까?

f(x) = x + 1, g(x) = 3x 로 세 가지를 모두 구해 봅시다.

식결과맞나?
(g ∘ f)⁻¹(x)(g∘f)(x) = 3(x+1) = 3x+3 → x/3 − 1기준
f⁻¹ ∘ g⁻¹f⁻¹(x/3) = x/3 − 1○
g⁻¹ ∘ f⁻¹g⁻¹(x−1) = x/3 − ⅓×

순서를 지켜야 합니다. f⁻¹ ∘ g⁻¹ 만 맞고 g⁻¹ ∘ f⁻¹ 은 틀립니다.

[확장하기] 두 함수 f(x) = 3x + 4, g(x) = 5x − 2 에 대하여 ( g ∘ (f ∘ g)⁻¹ ∘ g )(3) 의 값을 구하시오. (교과서 119쪽)

안쪽부터 차례로 갑니다.

g(3) = 5·3 − 2 = 13

(f ∘ g)(x) = f(5x−2) = 3(5x−2) + 4 = 15x − 2
→ (f ∘ g)⁻¹(x) = (x + 2) / 15   →   (f∘g)⁻¹(13) = 15/15 = 1

g(1) = 5 − 2 = 3

y = x 에 대하여 대칭

두 함수 y = 2x − 1 과 y = ½x + ½ 의 그래프를 그려 봅시다. 점을 끌어 보세요.

함수 y = f(x) 의 그래프와 역함수 y = f⁻¹(x) 의 그래프는
직선 y = x 에 대하여 대칭
왜 그럴까?

y = f(x) 의 그래프 위의 점을 (a, b) 라 하면

b = f(a)  ⟺  a = f⁻¹(b)

이므로 점 (b, a) 는 y = f⁻¹(x) 의 그래프 위의 점입니다.

그런데 (a, b) 와 (b, a) 는 직선 y = x 에 대하여 대칭이죠. Ⅰ-3 도형의 이동에서 배웠습니다!

⚠️ 교점은 늘 y = x 위에 있을까?

앞 화면에서 두 그래프의 교점이 y = x 위에 있었습니다. 언제나 그럴까요?

정리
  • 증가함수 — 교점은 모두 y = x 위에 있습니다. f(x) = x 를 풀면 끝이에요.
  • 감소함수 — y = x 밖에서도 만날 수 있습니다.

“역함수와의 교점은 y = x 에서 구하면 된다” 고 외우면 감소함수에서 틀립니다.

왜 그럴까? 두 그래프는 y = x 에 대해 서로 대칭입니다. 점 P 가 교점이면 P 를 y = x 에 대칭시킨 점 P′ 도 교점이에요. 증가함수는 P 와 P′ 이 같을 수밖에 없지만(그래서 y = x 위), 감소함수는 P 와 P′ 이 서로 다른 두 교점이 될 수 있습니다.

🔍 y = x² 은 정말 역함수가 없을까?

앞에서 y = x² 은 뒤집으면 함수가 되지 못했습니다. 그런데 입력을 받는 범위를 줄이면 어떻게 될까요?

정리
정의역일대일대응?역함수
실수 전체아니다 — −1 과 1 이 모두 1 로없음
x ≥ 0맞다 (치역 y ≥ 0)y = √x
x ≤ 0맞다 (치역 y ≥ 0)y = −√x

함수는 식만이 아니라 정의역까지 정해야 완성됩니다. 같은 식이라도 정의역이 다르면 다른 함수예요 — 1-01 에서 배운 그대로입니다.

다음 단원 예고 — 여기서 나온 y = √x 가 학습지 7 의 무리함수 입니다. y = x² 의 오른쪽 반을 눕힌 모양이죠.

🌡 화씨와 섭씨 — 서로의 역함수

화씨온도 x °F 를 섭씨온도 y °C 로 바꾸는 식은 y = (5/9)(x − 32) 입니다.

물음답
(1) 섭씨 x °C → 화씨 y °F 로 바꾸는 식은?
(2) 0 °C 는 몇 °F 인가?
(3) 100 °C 는 몇 °F 인가?
(4) 화씨와 섭씨의 눈금이 같아지는 온도는?
(4) 를 푸는 방법

눈금이 같아진다는 것은 y = x 인 점을 찾는 것입니다.

(5/9)(x − 32) = x  →  5(x − 32) = 9x  →  5x − 160 = 9x  →  −4x = 160

x = −40  →  −40 °C = −40 °F

두 그래프가 y = x 위에서 만나는 점이죠. 이 식은 증가함수라 교점이 y = x 위에 있습니다 — 앞 화면에서 본 그대로입니다.
