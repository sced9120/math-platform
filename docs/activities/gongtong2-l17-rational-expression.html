📝 단어 총정리 — 유리식, 무리식

1. 유리식 — 분모와 분자가 모두 으로 이루어진 식. 특히, 다항식도 유리식이다.

2. 무리식 — 식의 변수가 에 포함되어 있는 식 중 유리식으로 나타낼 수 없는 식.

예: √x, √(x−1), 1/√x, 2x + √(3x−1) 등등

교과서 125쪽 — 유리식의 성질

① A/B = (A×C)/(B×C)  (단, BC ≠ 0)
② A/B = (A÷C)/(B÷C)  (단, C ≠ 0)

①은 통분의 근거, ②는 약분의 근거입니다. 분수를 다루던 방법이 그대로 옵니다.

⚠️ 오늘 가장 조심할 것 — 약분해도 정의역은 그대로

(x+1)/(x²−1) = (x+1)/((x+1)(x−1)) = 1/(x−1)

약분한 결과만 보면 x ≠ 1 만 빼면 될 것 같습니다. 하지만 성질 ②의 조건이 C ≠ 0, 즉 x + 1 ≠ 0 이었죠. 약분을 할 수 있으려면 애초에 x ≠ −1 이어야 했습니다.

정의역은 약분하기 전의 식으로 정한다 → x ≠ 1 이고 x ≠ −1

이 함정이 뒤쪽 Q2 (3) 번에 그대로 나옵니다.

❓ 이 두 함수는 같은 함수일까?
f(x) = (x² − 1)/(x − 1)  와  g(x) = x + 1

약분하면 f(x) = x + 1 이니 같아 보입니다. 그런데—

x 값을 눌러 두 함수에 넣어 보세요.

다른 함수입니다. 두 함수가 같으려면 정의역과 대응이 모두 같아야 합니다.

√ 무리식의 계산 (7)~(12)

단 하나의 공식으로 거의 다 됩니다.
(√A + √B)(√A − √B) = A − B
근호가 통째로 사라집니다. 이것이 분모의 유리화의 원리이기도 합니다.
분모가 √A + √B 이면 √A − √B 를 분자·분모에 곱하세요.
➕ 교과서 130쪽 예제 1 — 분모의 유리화 한 문항 더
x / (√(x+4) + 2) 를 간단히 하시오.

분모의 짝 √(x+4) − 2 를 분자·분모에 곱합니다.

= x(√(x+4) − 2) / ((x+4) − 4) = x(√(x+4) − 2) / x = √(x+4) − 2

마지막에 x 로 약분했으므로 x ≠ 0 이 꼭 필요했습니다. 또 근호 안이 실수여야 하니 x ≥ −4 도 함께 붙습니다. 정리하면 −4 ≤ x, x ≠ 0.

🏺 이집트 사람들의 분수

고대 이집트 사람들은 분자가 1 인 분수(단위분수) 만 썼습니다. 그래서 2/3 같은 수도 단위분수의 합으로 바꿔 적어야 했습니다.

그들이 쓴 규칙
1/x = 1/(x+1) + 1/(x(x+1))

오른쪽을 통분하면 —

1/(x+1) + 1/(x(x+1)) = x/(x(x+1)) + 1/(x(x+1)) = (x+1)/(x(x+1)) = 1/x

오늘 배운 통분과 약분만으로 끝납니다. (단, x ≠ 0, x ≠ −1)
